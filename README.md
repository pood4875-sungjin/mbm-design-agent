# Campaign Agent

MBM 캠페인 디자인 실행 에이전트. 기획을 넣으면 온라인·오프라인 산출물을 한 번에 만들어 준다.

바로 열기: https://pood4875-sungjin.github.io/mbm-design-agent/app/

## 쓰는 법

1. 위 링크를 연다.
2. 기획 내용을 붙여넣거나 직접 입력한다.
3. 무엇을 만들지 → 필요한 정보 → 스타일 순으로 4단계를 지나면 초안이 나온다.
4. 아트보드에서 고치고, 우측 상단에서 내보낸다.

## AI 대화 (선택)

자연어 대화는 각자 자기 Anthropic API 키로 동작한다. 키는 브라우저에만 저장되고
서버로 가지 않는다. 우측 상단 [AI 키]에 넣고 [연결 테스트]를 누르면 된다.

키가 없어도 앱은 그대로 쓸 수 있다 — 대화가 키워드 기반 진행으로 바뀔 뿐,
생성·편집·내보내기는 전부 동작한다.

**이 저장소에는 API 키가 들어 있지 않다.** `app/config.local.example.js`는 형식만 보여주는
예시 파일이다. 로컬에서 키를 자동으로 잡히게 하려면 이 파일을 `config.local.js`로 복사해
키를 넣는다. 그 파일은 커밋되지 않는다.
