# 노션 마케팅 에이전트 대시보드 — 업데이트 요청 8 + 개발중 5 (2026-11-20 읽음)

## 업데이트 요청 (11/18 등록, 전부 「확인요청」)

[N1] [공통] 가이드 범위 초과 시 초과 글자만 생략 제안 (오류·상)
- 현재: 입력 문구가 가이드 범위를 넘으면 그 문구 전체가 산출물에서 사라진다. 가이드 안에 들어가는 부분까지 함께 없어진다.
- 그림: 자소설 550×400·800×800에서 메인이 「GS리테일」로 바뀌었다. 서브와 상세도 표기되지 않았다. 1200×280·750×500에서는 서브가 빠졌다.
- 개선 방향: 가이드 안의 문구는 유지하고 넘치는 뒷부분만 숨긴다. 입력 원문은 그대로 두어, 줄이면 다시 나타난다. 넘치면 「검수 필요」로 표시한다.

[N2] [공통] 화면 이동 시 오류 현상 (오류·상, 영상 첨부)
- 드래그로 화면을 옮기면 산출물과 글자가 파랗게 선택된다.
- 반투명 사본이 마우스를 따라온다. 🚫 아이콘이 자주 뜬다.
- 버튼을 놓아도 계속 움직이고 선택 상태가 풀리지 않는다. 우클릭 메뉴 같은 팝업이 뜬다.

[N3] [자소설닷컴] 서브문구 입력 시 문구 오류 (오류·상)
- 서브가 빈 상태에서 「에이케이플라자(주)」를 입력하면 메인 일부인 「AK PLAZA」가 자동으로 붙어 두 줄이 된다(160×600).
- 불필요한 문구를 지워도 박스는 두 줄 크기로 남아 가이드를 벗어난다.
- 예시 1-2: 메인 「경력 전문직 채용 모집」, 서브 「AK PLAZA」로 의도했다. 실제로는 서브가 「AK PLAZA 경력 전문직 채용」(550×400)과 「AK PLAZA AK PLAZA」(160×600)로 나왔다.

[N4] [공통] 영문 고객사명 자동 인식 오류 (오류·중)
- 메시지의 첫 줄에 고객사명을 영문 「AK PLAZA」로 적으면 인식하지 못해 고객사 칸이 비어 있다.

[N5] [자소설닷컴] SVG 내보내기 시 동일 규격 소재의 파일명 중복 (오류·중)
- 아래 두 쌍이 각각 같은 SVG 이름으로 나온다. 폴더로 옮기면 하나가 덮이거나 번호가 붙는다. 이미지 파일은 각 패키지 이름으로 맞게 나온다.
  - M프리미엄(M채팅목록배너 로고)과 M스탠다드
  - PC프리미엄과 PC스탠다드의 PC채용공고

[N6] [자소설닷컴] 상세문구 3번째 줄 앞 공백 정렬 추가 (디자인·중)
- 대상: PC 프리미엄 - PC 팝업배너, M 프리미엄 - M 팝업배너.
- 상세 3번째 줄이 2번째 줄 「모집직무: 」 다음 글자와 같은 자리에서 시작하도록 공백을 자동으로 넣어 달라는 요청이다.
- 지금까지는 담당자가 전각 공백 4개와 일반 공백 2개를 직접 입력해 왔다.

[N7] [공통] 상단 문구 삭제요청 (디자인·하)
- 캔버스 맨 위 「하 · 1차 적용 · 15장 → 17종」 타이틀을 없애고, 매체명이 가장 위에 나오게 해 달라는 요청이다.

[N8] [공통] 배경 이미지 삽입 및 채우기·편집 기능 확장 (희망·하)
- 현재 배경은 색만 지정할 수 있어 사진·패턴 배경을 쓸 수 없다.
- 역할 구분: 배경 이미지는 소재 전체를 덮는 장식, 키비주얼은 필수 영역이 있는 핵심 그림이다.
- 배경 유형에 「이미지」를 추가하고 기존 이미지 편집(투명도·위치·크기)을 쓸 수 있게 한다.
- 배치 옵션: 꽉 채우기(Fill), 전체 보기(Fit), 반복(Tile, 크기 조절).
- 예시: 담당자가 한림제약 자소설 소재에 좌우 반복 패턴을 넣었다(투명도·크기 조절).
