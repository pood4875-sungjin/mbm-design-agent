사용자(가이드 「[중앙배너 공통] 텍스트 영역(웹 폰트) / 이미지 영역 분리 · 별도 전달: 텍스트 / 배경 Hex / 텍스트 없는 이미지 / 로고 이미지(MO)」): 「결국 이미지랑 로고 이미지만 주면 되는 건가」 → 「응 그렇게」.
- 추출 목록: 메인 대형 배너 이미지형 1256×295·702×428 → **참고 규격**으로. 대신 `catch-center-object-pc`(515×315, 투명 배경 누끼 오브젝트, 글자 X) · `catch-center-object-mo`(622×380, 배경색 포함, 글자 X) · `catch-center-logo-mo`(160×160) 추출.
