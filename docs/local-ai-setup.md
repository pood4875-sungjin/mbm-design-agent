# Claude Code 연결 — 로컬 앱에서 내 Claude 계정 쓰기

AI 기능은 **내 컴퓨터에서 켠 앱**에서 **내 Claude 계정**으로 돌아요. API 키는 쓰지 않고, 그 계정 플랜의 사용 한도 안에서 돌아요.
공개 앱(github.io)에서는 연결할 수 없어서 규칙으로만 판단해요.

## 처음 한 번
1. **Claude Code 설치** — 터미널에 한 줄:
   ```sh
   npm install -g @anthropic-ai/claude-code
   ```
2. **앱 켜기** — 저장소 폴더의 **`MBM 시작.command`** 를 더블클릭해요. 서버가 켜지고 브라우저로 앱이 열려요. (처음엔 서버 패키지를 설치하느라 조금 걸려요)

## 앱에서 연결하기
1. 앱 위쪽 오른쪽 **「Claude Code 연결」** 칩을 눌러요. 로컬 앱 · Claude Code 설치 · 계정 연결 세 단계를 확인해서 보여 줘요.
2. 로그인이 필요하면 **「계정 연결」** 을 눌러요. 앱이 `claude auth login` 을 실행하고, 브라우저에 Claude 로그인 창이 떠요.
3. 로그인을 마치면 앱이 `claude auth status` 로 확인해서 칩이 **「Claude Code 연결됨 · 플랜」** 으로 바뀌어요.
4. 그다음부터는 앱이 뒤에서 Claude Code 를 불러요.

## 연결되면 Claude 가 하는 일
| 기능 | 언제 |
|---|---|
| 그림 종류 판단 | 키비주얼을 올리면 규칙이 먼저 판정하고, Claude 가 그림을 보고 다시 골라요(4~5초). 다르면 「키비주얼 유형」에 넣고 알려 줘요. 「자동」으로 되돌릴 수 있어요 |
| AI 그림 판단 | 소재 패널 「AI 그림 판단」 — 그림을 어디서 자르고 어디에 놓을지 |
| 기획 해석 | 첫 화면에 적은 공고·지시를 해석해요(키가 없을 때) |
| AI 추가 제안 · 말로 고치기 | 오른쪽 패널 「AI 디자인」 |

같은 그림은 한 번만 판단하고 저장해 둬요(`ref/learned/cases/_out/kvjudge-cache.json`).

## 알아 두기
- 계정은 각자 자기 것으로 연결해 주세요. 한 계정을 여러 사람이 같이 쓰면 이용 약관에 걸릴 수 있어요.
- 사용 한도에 걸리면 「잠시 뒤 다시」라고 알려 주고 규칙 판정으로 계속 진행해요.

## 안 될 때
| 칩·창에 뜨는 말 | 할 일 |
|---|---|
| Claude Code · 규칙만 | 공개 주소로 열었어요 — `MBM 시작.command` 로 로컬 앱을 열어 주세요 |
| Claude Code 설치 필요 | 위 설치 한 줄 실행 뒤 창에서 「다시 확인」 |
| 로그인 창이 닫혔어요 | 「계정 연결」을 다시 누르거나 터미널에서 `claude auth login` |
| 서버가 예전 버전이에요 | `git pull` 후 `MBM 시작.command` 다시 |

서버 쪽 코드: `server/claudelink.js`(상태·로그인·그림 종류 판단·일반 질문), 앱: `app/claudelink.js`(칩·연결 창).
