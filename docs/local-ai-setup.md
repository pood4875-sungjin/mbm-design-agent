# Claude 연결 — 로컬 앱에서 내 Claude 계정 쓰기

AI 기능은 **내 컴퓨터에서 켠 앱**에서 **내 Claude 계정**으로 돌아요. API 키는 쓰지 않고, 그 계정 플랜의 사용 한도 안에서 돌아요.
공개 앱(github.io)에서는 연결할 수 없어서 규칙으로만 판단해요.

## 처음 한 번
1. **Claude Code 설치** — 터미널에 한 줄:
   ```sh
   npm install -g @anthropic-ai/claude-code
   ```
2. **앱 켜기** — 저장소 폴더의 **`MBM 시작.command`** 를 더블클릭해요. 서버가 켜지고 브라우저로 앱이 열려요. (처음엔 서버 패키지를 설치하느라 조금 걸려요)

## 앱에서 연결하기
1. 앱 위쪽 오른쪽 **「Claude 연결하기」** 칩을 눌러요. 로컬 앱 · Claude Code 설치 · 계정 연결 세 단계를 확인해서 보여 줘요.
2. 로그인이 필요하면 **「계정 연결」** 을 눌러요. 앱이 `claude auth login` 을 실행하고, 브라우저에 Claude 로그인 창이 떠요.
3. 로그인을 마치면 앱이 `claude auth status` 로 확인해서 칩이 **「Claude 연결됨」** 으로 바뀌어요.
4. 그다음부터는 앱이 뒤에서 Claude Code 를 불러요.

## 연결되면 Claude 가 하는 일
| 기능 | 언제 |
|---|---|
| 그림 종류 판단 · 추가 시안 방향 | 키비주얼을 올리면 규칙이 먼저 판정하고, Claude 가 그림을 보고 다시 골라요(5~10초). 추가 시안 3개(정렬·태그·밝은 지면)의 방향도 같이 골라요. 되돌리기 ⌘Z |
| AI 그림 판단 | 초안을 만들거나 그림을 바꾸면 **자동으로** 돌아요(1~3분). 그림을 어디서 자르고 어디에 놓을지 정해요. 그 사이 손댄 소재는 건드리지 않아요. 인스펙터 「AI 판단 해제」로 되돌려요 |
| 기획 해석 | 첫 화면에 적은 공고·지시를 해석해요(키가 없을 때) |
| AI 추가 제안(자유 디자인) · 말로 고치기 | 오른쪽 패널 「AI 추가 제안」을 **눌렀을 때만** |

같은 그림은 한 번만 판단하고 저장해 둬요(`ref/learned/cases/_out/kvjudge-cache.json`).

## 알아 두기
- 계정은 각자 자기 것으로 연결해 주세요. 한 계정을 여러 사람이 같이 쓰면 이용 약관에 걸릴 수 있어요.
- 사용 한도에 걸리면 「잠시 뒤 다시」라고 알려 주고 규칙 판정으로 계속 진행해요.

## 안 될 때
| 칩·창에 뜨는 말 | 할 일 |
|---|---|
| Claude Code · 규칙만 | 공개 주소로 열었어요 — `MBM 시작.command` 로 로컬 앱을 열어 주세요 |
| Claude Code 설치 필요 | 위 설치 한 줄 실행 뒤 창에서 「다시 확인」 |
| 로그인 창이 닫혔어요 | 「계정 연결」을 다시 누르거나 터미널에서 `claude auth login` |
| 서버가 예전 버전이에요 | `git pull` 후 `MBM 시작.command` 다시 |

서버 쪽 코드: `server/claudelink.js`(상태·로그인·그림 종류 판단·일반 질문), 앱: `app/claudelink.js`(칩·연결 창).

## 나중에 API 로 바꿀 때 (지금은 안 해요)
2026-11-10 결정: **지금은 로컬 앱 + 각자 Claude 계정 로그인으로 가요.** API 키 방식은 나중에 필요할 때 개발해요. 그때 볼 것만 적어 둬요.

- **왜 지금은 로그인인가요?** 디자인 생성은 여러 번 주고받아서 API 로 하면 토큰 비용을 미리 알기 어려워요. 로그인은 월 구독료 고정이에요. 대신 플랜 사용 한도에 걸릴 수 있어요.
- **claude.ai 밖 우리 서버에 「Claude 로그인」을 붙이는 건 안 돼요.** 다른 서비스가 Claude 계정 로그인을 붙여 주는 건 Anthropic 이 허락하지 않아요. 서버에 올리려면 API 키(회사 키 또는 각자 키)이거나, 앱을 claude.ai 안(Artifact)에 올려 보는 사람 계정으로 부르는 방법이 있어요.
- **지금 기능별 상태**

  | 기능 | 지금 | API 로 바꿀 때 |
  |---|---|---|
  | 그림 종류 판단 `/api/kvjudge` | 계정만(`server/claudelink.js judgeKv`) | API 길 새로 |
  | 기획 해석 `/api/claude/ask` | 계정만(`server/claudelink.js ask`) · 브라우저 키 길은 `app/llm.js` 에 남음(입력 칸만 뺌) | 서버 API 길 새로 |
  | AI 그림 판단 `/api/analyze` | `server/.env` 키 있으면 API, 없으면 계정(`server/design.js analyzeKvCli`) | 이미 됨 |
  | 자유 디자인 `/api/freedesign` | 계정 · `FREEDESIGN_API=1` + 키면 API | 이미 됨 |
  | A/B 디자인 `/api/design` | API 만 | 계정 길은 없음 |

- **바꿀 때 하면 좋은 것:** Claude 부르는 곳을 함수 하나로 모으고, 설정 한 줄(`MBM_ENGINE=cli|api`)로 다섯 기능을 한꺼번에 바꿔요. 칩은 「API 키 사용 중」으로 보여 줘요. 바꾸기 전에 Claude Code 결과에 나오는 「API 로 했으면 얼마였을지」를 기능별로 쌓아 보면 비용을 숫자로 가늠할 수 있어요.
