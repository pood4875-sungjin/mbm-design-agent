매체 디자인 기준

Figma 컨시어지 보드의 실제 고객사 소재를 한 장씩 보고 기록한 관찰에서 뽑았다. 값마다 "몇 장 중 몇 장"이 붙는다 — 취향이 아니라 이미 나간 소재의 다수 선택이 기준이다. 원본 관찰 기록 core/design/*.json, 프로필 core/design.js. 자동 생성 렌더러는 이 프로필을 그대로 읽는다.

매체별 프로필

프로필 값이 "—"이면 관찰이 2장 미만이거나 과반이 없어 기준을 두지 않은 것이다. 그때 렌더러는 지면 비율로 판단하는 기본 문법(가로형 왼쪽 정렬·오른쪽 오브젝트 / 세로형 스택·하단 오브젝트·중앙 정렬)을 쓴다. 관찰을 더하려면 core/design/<매체>.json의 examples에 추가하고 node scripts/build-design.mjs.
