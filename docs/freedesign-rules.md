# 자유 디자인 규칙 (2026-11-05 사용자)

Claude 가 배경·타이포를 **자유롭게** 디자인한다. 매체 규정(글자 수·안전영역·색·폰트·로고)은 검수기가 따로 강제한다. 취향 규칙은 아래 둘뿐 — 그 외(그라데이션 글자·칩·글로우·장식·정렬·글꼴 섞기·색)는 전부 자유.

1. **양의 자간 금지** — `letter-spacing` 은 0 또는 음수만(한글 제목 −0.02~−0.04em 권장). 작은 글자를 띄워 쓰는 것(아이브로우 0.1em 등)이 가장 큰 AI 티.
2. **장평 금지** — `transform: scaleX/scaleY`, `font-stretch`, 좁은·넓은 변형 글꼴로 글자 폭을 바꾸지 않는다.

(11-05 1차 규칙 — 대문자 아이브로우·그라데이션 글자·칩·글로우·장식 금지 — 는 「디자인이 다채롭지 못하다」는 사용자 피드백으로 폐기.)
