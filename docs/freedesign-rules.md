# 자유 디자인 규칙 (2026-11-05 사용자)

Claude 가 배경·타이포를 **자유롭게** 디자인한다. 매체 규정(글자 수·안전영역·색·폰트·로고)은 검수기가 따로 강제한다. 1·2항은 취향 규칙(AI 티), 3·4항은 구조 규칙(취향이 아님 — 청사진 분포·시안 틀 검사기 근거). 그 외(그라데이션 글자·칩·글로우·장식·정렬·글꼴 섞기·색·배경)는 전부 자유.

1. **양의 자간 금지** — `letter-spacing` 은 0 또는 음수만(한글 제목 −0.02~−0.04em 권장). 작은 글자를 띄워 쓰는 것(아이브로우 0.1em 등)이 가장 큰 AI 티.
2. **장평 금지** — `transform: scaleX/scaleY`, `font-stretch`, 좁은·넓은 변형 글꼴로 글자 폭을 바꾸지 않는다.
3. **정보 블록은 한 규칙** — 날짜(date)·직무(detail)·안내(notice)는 한 「정보 블록」이다.
   - 블록 안 라벨(「모집기간」「모집직무」) 스타일은 하나 — 전부 뱃지 / 전부 볼드 라벨 / 전부 세로 구분선. 날짜는 뱃지인데 직무는 볼드 라벨이면 ✗ (11-05 사용자 그림: 한 블록에 규칙이 둘).
   - 라벨은 한 열: 라벨 폭이 같고(고정 폭), 값이 시작하는 x 가 같다.
   - 행 간격 ≥ 글자 크기의 0.6배(행이 붙어 보이면 ✗). 값은 라벨과 같은 기준선(vertical-align 으로 맞춘다).
   - 프롬프트의 정보 블록 프리셋 3종(뱃지형 2행 / 볼드 라벨형 2행 / 세로 구분선형 가로 1행) 중 하나를 통째로 쓰고 글자 크기만 규격에 맞춘다. 글꼴·색은 디자인에 맞게 바꿔도 되지만 구조는 유지.
4. **간격 기본 규칙** — 「너무 붙음(하한)」과 「너무 벙벙(상한)」 사이만 통과. em 은 두 요소 중 작은 글자 기준, 상한은 과거 통과 소재의 줄 간격 분포(core/template-norms.js `gap` 상위10% × 메인 px; 규격 분포가 없으면 전 규격 상위10% 들의 중앙값).
   - 서브→메인 ≥ 0.3em · 메인→정보 블록 ≥ 0.8em · 정보 블록 행 ≥ 0.6em · 모든 쌍 ≤ 분포 상한.
   - 글자 ↔ 키비주얼(누끼 주인공)·로고: 겹침 0, 거리 ≥ 메인 px 0.5배, 키비주얼은 규격 긴 변 10% 이하(그 이상 비면 글자·그림을 키운다).
   - 잘림·낱말 안 줄바꿈·규격 밖·안전영역 밖 0 (매체 규정 층).
   - 검증하지 않고 참고만 하는 분포(프롬프트에 규격별 수치로 들어간다): 왼쪽·위 여백, 메인 글자 크기(÷√면적), 서브/메인 비, 글자 덩어리 폭.
