# AD 매체 규격 접수 양식

> **2026-09-28 갱신.** 1~4번(매체 목록·규격·제약·필수/금지 문구)은 `[SK추진실] 광고소재제작가이드_260918.zip` + Figma 「컨시어지」 보드로 접수되어
> `core/media/*.json` → [`docs/media-rules.html`](media-rules.html) 에 정리됐다. **아직 비어 있는 건 5·6번과 아래 3가지다.**
>
> - 월 220건의 내역 — 캠페인 몇 건 × 매체 몇 개 × 규격 몇 종
> - 수정 3회의 유형 분포 (6번 표)
> - 고객사 브랜드 자료가 오는 형태 (가이드 PDF? 로고 파일만?)
>
> 그리고 media-rules.html 의 **「확인 필요」 항목**은 자료에 없어서 비워 둔 값이다 — 담당자 확인이 필요하다.

에이전트가 매체별 규정에 맞춰 소재를 만들려면 아래가 필요하다.
**모르는 칸은 비워 두고 "모름"이라고 적는다.** 추측값을 채우면 그 값이 규칙이 되어
잘못된 소재를 통과시킨다. 빈 칸은 검사에서 제외되므로 비워 두는 편이 안전하다.

## 2. 규격 (매체 × 소재 유형마다 한 줄)

| 매체 | 소재 유형 | 가로(px) | 세로(px) | 파일 형식 | 용량 상한 | 기본 제작 여부 |
|---|---|---|---|---|---|---|
| 예) 사람인 | 상단 배너 | 750 | 200 | jpg | 300KB | 필수 |
|  |  |  |  |  |  |  |

"기본 제작 여부" = 캠페인마다 항상 만드는 것(필수) / 요청 있을 때만(선택).
이 구분이 한 캠페인의 기본 생성 장 수를 정한다.

## 3. 제약 사항 (매체가 문서로 요구하는 것만)

| 매체 | 제약 | 값 | 위반하면 |
|---|---|---|---|
| 예) 링크드인 | 텍스트 면적 비율 | 20% 이하 | 노출 제한 |
| 예) 사람인 | 가장자리 여백 | 상하좌우 20px | 반려 |
|  |  |  |  |

자주 있는 제약: 텍스트 면적 비율 · 가장자리 여백(안전영역) · 최소 글자 크기 ·
로고 최소 크기 · 제목 줄 수 · 필수 고지 문구 · 금지 표현 · 애니메이션 길이(GIF)

| 매체 | 구분 | 내용 | 근거 |
|---|---|---|---|
|  | 필수 / 금지 |  |  |

> 채용 광고는 차별 금지 규정(성별·연령 등 제한 표현)이 걸린다.
