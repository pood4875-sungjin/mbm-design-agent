# 잘 읽히는 공고 문장 형식 (메세지 작성 초기화면)

첫 화면에 적은 문장은 규칙 파서(`core/brief.js` `extractRecruit`)가 읽어 **고객사 · 채용 구분 · 접수 시작 · 지원 마감(시각) · 모집 직무 · 시즌**을 칸에 채웁니다.
LLM 추측이 아니라 적힌 글자만 읽으므로, 아래 순서와 라벨을 지키면 빠짐없이 읽힙니다. 읽은 값은 칸에 점선으로 보이니 틀린 건 바로 고쳐 쓰면 됩니다.

## 한 줄 공식

```
[시즌] 고객사 채용구분 채용. 접수시작 ~ 마감 [시각]. 모집분야: 직무1, 직무2
```

| 자리 | 쓰는 법 | 예 |
|---|---|---|
| 시즌(선택) | 문장 맨 앞. `2026년` · `2026년 하반기` · `2026 상반기` | `2026년 하반기` |
| 고객사 | 시즌 바로 뒤, **첫 명사구**. 띄어쓰기 없이 한 덩어리. `주식회사`·`(주)`·`㈜`는 앞뒤 어디든 붙여도 이름에 들어감. 두 회사는 `&`로 잇기 | `현대오일터미널 주식회사` · `한미글로벌&터너앤타운젠드코리아` |
| 채용 구분 | 고객사 뒤 ~ `채용` 앞 구절 전부. 회차·직군 표기도 여기 | `신입 공채` · `전문연구요원 채용` · `2026-6 일반직 직원 채용` |
| 기간 | `시작 ~ 마감` (`~` `-` `부터…까지` 다 됨). 날짜는 `2026.10.27` · `2026년 10월 27일` · `10/27` 어느 꼴이든. 요일 괄호 `(화)`, 시각 `13:00`·`17시`는 날짜 뒤에 | `2026.10.27(화) ~ 11.9(월) 13:00까지` |
| 모집 직무 | `모집분야:` `모집부문:` `모집직무:` 라벨 뒤에 쉼표로 나열. 마침표(`.`)나 줄바꿈까지 읽음 | `모집분야: 전산, 안전/보건` |
| 매체(선택) | 문장 끝에 쉼표로 | `잡다, 카카오 비즈보드, 자소설닷컴` |

## 예문 5개 (전부 읽힘)

1. `피에스케이 2026년 전문연구요원 채용. 2026년 10월 27일 00:00~2026년 12월 31일 23:50. 모집분야: 전장설계, 공정개발, 기구설계`
   → 고객사 피에스케이 / 시즌 2026년 / 채용 구분 전문연구요원 채용 / 접수 10-27 ~ 마감 12-31 23:50 / 직무 전장설계, 공정개발, 기구설계
2. `2026년 하반기 한미글로벌&터너앤타운젠드코리아 신입채용 2026.10.26(월)-11.8(일). 모집부문: PM 건설 사업 관리. 잡다, 카카오 비즈보드, 자소설닷컴, 구글`
   → 고객사 한미글로벌&터너앤타운젠드코리아 / 시즌 2026년 하반기 / 채용 구분 신입 / 10-26 ~ 11-08 / 직무 PM 건설 사업 관리 / 매체 4곳
3. `인천국제공항보안 2026-6 일반직 직원 채용 공고` ⏎ `2026.10.27(화) ~ 11.9(월) 13:00까지` ⏎ `모집분야: 전산, 안전/보건`
   → 고객사 인천국제공항보안 / 채용 구분 2026-6 일반직 직원 채용 / 10-27 ~ 11-09 13:00 / 직무 전산, 안전/보건 (줄바꿈해도 됨)
4. `2026년 하반기 현대오일터미널 주식회사 생산전문직 채용 2026.10.28(수) ~ 2026.11.08(일) 모집부문 생산전문직`
   → 고객사 현대오일터미널 주식회사 / 시즌 2026년 하반기 / 채용 구분 생산전문직 채용 / 10-28 ~ 11-08 / 직무 생산전문직
5. `GS에너지 2025년 신입 공채. 접수 6.20(금)~7.2(수) 17시. 모집분야 일반(사업, 재무 등), 보훈(사업/경영지원). 자소설닷컴, 인스타그램, 블라인드.`
   → 고객사 GS에너지 / 시즌 2025년 / 채용 구분 신입 공채 / 06-20 ~ 07-02 17:00 / 직무 일반(사업, 재무 등), 보훈(사업/경영지원)

## 이렇게 쓰면 못 읽습니다

- **고객사를 뒤에** — `전문연구요원 채용 피에스케이`처럼 채용 구분 뒤에 오면 회사로 안 읽힘. 맨 앞(시즌 뒤)에.
- **고객사 이름을 띄어쓰기** — `인천 국제공항 보안`은 「인천」이 지역으로 읽힘. 붙여서 `인천국제공항보안`.
- **날짜만 둘, 기호 없음** — `11월 1일 시작 11월 30일 종료`는 어느 게 마감인지 고르지 않음. `11월 1일 ~ 11월 30일` 또는 `11월 30일까지`.
- **직무 라벨 없이 나열만** — `전산, 안전/보건`만 있으면 직무로 안 읽힘. `모집분야:`를 앞에.
- **마감이 공고마다 다를 때** — 날짜 대신 `* 채용 일정은 공고별 상이`라고 적으면 그 문구가 날짜 자리에 들어감.
- **짧은 수식어만** — `백엔드 개발자 채용`처럼 회사 없이 적으면 고객사 칸이 비고, 시작하면 물어봄(추측하지 않음).
