## ① 정렬 ↔ 비주얼 위치
### 관찰
| 형태 | 정렬 | 비주얼 | 로고 |
|---|---|---|---|
| 가로형(580·970) | 9묶음 전부 왼쪽 | 오른쪽(칸 또는 전면 + 왼쪽 녹임) | 오른쪽 위 |
| 세로형(300×600·1050), 왼쪽 정렬 | 왼쪽 | 아래. 전폭이거나 오른쪽으로 치우침(중심 x 69%, 오른쪽 6% 넘침) | 왼쪽 위 또는 가운데 위 |
| 세로형, 가운데 정렬 | 가운데 | 아래 전폭(중심 x 49~50%) | 가운데 위 또는 아래 가운데 |

- 가로형에서 가운데·오른쪽 정렬 변형은 이 페이지에 없다. 가로형의 ①은 「정렬」보다 「비주얼 칸 폭」 변형이다.
  - 칸형: 사진이 x 23%부터 시작, 지면색 녹임이 x 18%→100% 구간
  - 전면형: 사진이 왼쪽 밖(−26%)부터 깔리고, 녹임이 0→99% 구간
  - 글자 블록은 한 픽셀도 안 움직인다(시작 x 28 = 4.8%, 폭 66%).
- 세로형의 정렬 변형은 비주얼을 옮기지 않는다. 아래 칸(y 62%부터, 위 녹임 72px = 높이 12%)은 그대로 두고 글자·알약·로고만 정렬을 따른다.
  - 가운데 → 왼쪽: 메인이 2줄로 줄고, 회사명이 머리 줄로 빠졌다.
- 왼쪽 정렬일 때 세로형 비주얼을 아래 오른쪽으로 밀어 대각 균형을 맞춘 사례가 1건 있다(D).

### 비주얼 처리
- **누끼**: 그대로 둔다(E는 파일·좌표가 같다). 지면이 흰 카드라 녹임도 필요 없다.
  - H는 같은 KV 계열의 밝은 지면용 다른 파일을 썼다. 크기를 키웠고(580에서 면적 1.4배, 거의 전면), 글자와 닿는 두 변에 지면색 녹임을 2~3겹 겹쳤다(왼쪽 W의 51%, 아래 H의 35~43%).
- **사진**: 반전안에서 사진을 바꿨다(F·G 둘 다).
  - F: 무채 거실 → 따뜻한 침실. 칸이 좁아졌다(580에서 폭 463 → 338, 시작 x 30% → 56%).
  - G 300×600: 빌딩 사진 → 인물 누끼.
  - 같은 사진의 톤·채도만 조정한 사례는 없다(이미지 필터 0건). 「이미지면 톤 검수」 = 밝은 지면에 맞는 밝은 사진이 있는지 보는 일이다.
- 녹임: 밝은 지면도 지면색 100% → 0% 선형이다. 정지점은 어두운 시안보다 앞(100%@12%, 75%@61%, 50%@73%, 0%@100%)이고 구간이 길다.
- **로고**: 단색(마스크) 로고는 흰색 → 메인 글자색(딥)으로 바뀐다. 원색 로고는 그대로 둔다.

## 공통: 세 변형이 지키는 것
- **메인 크기**는 같다(580: 48 → 48, 41~44 범위). 줄어든 건 정보가 늘거나 칸이 좁아질 때뿐이다(F 50 → 42, −16%. E 세로형 36 → 32, −11%). 서브·상세 크기 위계(메인의 0.4~0.6)는 유지된다.
- **왼쪽 여백·안전영역**은 같다(±3px). 카드형 반전(E)만 카드 안쪽 여백만큼(13px) 밀린다.
- **정보 블록 구성**(머리 → 메인 → 날짜 → 라벨·값 → 로고)과 순서는 같다. 태그 변형은 같은 정보를 라벨/값으로 쪼갤 뿐 더하거나 빼지 않는다.
- **로고 자리**: 정렬 변형 때만 움직인다.
- **글꼴**: 같은 문구 대안끼리는 바꾸지 않았다. 회차가 바뀌면 바뀐다.

## 결정(11-09 확정 — 총괄, 피그마 근거) · 구현 위치
1. **반전 지면 기준**: 누끼·그림 없음 = L* ≥ 98, 흰색에 브랜드 주색 ≤ 3%. 바탕 있는 그림(사진·일러스트) = 이음 쪽 변 색을 흰색으로 풀어 L* 92~95(이미 L* ≥ 92 면 그 색 그대로).
   글자 = 브랜드 딥(L* 5~20, 지면 대비 ≥ 7:1), 서브·날짜도 같은 딥. 강조어 = 브랜드 주색(지면 대비 ≥ 3:1, 못 넘으면 딥). 단색 로고는 딥으로 칠함(원색 로고 그대로). 알약·태그는 반전(fgIsDark).
   → `core/field.js` `LIGHT_FIELD`·`lightFieldOf`·`brandInk` · `core/editlayout.js` `bgFill: 'light'` · `core/renderers/ad.js` `lightInk`(글자·강조어·`mbm-ink-*` SVG 필터 로고).
2. **세로형은 정렬을 바꿔도 비주얼 아래 칸 유지**(시안 슬롯 A 에서만 `kvPlace: 'bottom'` 을 같이 준다 — 기존 `textAlign`/`kvPlace` 프리셋 뜻은 그대로). 가로형 A = 비주얼 칸형 ↔ 전면 녹임 또는 좌우 거울(기본안과 다른 쪽).
   → `core/variants.js` `slotPresets('A')`. 틀 규격 오른쪽 정렬은 그림·로고 칸과 **글자 열도** 거울(`templateMold.alignMirrorColumn`), 폭 전체 글자 칸을 왼쪽·오른쪽 정렬로 바꾸면 여백 W 6%.
3. **라벨 태그 모양 옵션**: 각진(반지름 = 높이 × 0.12) / 알약. 날짜는 알약, 라벨은 각진이 기본. → `infoTag: 'date'|'label'|'both'` · `tagShape: 'pill'|'square'`(`core/editlayout.js` `INFO_TAG`·`infoTagOf`). 기본안의 「날짜·라벨은 알약을 두르지 않는다」는 그대로.
4. **밝은 지면에 안 맞는 사진**(이음 쪽 상대 휘도 < 0.55 또는 딥 대비 < 7)은 C 슬롯을 빼고 A 의 다른 변형 → B 의 다른 태그 구성 → 시안 틀·기존 프리셋 순으로 채운다. 사유는 `edit.ignored` 「bgFill(밝은 지면 — 이음 쪽 밝기 0.27 < 0.55 …)」와 안 `trace.substitute`·`stats.slots` 에.

## 추가 기준(11-09 사용자 피드백)
- **가운데 정렬의 키비주얼은 유형별로**: 누끼·오브제 = 글자와 함께 가운데(틀 칸이 글자 줄과 겹치면 글자 아래 폭 전체 빈 띠 — 높이 ≥ 20% — 에 담음, `alignrule.js belowText`). 이미지(사진·바탕 있는 그림) = 지면 가득(cover) + 위→아래 브랜드 스크림(가로·정사각), 세로형은 아래 칸 폭 가득.
  오른쪽 정렬도 같은 원칙(누끼 = 따라감, 이미지 = 반대편 칸 거울). 애매하면 이미지 쪽.
- **글자만 옮기고 비주얼이 그대로인 정렬 안은 거른다**(`variants.js alignFollows`): 가운데인데 비주얼이 한쪽 칸, 오른쪽인데 비주얼이 오른쪽, 왼쪽인데 비주얼이 왼쪽 → 안에서 뺀다.
