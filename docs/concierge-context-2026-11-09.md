대시보드: 마케팅 에이전트 대시보드(노션, 링크 공개). 「개발 완료 항목」 15건은 이번 범위 밖. 아래 15건 = 컨시어지 요청 2 + 개발중 13.
사용자가 함께 준 11/04 기준 리스트업 요약도 대조함.

## A. 컨시어지 요청 (확인요청)
1. **[공통] SVG 파일 내 이미지 전체 화질 개선 필요** (오류·상, 박진화) — SVG 로 내보내면 파일 속 이미지 화질 저하. EX1 자소설 PC스탠다드 PC메인배너 2400×560(일러스트 과학자), EX2 AhnLab 아이소 일러스트(생성 파일 흐림 vs 피그마에서 같은 이미지로 바꾼 것 선명). 제안: 개선이 어렵다면 담당자가 알 수 있게 사전 가이드 고지.
2. **[공통] 피그마 연동/사이트 내부 편집 기능** (희망·중) — 현재 SVG 추출 → 피그마 불러오기. 희망: 웹 → 피그마 생성 자동화(생성과 동시에 / 1차 편집 후 연동), 또는 사이트 내부 자체 편집 = 사이트 피그마화.

## B. 개발중 항목
3. **[자소설] 규정 미준수 소재 검수 승인 오류** (반영중) — 규정 벗어난 소재가 승인 통과. EX1 PC메인배너, EX2 PC채용공고배너(서브 2줄/메인 4줄 기준으로 만드는 듯). 제안: PC채용공고배너는 문구 구성별 레이아웃 가이드 6종 학습.
4. **[메시지 작성] 초기화면** (반영중, 11/03 예시 추가) — 메시지에서 고객사·채용구분·지원마감·접수시작이 빠지는 경우. 예: 피에스케이(4항목 안 됨), 인천국제공항보안(고객사), 현대오일터미널(고객사). 11/03 추가: 「[대구경북첨단의료산업진흥재단] - 채용명 MEDILINK 아카데미 5기 교육생 모집 - 공고 진행 일자 … 2026.11.06.(금) ~ 12.17.(목) 자정까지 - 공고 모집 직무 : 의료기기 설계 / 의료기기 인허가(RA)」 → 고객사·지원마감·접수시작 자동입력 안 됨.
5. **[공통] 문구 오류** (보완필요, 11/03 추가) — 10/28분(띄어쓰기 없는 긴 기업명 생략, 자소설 160×600 글자수 구간, 메인 「채용」 자동 제거 희망)은 11-02 처리. **11/03 추가: 시즌 미작성 시 「예: 2026 하반기」 예시가 소재에 자동 입력됨**(자소설 160×600·1200×280 「2026 하반기」).
6. **[추가 희망] 파일명 수정** (보완필요) — (기업명)_(매체)_상품명(상품 내 배너이름/사이즈규격). 이미지 4장(현재 적용/다운로드 파일명/사람 제작 예시).
7. **[카카오] PC디스플레이 폰트 규정** (보완필요) — 카카오 전체가 Pretendard 고정인데 PC디스플레이는 폰트 고정 규정 없음.
8. **[카카오] 비즈보드 규격 사이즈 변경** (반영중) — 1029×258 → 960×300(= NAP DSP 비즈보드). 4유형: 오브젝트형 좌/우 × 메인 1줄/2줄, 썸네일형 좌/우 × 메인 1줄/2줄. 카카오 비즈니스 제작 가이드 링크.
9. **[공통] 선택한 소재만 추출** (반영중) — 복수 선택 → zip/svg. 「선택하기」 버튼(우상단), 드래그 = 선택(피그마식 다중 선택), 매체 그룹 전체/개별 선택(매체 추가 패널 형식, 생성된 소재만 활성).
10. **[공통] 브랜드컬러 외 폰트 색상 지정** (반영중) — 리멤버·카카오 등 폰트색 지정 매체 외에는 주·보조·포인트 외 글자색 설정. 지금 흰/회/검 3가지 자동이라 2차 수정 필요.
11. **[공통] 색상 스타일 설정** (반영중) — 배경이 주색 그라데이션 고정, 단색 불가, 보조색 변경해도 변화 없음. 제안: 단색/그라데이션 분리·직접 선택(1차는 AI 추출 색).
12. **[자소설] PC메인배너 서브문구 폰트스타일 SVG 오류** (보완필요, 11/03 추가) — SVG 에서 서브가 Regular(사이트는 Medium). **11/03 추가: ① 문구 색상이 다른 소재와 통일 안 됨(자동 설정 기준) ② 브리프(전체 일괄)의 채용구분(「MEDILINK 아카데미 5기 교육생 모집」)이 PC메인배너(1200×280)에만 안 들어가고 「대구경북첨단의료산업진흥재단 채용」 + 「2026 하반기」로 나옴.**

14. **[추가 희망] 사이트 내 용량 수정** (반영중) — 용량 초과로 검수 미통과 → 사이트에서 용량 낮추기.
