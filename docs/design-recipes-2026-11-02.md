## 구현 상태
레시피 R1~R3 안은 폐기했다. 제가 만든 유형 대신 피그마 시안을 틀로 탑재하는 방식으로 교체(`core/templates-data.js`, `core/renderers/ad-template.js`). 아래 제안은 분석 기록으로 남긴다. 기록: [history](../history/2026-11-02_시안틀_탑재.md)

## 제안: 시안 레시피 6개
레시피 = 쓰임 + 글자 구조 + 정보 표현. 키비주얼 유형에 맞는 것 중 1~3개만 낸다.

| 레시피 | 구성 | 잘 맞는 키비주얼 | 지금 렌더러 |
|---|---|---|---|
| R1 정보형 | V2 + 작은 문구·큰 제목 + 라벨 알약·값 | 누끼, 일러스트 | 라벨 알약 추가 |
| R2 임팩트형 | V1 + 기업명 굵게·채용구분 가늘게 + 날짜 한 줄 | 빈 면 있는 사진 | 굵기 대비 추가 |
| R3 강조형 | V2 + 핵심어 색 강조 + 날짜 알약 | 누끼, 일러스트 | 날짜 알약 추가, 색 강조는 일부 있음 |
| R4 녹임형 | V3 + 큰 제목 + 세로 막대 날짜 | 건물·풍경 사진 | 막대 추가, 녹임 있음 |
| R5 카드형 | V2 + 큰 제목 + 유리 정보 카드 | 3D, 아이소메트릭 | 카드 추가 |
| R6 분할형 | V4 + 큰 제목 + 라벨·값 | 사진 | 자르기 추가 |

### 적용 범위
- 난이도 하(자소설·리멤버·카카오 비즈보드): 시안 1개, 레시피 미적용. 지금처럼 규정 검수만 한다.
- 틀에 가까운 잡다: 시안 1개.
- 나머지 자유 규격: 키비주얼 유형별 상위 3개까지. 겹침·잘림으로 걸러진 레시피는 내지 않는다.

### 바꿔야 할 기존 규칙
- `core/renderers/ad.js`의 「날짜·라벨은 알약을 두르지 않는다」: 자유 매체에서 날짜 알약이 16~22%라 레시피에서는 허용한다. 규정 매체는 그대로 둔다.
- `CANON.variants`: 규정 1 · 기본 3 · 자유 3 으로 변경 완료.
- `core/variants.js`: 기본안 다음에 레시피, 모자라면 기존 프리셋 후보.
