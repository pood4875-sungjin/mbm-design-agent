# 에브리타임 틀 전수조사 (2026-10-15)

에브리타임01 보드의 템플릿(마이다스 자리표시 프레임)과 고객사 프레임을 Figma에서 실측한 값. 「구멍 뚫린 틀」 — 글자 x·줄 y·크기·그림 칸만 고정. **굵기·색은 샘플이 갈려 틀에 넣지 않고 기존 가이드가 정한다**(검수 표 –). 배경·키비주얼 처리는 기존 가이드(커뮤니티 보드 투명 배경 필수 · 홈배너 단색만 등).
8규격 중 글자가 이미지 안에 있는 3규격만 틀. 나머지 5(커뮤니티 네이티브 288 · 홈 카드 프로필 160 · 공모전 카드 288 · 검색 키워드 288 · 데일리 메시지 120)는 글자가 이미지 밖 텍스트 필드라 틀 없음(보드 템플릿 프레임 1:655·658·765·766·767 모두 빈 프레임).
