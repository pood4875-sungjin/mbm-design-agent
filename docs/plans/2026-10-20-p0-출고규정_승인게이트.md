# P0 — 자소설·리멤버 출고 규정 완성 + 검사 승인 게이트 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 11월 100% 대체 대상(자소설닷컴 11규격 + 리멤버 8규격 = 등급 A)에 대해, 매체 규정이 전부 데이터·검사기에 들어가 있고(출고 체크리스트 한 장으로 증명), 검사를 통과한 소재만 승인·전달되게 한다.

**Architecture:** 규정은 데이터(`core/media/<id>.json`), 검사는 순수 함수(`core/lint.js`: 측정값 × 규칙 → block/warn/pass), 측정은 브라우저(`app/measure.js`), 게이트는 새 순수 함수(`core/gate.js`: 등급 × 규격 검사 × 디자인 검수 × 샘플 문구 → 차단/검수 필요/승인 가능/초안)이고 앱(`app/app.js`)은 게이트 결과대로 배지·승인·ZIP 을 분기한다. 출고 체크리스트는 데이터에서 생성(`scripts/ship-checklist.mjs` → `docs/ship-checklist.md`)해 「규정 항목 × 자동검사 코드 × 근거」가 한 표에 보이게 한다.

**Tech Stack:** 바닐라 JS ESM · `node --test` · 매체 JSON → `node scripts/build-media.mjs` → `core/media.js` · 규칙 장부 `ref/learned/rules.json` → `node scripts/rules-ledger.mjs --md` + `node scripts/build-rules.mjs` · 앱은 정적(`python3 scripts/serve.py 4794` 또는 launch.json `mbm-agent`)

**배경(지금 있는 것 — 다시 만들지 말 것):**
- `core/lint.js` `lintArtifact({ spec, medium, measure })` 가 이미 검사한다: 제출 치수(`submitSize` = w·h × exportScale 또는 exportW/H) · 포맷 · maxKB/minKB · 글자수·줄수(`textLimits` → `limitsByRole`, 매체 `textCounting`) · 잘림 · 글자색(`spec.textColors.main/sub` 있을 때만) · 필수 폰트(warn) · 숫자 safeArea · textHeightPx · 투명 배경. `level` = block/warn/pass.
- `app/measure.js` `measureArtifact(html, spec)` 가 측정값을 만든다(w·h·bytes·format·transparent·fontFamily·texts[{role,text,lines,fontPx,color,bbox}]·logo{bbox}).
- `app/app.js` `lintAds()`(1870행 근처) 가 `channel === 'ad'` 산출물마다 `a.lint` 를 채우고, `approveAll()`(2936행) 은 `lint.level === 'block'` 이 하나라도 있으면 승인을 막는다. `exportAdZip` 은 block 을 ZIP 에서 뺀다. 디자인 검수(`core/adcheck.js` → `a.design.warnings`)는 배지만.
- `core/adcheck.js` 경고 코드: `text-over-subject` `logo-covered` `hard-cut` `empty-band` `text-clipped` `chip-overflow` `low-res` `low-res-logo` `short-melt` `band-seam` `busy-under-text`.
- 자소설 JSON: `format ['png']`, `exportScale 2`(달력은 템플릿이 이미 2배 → `exportW 328`), `maxKB null`(어느 자료에도 없음 — needsReview 1항), `textLimits`(서브/메인/상세, 자소설 세는 법 `half-latin`), `logo.count`(0 = M스탠다드 메인·PC달력 로고 금지, 1 = 기본, 보드는 2개 허용), `textColors.rule` 「모든 문구 1가지 색」(달력 마감일만 예외), `background` 「강한 형광색·색 분할 불가」, 전달물 2규격 `asset.minW`(로고 500 · 이미지 720). 반려 사례 2(치수 자동 · 내용 수동).

```js
// core/gate.js — 승인 게이트(10-20 운영 모델 §4·§5): 등급 × 규격 검사(lint) × 디자인 검수(adcheck) × 샘플 문구 → 상태 하나.
//   blocked  규격 검사 차단(매체 규정 위반) — 승인·전달 불가, 고쳐야 함
//   pending  아직 검사 안 끝남
//   review   규정은 통과했지만 사람이 봐야 함(글자-주인공 겹침·로고 가림·글자 잘림·저해상도·칩 넘침·샘플 문구) — 사유를 적고 승인 가능
//   ready    등급 A·B 가 검사 다 통과 — 「통과분 승인」 묶음에 들어간다
//   draft    등급 C(자유 배치) 또는 등급 모름 — 디자이너 수정 전제. 개별 승인만
// 원칙: 확신 없으면 내보내지 않고 표시한다(광고는 틀린 걸 내보내는 비용이 더 크다).
export const REVIEW_CODES = new Set(['text-over-subject', 'logo-covered', 'text-clipped', 'low-res', 'low-res-logo', 'chip-overflow']);
export const STATE_LABEL = { blocked: '차단', pending: '검사 중', review: '검수 필요', ready: '승인 가능', draft: '초안' };

export function approvalGate({ grade, lint, design, samples = 0 }) {
  const reasons = [];
  if (lint?.level === 'block') { for (const i of lint.issues ?? []) if (i.level === 'block') reasons.push(`규정: ${i.msg ?? i.code}`); return { state: 'blocked', reasons }; }
  if (!lint) return { state: 'pending', reasons: ['규격 검사 전'] };
  const warns = (design?.warnings ?? []).filter(w => REVIEW_CODES.has(w.code));
  for (const w of warns) reasons.push(`디자인: ${w.msg ?? w.code}`);
  if (samples > 0) reasons.push(`샘플 문구 ${samples}곳 — 실제 정보로 바꿔야 함`);
  if (grade !== 'A' && grade !== 'B') return { state: 'draft', reasons: [grade === 'C' ? '자유 배치 — 디자이너 수정 전제' : '등급 없음', ...reasons] };
  if (reasons.length) return { state: 'review', reasons };
  return { state: 'ready', reasons: [] };
}
```
