# 2단계 레이아웃 선택 플로우 — 「여러 안 생성 → 선택 → 추출」 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 규정이 느슨한 매체(2·3단계)의 광고 규격마다 「쓸 수 있는 레이아웃 안」을 2~5개 자동으로 만들어 보여 주고, 사람이 규격별 또는 캠페인 일괄로 고르며, 선택안만 또는 전체 안을 ZIP 으로 내보낼 수 있게 한다. 어떤 안이 선택됐는지 로그로 쌓아 다음 기본안·템플릿 후보의 근거로 삼는다.

**Architecture:** 새 디자인을 지어내지 않는다 — 안(variant)은 이미 있는 편집 프리셋(`core/editlayout.js PRESETS`: 키비주얼 위치·크기·글자 정렬·배경·글자색 톤)의 **조합**이고, 각 조합을 실제로 렌더해 추적(trace)으로 걸러 「프리셋이 먹히고(ignored 없음) · 겹침 교정이 실패하지 않고 · 결과가 서로 다른」 것만 남긴다. 계산은 순수 함수 `core/variants.js`(node 테스트 가능), 생성 시점은 `core/generate.js generateArtifacts`, 저장은 `artifact.variants[] + artifact.variantSel`, **선택 = 그 안의 프리셋을 `artifact.overrides.style` 로 복사**(기존 렌더·게이트·내보내기 경로를 그대로 탄다). 규정 매체(자소설·리멤버·카카오 = `mediumRules.fonts.required`)는 안이 1개(변형 없음). 앱은 인스펙터에 「레이아웃 안」 썸네일 줄과 「이 안으로 전부」, 전체 내보내기에 「전체 안 포함」을 더한다.

**Tech Stack:** 바닐라 JS ESM · `node --test` · 매체 JSON 변경 없음 · 규칙 장부(`ref/learned/rules.json` → `node scripts/rules-ledger.mjs --md` · `node scripts/build-rules.mjs`) · 앱은 정적(`python3 scripts/serve.py 4794`)

**건드리지 않는 것:** `core/renderers/ad.js`·`core/field.js`·`core/kvtypes.js`(품질 검수 루프 에이전트가 워크트리에서 작업 중) · 매체 JSON · `core/lint.js`.

**배경(지금 있는 것):**
- 프리셋 7개(`PRESETS`: kvPlace auto/right/bottom/bg/left · kvSize auto/sm/md/lg · textAlign auto/left/center/right · textAnchor · bgFill auto/brand/kv/custom · bgGrad · scrim) + `style.textTone`(auto/dark/light, 10-19·10-20). `editOf(style)` 가 설정된 값만 뽑고, 렌더러는 `TR.edit = { presets, place: EP, ignored: [...] }` 에 무엇이 적용되고 무엇이 무시됐는지 남긴다(`EP.ok`, `ignored` 에 `textAlign(사유)` 등).
- 가용성 판정 `placeAvail(spec, opt, { gate, objectBox, cutout })`·`sizeAvail(...)`(core/editlayout.js 165행~) — `gate` 는 첫 렌더 trace 의 `TR.gate`(hasKv·template·transparent·logoOnly…). 정렬 잠금 `alignLockOf(spec)`(core/alignrule.js).

```js
// core/variants.js — 레이아웃 안(variant) 후보 만들기(10-20 2단계 플로우).
//   안 = 편집 프리셋(core/editlayout.js PRESETS + textTone)의 조합. 새 디자인을 지어내지 않는다.
//   후보를 순서대로 실제 렌더해(renderArtifact) 추적(trace)으로 거른다: ① 프리셋이 하나라도 무시되면(edit.ignored) ② 겹침 교정 실패(overlapFix.fail)
//   ③ 결과 그림이 이미 있는 안과 같으면(hash) 버린다. 첫 안은 늘 기본안(빈 style). 규정 매체(fonts.required)는 기본안 하나.
import { renderArtifact } from './contract.js';
import { adSpecEntries } from './adspecs.js';
import { CANON } from './canon.js';

// 우선순위 = 디자이너가 먼저 보여 줄 순서: 자리 바꾸기 → 정렬 → 크기 → 배경 → 톤 → 조합
export const CANDIDATE_ORDER = [
  {},
  { kvPlace: 'left' },
  { kvPlace: 'bottom' },
  { textAlign: 'center' },
  { kvPlace: 'bg' },
  { kvSize: 'lg' },
  { bgFill: 'brand' },
  { kvPlace: 'left', textAlign: 'center' },
  { kvPlace: 'bottom', textAlign: 'center' },
  { textAlign: 'right' },
  { kvSize: 'sm' },
  { textTone: 'light' },
  { textTone: 'dark' },
  { bgFill: 'brand', textAlign: 'center' },
];
const KV_KEYS = new Set(['kvPlace', 'kvSize']);

const traceOf = html => { const m = html?.match?.(/data-trace="([^"]*)"/); if (!m) return null; try { return JSON.parse(m[1].replace(/&quot;/g, '"').replace(/&amp;/g, '&')); } catch { return null; } };
// 그림 지문: data URL(수 MB)을 뺀 html 의 짧은 해시 — 같은 안인지 가르는 용도
export const htmlHash = html => { const s = String(html ?? '').replace(/data:[^'")]+/g, ''); let h = 2166136261; for (let i = 0; i < s.length; i++) { h ^= s.charCodeAt(i); h = Math.imul(h, 16777619); } return (h >>> 0).toString(16); };

export function variantCountFor(spec) {
  const V = CANON.variants ?? { regulated: 1, default: 3, free: 5 };
  if (!spec) return V.default;
  if (spec.mediumRules?.fonts?.required) return V.regulated;   // 자소설·리멤버·카카오 — 정답이 하나
  if (spec.grade === 'C') return V.free;
  return V.default;
}
const labelOf = (st, i) => {
  if (!Object.keys(st).length) return '기본안';
  const L = { kvPlace: { left: '키비주얼 왼쪽', bottom: '키비주얼 아래', bg: '전체 배경', right: '키비주얼 오른쪽' }, textAlign: { center: '가운데 정렬', right: '오른쪽 정렬', left: '왼쪽 정렬' }, kvSize: { lg: '키비주얼 크게', sm: '키비주얼 작게' }, bgFill: { brand: '브랜드색 지면' }, textTone: { light: '흰 글자', dark: '검은 글자' } };
  return Object.entries(st).map(([k, v]) => L[k]?.[v] ?? `${k} ${v}`).join(' · ');
};

// specId 하나의 안 목록. ctx/style 은 캠페인 값(산출물 overrides 는 이미 합쳐 넘긴다). opts 는 renderArtifact 로 그대로.
export function variantCandidates(specId, ctx, style, opts = {}) {
  const spec = adSpecEntries()[specId]; if (!spec) return [];
  const want = variantCountFor(spec);
  const V = CANON.variants ?? {};
  const out = []; const seen = new Set(); let rendered = 0;
  const hasKv = !!style?.keyVisual;
  for (const cand of CANDIDATE_ORDER) {
    if (out.length >= want || rendered >= (V.maxRender ?? 14)) break;
    if (!hasKv && Object.keys(cand).some(k => KV_KEYS.has(k))) continue;   // 그림 없는 캠페인엔 위치·크기 안이 뜻이 없다
    const st = { ...style, ...cand };
    let html; try { html = renderArtifact(specId, ctx, st, opts); rendered++; } catch { continue; }
    const tr = traceOf(html); if (!tr) continue;
    const ignored = (tr.edit?.ignored ?? []).filter(Boolean).map(String);
    if (Object.keys(cand).some(k => ignored.some(x => x.startsWith(k)))) continue;   // 프리셋이 안 먹은 안은 기본안과 같은 그림
    if (tr.edit?.place && tr.edit.place.ok === false && cand.kvPlace) continue;
    if (tr.rules?.includes('overlapFix.fail')) continue;
    const hash = htmlHash(html); if (seen.has(hash)) continue; seen.add(hash);
    out.push({ id: out.length, label: labelOf(cand, out.length), style: cand, hash, trace: { rules: tr.rules ?? [], edit: tr.edit ?? null, place: tr.place ? { mode: tr.place.mode, objectSide: tr.place.objectSide } : null } });
    if (want === 1) break;
  }
  return out;
}
```

export function variantStats(campaigns) {
  const bySpec = {}, campaignWide = {}; let total = 0;
  for (const c of campaigns) for (const e of c.log ?? []) {
    if (e.type !== 'variant_selected') continue; total++;
    const m = e.meta ?? {};
    if (m.all) { campaignWide[m.label] = (campaignWide[m.label] ?? 0) + 1; continue; }
    (bySpec[m.specId] ??= {})[m.label] = (bySpec[m.specId][m.label] ?? 0) + 1;
  }
  return { bySpec, campaignWide, total };
}
export function statsMarkdown(s) {
  const out = ['# 레이아웃 안 선택 집계\n', `> 선택 ${s.total}건 · 생성: \`node scripts/variant-stats.mjs\``, ''];

  return out.join('\n');
}
