# 2026-10-20 — 광고 소재 에이전트 운영 모델 재설계 (원론)

> 왜 다시 쓰나: 10-19 유관부서 회의 결정 「기준 명확·자유도 없는 소재부터 100% 대체, 순차 확대」. 그리고 「못 쓰는 디자인 결과물이 나오지 않게」.
> 참고 틀: 디자인 시스템 에이전트 문서(값 → 부품 → 자리·기준 → 검사 → 전달 / 선택 vs 적용 / 고정·제품·화면 등급 / 기록이 문법으로 돌아감 / 패턴 안·밖).
> 이 문서는 「있어야 할 것」과 「지금 있는 것」을 같은 말로 놓고, 그 거리를 11월 전 할 일로 바꾼다.

## 0. 한 줄

**에이전트의 일은 「예쁘게 만드는 것」이 아니라 「틀 안에서 고를 것을 고르고, 나머지는 규정대로 적용하고, 검사에 통과한 것만 내보내고, 못 하는 건 알아보고 넘기는 것」이다.**
못 쓰는 결과물은 세 군데서 나온다 — ① 입력이 틀렸거나(공고 정보·자산) ② 선택이 틀렸거나(키비주얼 유형·배치 경로) ③ 규정·검사를 안 거쳤거나. 적용(글자 크기·여백·색)은 이미 가장 많이 채워진 층이라 여기서 나는 오류는 적다.

## 1. 우리 에이전트를 다섯 층으로 다시 보기

| 층 | 디자인 시스템 문서의 말 | 우리 것 | 채워진 정도 |
|---|---|---|---|
| 값 | 토큰 | `core/canon.js`(디자인 가이드 수치) · 팔레트·글자색·폰트 · **매체 규정 수치**(크기·글자수·용량·여백) `core/media/*.json` | 디자인 값 ◎ · 매체 규정 △(포맷·용량·파일명 비어 있는 매체 다수) |
| 부품 | 컴포넌트 | 메인·서브·날짜·상세·칩·로고 칸·키비주얼 칸·띠·스크림 (`core/renderers/ad.js`) | ◎ |
| 자리 | 화면 틀(셸) | **틀(templateMold)** = 매체 템플릿 칸(자소설·리멤버·NAP·구글·블라인드…) / **자유 배치** = 디자인 가이드(kvtypes × 배치) | 틀 ◎(실측 완료) · 자유 ○ |
| 기준 | 결정표·카드 | 키비주얼 유형 판정(`kvtypes`) · 지면색 사다리(manual→kv-edge→kv-mood→kv-vivid→tint→brand) · 글자색·정렬·겹침 교정·끊김 녹임 | ○ — 대부분 「기본값」이고 사람이 고르는 자리는 색·정렬·글자색 셋 |

| 전달 | 포장 | PNG/JPG 배수 내보내기 · ZIP · SVG→피그마 · 전달물(원본 파일) | ○ — 매체별 파일 규정(이름·용량·색) 미적용 |
| 기록 | 선례집 | trace rules · 규칙 장부 226건 · history · `ref/learned/cases` | ◎ 쌓이는 구조는 있음 · **실제 요청 사례 0** |

위계도 같다: 자유 배치는 CANON 값만, 틀은 매체 JSON 값만 쓴다. 숫자가 렌더러에 박힌 곳이 아직 남아 있고(검색: 매직 넘버), 그곳은 값 하나 바꿔도 안 따라온다.

## 2. 선택과 적용을 가르기 — 어디서 「판단」이 일어나나

디자인 시스템 문서의 핵심: 판단(선택)은 앞에서 끝내고, 뒤 단계는 적용만 한다. 뒤에서 새 판단이 생기면 앞 단계 출력의 구멍이다.

광고 소재 한 건의 판단 지점은 생각보다 적다.

| 순서 | 판단 | 선택지 | 기준 | 지금 |
|---|---|---|---|---|
| ① 입력 확정 | 공고 정보 6(회사·직무·고용형태·기간·시즌·공고 타이틀) · 자산(키비주얼·로고) · 브랜드색 · 매체 목록 | 있음/없음/확인 필요 | **빈칸은 추측하지 않는다**(불변식) | 문장 파싱 + 손 편집. 컨시어지 요청 양식과 안 맞춰져 있음 |
| ② 키비주얼 유형 | 누끼 · 사진 · 바탕 일러스트 · 질감 · 로고만 | 투명도·가장자리·주인공 상자로 자동 판정 | **틀리면 그 뒤 전부 틀린다** → 사람 1클릭 확인이 맞다 | 자동 + `kvTypeOverride`(있으나 묻지 않음) |
| ③ 규격별 경로 | 틀 / 자유 / 로고만 / 전달물 | 매체 JSON 이 정함 | 사람이 고르지 않는다 | ◎ |
| ④ 지면색 | 손 지정 / 키비주얼에서 / 브랜드 | 사다리 기본값 + 인스펙터 | 제품 단위로 한 번 정하면 됨 | ○ |
| ⑤ 표현 프리셋 | 글자색 톤 · 정렬 · 키비주얼 크기 | 기본값 + 산출물별 | 자유 규격에서만 의미 | ○ (틀은 잠김) |
| 적용 | 글자 크기·줄바꿈·여백·녹임·겹침 교정·로고 칸 | — | 규칙대로 | ◎ |
| 검사 | 규정 + 디자인 검수 | 통과 / 실패 / 확인 필요 | 실패는 못 넘김 | △ |

**결론 1.** 11월 범위(틀 매체)에서 사람이 할 판단은 ①과 ② 둘뿐이다. 이 둘을 「묻는 화면」으로 만들면 나머지는 자동이다. 지금 앱은 ①을 인테이크·인스펙터에 흩어 두고 ②는 묻지 않는다.

**결론 2.** 자유 배치의 ⑤는 「디자이너 손」이 들어가는 구간이라 11월엔 범위 밖. 고도화를 멈춘다(회의 결정).

## 3. 규격 등급 — 「패턴 안 / 패턴 밖」을 매체 규격에 적용

디자인 시스템 문서는 「패턴 안은 에이전트가 끝까지, 패턴 밖은 자리만 그리고 넘긴다」. 우리 말로 옮기면 **규격마다 등급**이다.

| 등급 | 뜻 | 규격(추출 51 기준) | 에이전트가 끝까지 하나 | 승인 |
|---|---|---|---|---|
| **A 규정 틀** | 칸·글자·크기가 템플릿으로 고정, 선택 없음 | 자소설 7+전달물 2 · 리멤버 8 · 잡다 2 · 구글 4 · NAP 4 · 인스타 1 · 네이버 DA 1 · 블라인드 2 · 카카오 2 · 에브리타임 3 ≈ **36** | 예 | 검사 통과 = 승인 후보(사람은 훑어보기) |
| **B 로고·비주얼만** | 그림이 곧 소재 | 캐치 2 · 에브리타임 3 · 네이버 1 · 자소설 2 ≈ **8** | 예(입력 스펙만 맞으면) | 자동 |
| **C 자유 배치** | 디자인 가이드로 에이전트가 배치 | 블라인드 1 · 캐치 1 · 당근 1 · 에브리타임 2 · 카카오 1 · 네이버 1 ≈ **7** | **아니오 — 초안**. 디자이너 수정 전제, SVG 인계 | 디자이너 |

11월 100% 대상 = A 중 자소설·리멤버(17 + 전달물 2). 같은 A 라도 매체마다 샘플 대조가 끝난 정도가 다르다(자소설 6샘플 전수 · 리멤버 8 · NAP 4 · 구글 4 · 블라인드/네이버/인스타 사용자 수정본 1회). **등급은 데이터에 적는다**(`spec.grade`), 앱은 등급대로 승인 흐름을 바꾼다.

등급 C 의 원칙은 「끝까지 만들지 않는다」가 아니라 「**끝까지 만들되 자동 승인하지 않고, 디자이너가 고칠 것을 전제로 넘긴다**」. 지금은 A 와 C 가 같은 얼굴로 나와서 받는 쪽이 어느 걸 믿어도 되는지 모른다. 이게 「못 쓰는 결과물」 인상의 큰 원인이다.

## 4. 요청 한 건의 흐름 (운영 모델)

```
컨시어지 요청(고객사·매체·규격·공고·자산·납기)
  │  ① 입력 확정 — 양식 그대로 받아 빈칸만 묻는다. 자산은 입력 스펙 판정(해상도·누끼·로고 폭) → 미달이면 「받을 수 없음」을 바로 돌려준다
  ▼
② 키비주얼 유형 확인(1클릭) · 브랜드색 확인
  ▼
③ 규격 등급 분기 ── A 틀 ─────────┐    ── B 로고·비주얼만 ──┐    ── C 자유 ───┐
  ▼                              ▼                       ▼                ▼
조립(적용만): 틀 칸 + 규칙        원본 그대로/칸 맞춤      가이드 배치(초안)
  ▼
검사 ── 규정(크기·용량·포맷·글자수·필수/금지 요소·반려 사례) + 디자인(겹침·끊김·로고 가림·빈 띠·대비)
  │      실패 → 자동 교정 사다리(겹침·끊김·줄 수) → 그래도 실패면 「검수 필요」
  ▼
승인 ── A·B: 통과분은 승인 후보 묶음으로(사람 훑기 1회) · C: 디자이너 작업 큐(SVG)
  ▼
전달 ── 매체 파일 규정(포맷·용량·파일명·색) 적용 · ZIP · 전달물은 원본 바이트
  ▼
기록 ── 사례 1건 = 요청·입력·등급·검사 결과·사람이 고친 것·매체 반려 여부
        └→ 주 1회: 「사람이 고친 것」 = 문법에 없던 것 → 규칙/틀 갱신(사람 승인) → 규칙 장부
```

지금과 다른 점 네 가지.
1. **입력 스펙 미달은 생성 전에 반려**(지금은 생성하고 경고만).
2. **검사가 승인 게이트**(지금은 배지).
3. **등급별로 승인 흐름이 다름**(지금은 전부 같은 보드).
4. **사람이 고친 것을 사례로 저장**(지금은 피그마 수정본을 내가 실측해서 반영 — 수동).

## 5. 「못 쓰는 결과물」을 막는 원칙 (고정·제품·화면 등급의 우리 판)

| 등급 | 우리 것 | 요청에서 |
|---|---|---|
| 고정 | 매체 규정(크기·용량·글자수·금지 요소·폰트 규정·로고 규정) · 접근성 최소 대비 · 비영리 폰트 금지 | 바꾸지 않는다. 어기면 **내보내기 자체를 막는다**(불변식 ⑥ 조용히 못 넘김) |
| 제품 단위 | 글자색 기본(#333/#fff·서브 70%) · 지면색 사다리 · 녹임·블리드 방식 · 공고 문구 사다리 | 한 소재만 바꾸지 않는다. 바꾸려면 규칙 장부(사람 승인) |
| 소재 단위 | 글자색 톤 · 정렬 · 키비주얼 크기 · 색 손 지정 · 문구 손 편집 | 그냥 바꾼다. 기록만 |

그리고 디자인 시스템 문서와 **다른 원칙 하나**: 그쪽은 「어떤 요청이든 화면은 만든다」지만, 광고는 틀린 소재를 내보내는 비용(매체 반려·고객 클레임)이 안 만드는 비용보다 크다. 그래서 우리는 **「확신 없으면 내보내지 않고 표시한다」**. 등급 C 와 검사 실패분은 자동 승인 후보에 들어가지 않는다.

## 6. 11월 전에 준비할 것 (우선순위)

### P0 — 없으면 100% 대체가 성립 안 함
1. **등급 A 19규격(자소설·리멤버) 규정 데이터 완성** — 파일 포맷·용량·색공간·파일명·글자수·필수/금지 요소. 지금 `file/format` 이 비어 있다. 보드·PDF 재추출 + 컨시어지 확인. 출고 체크리스트 한 장(규정 항목 × 자동검사 여부 × 근거).
2. **검사 → 승인 게이트** — 규정 검사 실패·입력 스펙 미달은 내보내기 차단, 디자인 검수 실패는 「검수 필요」 배지 + 자동 승인 후보 제외. 이미 있는 adcheck·반려 사례 자동검사 8건을 여기 연결.
3. **컨시어지 요청 양식 → 인테이크** — 실제 요청이 어떤 모양으로 오는지(표? 메신저? 메일?) 받아서 그대로 붙여 넣으면 공고 필드가 채워지게. 양식이 없으면 우리가 양식을 준다(고객사·매체·규격·공고 6필드·자산 링크·납기).
4. **키비주얼 유형 1클릭 확인** — 자동 판정을 보여 주고 「누끼/사진/일러스트」 중 고르게. 틀리면 전부 틀리는 유일한 선택.

### P1 — 돌리면서 필요해지는 것
5. **사례 저장** — 승인·수정·반려 결과를 `ref/learned/cases` 형식으로 앱에서 바로 내보내기(지금은 내가 손으로 만든다). 주간 리뷰의 입력.
6. **지표** — 규격 등급별: 생성 건수 · 검사 통과율 · 사람 수정 0건 비율 · 매체 반려 0건 비율 · 확인 필요 수. 과제 KPI1(85%+예외 분류)과 같은 분모.
7. **등급 태그와 보드 표시** — `spec.grade` + 보드에서 A/B/C 묶음, C 는 「초안 · 디자이너 수정 전제」가 보이게.
8. **전달 규정 적용** — 파일명 규칙·용량 압축·색공간. 전달물(자소설 M시작배너)은 원본 그대로 + 미달 반려.

### P2 — 11월 이후
9. 자유 배치(C) 고도화 재개 — 단, 사례가 쌓인 뒤. 지금 정렬·겹침 교정·녹임은 기반으로 두고 멈춘다.
10. 선례 검색 — 「같은 고객사 지난 소재」를 먼저 꺼내 재사용(검색 플로우는 있음).

### 하지 않을 것
- 새 매체 추가 · 자유 레이아웃 변형 · 키비주얼 AI 생성. 회의 결정과 맞지 않는다.

## 7. 어떻게 알 수 있나 (성숙도)

디자인 시스템 문서의 숫자를 그대로 쓴다: **패턴 안에서 끝난 비율 · 요청당 확인 필요 수 · 문법에 없던 것 횟수**. 우리 말로는 등급 A 자동 승인 비율 · 요청당 빈칸 질문 수 · 주간 「사람이 고친 것」 건수. 처음엔 낮고 사례가 쌓이면 오른다. 11월 4주 뒤 이 세 숫자가 곧 12월 확대 범위를 정한다.

## 8. 결정해 달라는 것

1. 등급 A 의 승인 = 「검사 통과분을 사람이 묶음으로 훑고 승인」 vs 「완전 자동 승인」. 첫 달은 전자를 권함.
2. 컨시어지 요청 양식 — 우리가 양식을 제안할지, 그쪽 기존 양식을 받을지. 이번 주 미팅 안건.
3. 키비주얼 유형 확인을 **매 요청** 묻을지, 자동 판정 신뢰도가 낮을 때만 물을지. 첫 달은 매번.
4. 등급 C(자유 7규격)를 11월 테스트베드 요청에서 **아예 제외**할지, 초안으로 같이 낼지.
