### 흐름 한 장
```
근거 ─────────────▶ 규칙 장부 ──────────▶ 코드 층 ─────────────▶ 테스트·전수 렌더 ──▶ 검수
· 매체 공식 가이드      history/규칙장부.md   core/media/*.json        npm test              자동(adcheck·lint)

· 사용자 피드백·노션     (근거 1건도 일단 넣음)  core/renderers/ad.js      이전 라운드와 비교      ↺ 깨진 곳 → 다시 근거
                                             시안 틀 mold · core/variants.js
```
- 규칙이 생기는 순서는 「케이스 테스트 → 깨진 곳 발견 → 원인 가르기(규칙 탓 / 그림 탓 / 오탐) → 규칙 고침 → 전 케이스 다시 돌려 회귀 확인 → 테스트 추가 → 장부에 한 줄」이에요(history/규칙장부.md 3절).
- 근거가 1건이어도 일단 넣어요. 다른 케이스와 부딪히면 조정하고, 안 풀리면 그 규칙만 되돌리고 기록해요(history/규칙장부.md 3절).

장부를 둘로 나누지 않고, 규칙마다 「층」과 「AI 쓰임」 두 칸을 붙여요(docs/ai-rule-layers.md).

11-10 에는 사용자와 이걸 세 층으로 다시 말했어요. **1 매체 공식 규정 · 2 최소 품질 = 검수 항목 · 3 디자인 완성도 = 생성 규칙**. 3층을 빼면 AI 자유 생성이에요. 비중 중 객관(주인공 겹침·가림·대비·로고 상한)은 2층, 거리·붙음·비어 보임은 3층(AI 참고)이에요(h/11-10_추가시안_Claude방향판단).

## 6. Claude 연결: API 키 → 로컬 claude CLI

### 왜 바꿨나
- 회사가 LLM API 키를 회수한다는 공지가 있었어요. 공개 앱은 AI 없이 핵심 동작만 하고, AI 층은 로컬 Claude Code 로 옮기는 안을 냈어요(h/11-09_컨시어지_재검수_피그마비교_수정5건).
- AI 디자인 트랙은 처음부터 「로컬 앱 + 회사 Claude 계정(claude CLI), API 금지」로 정했어요(h/11-10_추가시안3슬롯_…).
- 11-10 사용자: 「API 빼고 CLI 로 개인 Claude 계정 연결해서 그 플랜 토큰 안에서」(h/11-10_ClaudeCode연결_로컬앱).
- 결정: **지금은 로컬 앱 · 각자 계정 로그인. API 전환은 나중에.** 이유는 디자인 생성을 API 로 하면 토큰 비용을 가늠하기 어려워서예요(같은 기록, docs/local-ai-setup.md).

### 구조
```
브라우저 앱(app/) ──▶ 로컬 서버 server/server.mjs(4796) ──▶ claude -p (각자 로그인한 Claude 계정)
   「Claude 연결하기」 칩      /api/claude/status·login·ask
   app/claudelink.js          /api/kvjudge(그림 종류 + 추가 시안 방향)

                              /api/freedesign/jobs(자유 디자인)

```
| 스위치 | 기본 | 켜면 | 출처 |
|---|---|---|---|
| `FREEDESIGN_API=1` | 꺼짐 → 자유 디자인은 claude-code | API 엔진 허용 | `server/freedesign.js:187~188`, `server/server.mjs:72` |

### 앱 화면
- 위쪽 칩 하나: 연결 전 「Claude 연결하기」, 연결 뒤 「Claude 연결됨」. 누르면 세 단계(로컬 앱 · 설치 · 계정 연결) 창이 떠요. 「계정 연결」은 `claude auth login` 을 띄우고, `claude auth status` 로 확인해요(h/11-10_ClaudeCode연결_로컬앱).
- 설정의 API 키 입력·연결 테스트는 뺐어요(같은 기록).
- `MBM 시작.command` 를 더블클릭하면 서버가 켜지고 앱이 열려요(같은 기록).
- 공개 앱(github.io)에서는 연결이 안 되고 규칙으로만 돌아요(docs/local-ai-setup.md).
