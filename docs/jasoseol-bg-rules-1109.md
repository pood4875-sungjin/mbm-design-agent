## 공통 원칙
1. **지면은 한 장으로.** 규격 전체를 단톤(브랜드 주색) 또는 그라데이션으로 칠한다. 이전 틀처럼 「그림 칸만 색 · 나머지 흰 지면」으로 나누지 않는다(PC메인 포함).
2. **글자색은 지면 밝기로.** 어둡거나 채도 높은 지면 → 흰 글자(#FFFFFF). 밝은 지면(#F1F1F1·#F4F4F4·#FFFFF7·#B5F1F7·#97B6D4·#FFFFFF) → 어두운 글자(#141414·#333333 또는 브랜드 진한 색 #42525B·#44217A·#004F9C).
3. **그라데이션 = 주색 → 같은 계열 변주색 2색 선형.** 변주는 밝게(#3B73C6→#B7D4FF, #1F529C→#467DCD, #FF0013→#FF606C), 어둡게(#9EE393→#62C652, #2D2F5F→#0D0E2C), 색상 이동(#3B73C6→#3D3BC6·#36C5E0, #6ECCEB→#69DACD).
   - 방향: 가로형 → 왼쪽→오른쪽 · 세로형 → 위→아래(또는 반전) · 팝업(가로 사각) → 대각 45°(왼쪽 위→오른쪽 아래).
4. **누끼**는 그림 칸에 그대로 얹는다(녹임 없음). 칸 밖으로 조금 넘쳐도 된다(PC메인 일러스트 높이 328/280, 행성 누끼는 왼쪽으로 잘려 나감).
5. **이미지(바탕 있는 그림)**는 그림 칸에 cover 로 깔고, **지면 쪽 가장자리만** 지면색으로 녹인다. 녹임 띠 정지점은 모두 같다: 지면색 0% → **80% @ 0.5(가로 0.54)** → 100%.
6. **그라데이션 지면 + 이미지**: 녹임 색 = 그라데이션의 **그림 쪽 끝 색**(주색). 그래서 그라데이션은 그림 쪽에서 주색으로 시작해 반대쪽으로 변한다(「그라를 넣으려면 이미지쪽 그라 끝과 동일해야 하고 반대로 그라가 올라가야 함」).
