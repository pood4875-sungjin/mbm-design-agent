# 겹침 교정 사다리 (overlapFix, 2026-10-19)

사용자: 「키비주얼과 텍스트가 겹쳐서 텍스트가 안 보일 땐 텍스트를 줄이던지 띄어쓰던지 키비주얼 위치를 조정해야 하는데, 그런 규칙도 가능할까?」

## 어떻게 재나
- `renderAd` 가 한 번 그린 뒤 추적(`TR.textBox`)의 **글자 행 상자**와 `data-object="1"` 상자에서 계산한 **실제 그림 사각형**(contain/cover/auto/px, cutFade 와 같은 식)을 비교한다.
- 글자 행: 자유 배치는 메인 줄마다(폭 = textWidth×크기×1.04) + 나머지 블록 한 덩어리, 세로 자리는 정렬(v)·가로는 align. 틀은 행 실측(top·pitch·줄 수), 상세는 「라벨 열 + 값 열(valueW 안에서 접힘)」 또는 「라벨 : 값」.
- 주인공: 열·행 투명 프로필(`kvMeta.field.cols/rows`)이 있는 누끼는 **불투명 칸만**(min(열,행) 불투명도 ≥ .3 → 1), 없으면 focus 상자(사진·일러스트). 글자 쪽 **녹인 구간(data-melt)** 은 지면으로 읽히니 뺀다.
- 겹침 = 교집합 ÷ 글자 행 면적, 행 중 최대. 문턱: 캐릭터·프로필 누끼 **2%**, 그 외 **15%**(검수 `check.textOverSubject` 와 같음).

## 사다리
| 배치 | 순서 |
|---|---|
| 자유 | ① 글자 0.92 → 0.84 → 0.75 ② 메인 두 줄(회사명 뒤, 없으면 폭 비슷한 어절) ③ 키비주얼 0.85 → 0.7(편집 「키비주얼 크기」와 같은 길: 오른쪽 열 폭·아래 띠 높이·모서리 상자·블리드 면적) |
| 틀(templateMold) | ① 칸 안 그림 축소 0.85 → 0.7(누끼는 그림만 `auto Npx`, 사진·바탕 그림은 칸을 우하단으로 축소) ② 글자 0.92 → 0.84 → 0.75(규정 매체 자소설·리멤버·카카오는 0.85 바닥) |

처음 문턱 아래로 내려오는 단계를 쓴다. 끝까지 안 되면 가장 덜 겹치는 것을 쓰고 `overlapFix.fail` 로 남긴다(검수가 그대로 보고).

## 흔적
- 루트 `data-overlap="전%>후%:단계"`(text·wrap·kv) · trace rules `overlapFix.ok|fail`, 단계마다 `overlapFix.text|wrap`.
- 내부 힌트 `style.__fix { textK, wrap, kvK }` — 저장하지 않는다. `__fix: {}` 는 사다리를 끄는 스위치(시트·테스트의 「전」).
- CANON.overlapFix · 규칙 장부 `text-kv-overlap-fix`.
