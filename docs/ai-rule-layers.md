# AI 생성(자유) 축 규칙 — 층 설계 (2026-11-10 초안)

사용자(11-10): 「규칙 기반 말고 자유 기반으로 Claude Code 디자인을 연결해서 기존 디자인 데이터와 가이드를 학습하고, 이외에는 자유롭게 생성할 수 있게 하는 축이 AI 생성. 그건 별도 규칙이 필요하고 룰베이스와 부딪히는 지점이 있어서 하위로 추가해 진행하고 싶다.」

**결론**: 장부를 둘로 나누지 않고, 한 장부(`ref/learned/rules.json`)의 규칙마다 **층(layer)** 과 **AI 쓰임(ai)** 두 칸을 붙인다. AI 전용 규칙은 같은 장부의 L3 층으로 들어온다(지금은 `docs/freedesign-rules.md` 에 따로 있음). 부딪힘은 「같은 걸 재는데 층이 다른 두 규칙」으로 드러나고, 트랙마다 이기는 순서가 정해져 있다.

## 1. 층 다섯
| 층 | 무엇 | 예 | 룰 트랙 | AI 트랙 |
|---|---|---|---|---|
| **L0 매체 규정** | 매체 공식 가이드·제작 규정. 출고 차단 | 글자 수·크기 범위·안전영역·금지색·로고 금지·비주얼만(당근) | 강제 | **강제**(block) |
| **L1 공통 원칙** | 어느 디자인이든 지켜야 하는 정보·가독·그림 보존 | 지어내지 않기, 연도 한 번, 라벨 두 개 금지, 날짜 버리지 않기, 대비, 주인공·로고 가림, 잘림, 낱말 안 줄바꿈, 흐림 | 강제 | **강제**(block 또는 fix) |
| **M 공용 측정** | 그림·로고를 재는 법(유형 판정·주인공 상자·로고 톤) | 누끼/사진/일러스트/질감, 주인공 상자, 로고 색 | 판단 입력 | **프롬프트 입력**(input) — 같은 측정값을 준다 |
| **L2 룰 레시피** | 룰 트랙의 수치·배치·틀(샘플 틀 실측 포함) | 녹임 30~55%, 누끼 오른쪽 열 70%, 굵기 위계, 틀 칸 위치, 태그 크기 | 강제 | **참고만**(hint) — 분포·예시로 주고 막지 않음 |
| **L3 AI 전용** | 자유 생성에서만 생기는 문제를 막는 규칙 | 양의 자간·장평 금지(AI 티), 정보 블록 한 규칙, 간격 하한·상한, 구성 다양성, 「세로 직선 단순 분할」 금지 | 해당 없음 | **강제**(block 또는 fix) |

AI 쓰임 5가지: `block`(어기면 1회 재요청 → 그래도면 반려, 카드에 안 오름) · `fix`(자동 고침 → 재측정, 남으면 block) · `input`(측정값을 프롬프트에) · `hint`(참고 수치·분포·예시) · `off`(AI 와 무관 — 내보내기·출고 운영).

### 트랙마다 이기는 순서
- **룰 트랙**: L0 › L1 › L2 (L3 는 적용 안 함 — 룰 트랙은 자간 양수 같은 걸 애초에 안 만든다)
- **AI 트랙**: L0 › L1 › L3 › L2(참고). **L2 는 AI 안을 절대 막지 않는다** — 이게 「가이드 이외에는 자유」의 정의.
- 사용자 지시는 L0 밑, 나머지 위(룰 장부 C2 결정과 같이 정함).

### 지금 장부 300줄(되돌림 제외)을 나눈 초안 — `node scripts/rule-layers.mjs`
| 층 | 규칙 | block | fix | input | hint | off |
|---|---|---|---|---|---|---|
| L0 | 20 | 15 | 0 | 0 | 0 | 5 |
| L1 | 34 | 22 | 11 | 0 | 0 | 1 |
| M | 42 | 0 | 0 | 41 | 0 | 1 |
| L2 | 204 | 0 | 0 | 0 | 197 | 7 |
| L3 | (장부 밖 — `docs/freedesign-rules.md` 4항 + AI 게이트 항목 약 10개) | | | | | |

- 기본은 묶음별(매체 규정 → L0, 자동 검사 → L1, 유형 판정·손질 → M, 나머지 → L2), 예외는 스크립트 `OVERRIDE`.
- 눈여겨볼 예외: **「매체 규정」 묶음 35줄 중 16줄은 공식이 아니라 샘플 틀·디자이너 실측**(자소설 굵기·구글 슬롯·카카오 틀 64:3325·구글 930 그림 칸…) → AI 에겐 L2 참고. 장부의 묶음 이름이 출처를 가리고 있었다(규칙장부 8절 출처 표와 같은 이야기).
- 반대로 묶음은 타이포·글자 색인데 **L1 로 올린 것**: 지어내지 않기·연도 한 번·라벨 두 개 금지·날짜 필수·회사명 유지·사진 위 글자 스크림·작은 흰 글자 굵기·낱말 안 줄바꿈 금지·흐림 상한.

## 2. 「학습」 — AI 가 무엇을 보고 배우나
| 재료 | 지금 | 층 설계 뒤 |
|---|---|---|
| 규칙 문장 | `docs/freedesign-rules.md` 전문 + 규격 규칙 요약을 손으로 프롬프트에 | 장부에서 **L0(그 규격)·L1·L3 문장을 자동으로** 뽑아 「반드시」 절, L2 는 「참고 수치」 절 — 장부를 고치면 프롬프트가 같이 바뀜 |
| 분포 | `core/template-norms.js` 간격·여백·글자 크기 분포(참고) | 그대로 + L2 hint 수치(녹임 길이·태그 크기·굵기 위계)를 규격별로 |
| 예시 | 없음(그림은 KV 만) | 피그마 통과 소재(홍보사업셀 8436:3892 · 자소설 시안 236:37xx · 타이포 시안 5묶음) 중 **같은 규격 × 같은 KV 유형** 2~3장을 축소 이미지로 — 「이 수준」의 기준 |
| 취향 | 셀렉 루프 5점(`free-prefs.json`, KV 유형별 소프트 랭킹) | 그대로 — 구성(전면·모티프·타이포·대각·카드·축) 고르는 순서에만 씀(막지 않음) |

### 되먹임(규칙이 자라는 길)
- **반려 사유 → L3 완화 후보**: 게이트 사유마다 규칙 id 를 붙여 통계. 한 L3 규칙이 반려의 대부분을 차지하고, 그 안을 사람이 「좋다」고 고르면 완화 후보(지금 4항 「글자–KV 거리 ≤ 긴 변 10%」가 그 예 — 결정 0-2 ③).
- **채택 패턴 → L2 승격 후보**: AI 안에서 자주 채택되는 구성·강조(예: 날짜 알약 + 브랜드 딥)를 룰 트랙 시안 슬롯으로 옮길지 장부에 「ai 출신」 표시로 올림.
- **L1 은 사람 결정으로만** 바뀐다(데이터로 자동 완화 안 함).

## 4. 데이터 모양
- `rules.json` 규칙에 두 칸: `"layer": "L0|L1|M|L2|L3"`, `"ai": "block|fix|input|hint|off"`. `scripts/rules-ledger.mjs` 검사에 두 칸 추가(없으면 경고 → 다 채운 뒤 필수).
- L3 규칙도 장부 한 줄씩: `ai-no-positive-tracking` · `ai-no-scale-glyph` · `ai-info-block-one-style` · `ai-gap-floor-ceiling` · `ai-kv-distance` · `ai-composition-varied` · `ai-no-plain-split` · `ai-logo-buried` · `ai-text-over-card` · `ai-deco-over-text`. `where` = server/freedesign.js·core/typoaudit.js 함수. `docs/freedesign-rules.md` 는 장부에서 만드는 사람용 문서로 바뀜.
- 게이트 사유에 규칙 id: `{ rule: 'year-once', layer: 'L1', msg }` — 앱 디자인 검수(guidecheck)와 같은 id 를 써서 「AI 안이 왜 빠졌나」가 장부 한 줄로 이어진다.
- 장부 검사기 새 경고: **같은 측정량에 L1/L3 문턱이 둘**(K5·K6 같은 중복)이면 알림.

## 5. 단계
1. **분류 확정**(이 문서 + `scripts/rule-layers.mjs` 초안을 사용자가 봄) → `rules.json` 에 두 칸 기록, L3 10줄 등록.
2. **L1 을 AI 게이트에**: K1~K4 — `copyOptions` 를 L1 로 거르고, date 필수, 흐림 상한. 회귀 = `scripts/freedesign-ai-replay.mjs`(반려 재생) + 루프 1회.
3. **프롬프트 자동 생성**: 장부 → 「반드시(L0·L1·L3) / 참고(L2 수치) / 예시(피그마 2~3장)」. `docs/freedesign-rules.md` 직접 읽기를 대체.
4. **사유 id·통계**: 게이트 사유에 id, `/api/freedesign/stats` 에 규칙별 반려 수 → 완화·승격 후보 표.
5. **룰 트랙 쪽 정리**: K7 결정 문장, 장부 묶음 이름과 층이 어긋나는 16줄 표시.

## 6. 정할 것
1. 층 다섯(L0·L1·M·L2·L3)과 「AI 트랙에서 L2 는 막지 않는다」 원칙 — 이대로?
2. L1 에 올린 34줄(초안) — 특히 「낱말 안 줄바꿈 금지」·「사진 위 글자 스크림 필수」를 AI 에도 강제할지(사진 위 글자를 스크림 없이 대비만 맞추는 자유 안을 막게 됨).
3. K9 글자–KV 거리 10% 를 L3 강제 → 참고로 내릴지.
4. K10 로고 시각 비중 상한을 L1 로 둘지.
5. 예시 이미지(피그마 통과 소재)를 프롬프트에 넣을지 — 넣으면 호출 시간 +, 수준은 올라갈 것(실측 필요). 고객사 이미지라 로컬에서만.
