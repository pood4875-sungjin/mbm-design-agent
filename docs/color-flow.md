# 색은 어디서 와서 어디에 쓰이나요

키비주얼과 로고에서 색을 뽑아, 배너의 지면·글자·뱃지에 쓰는 흐름이에요.
코드: `core/palette.js`(뽑기·자리 정하기) · `app/app.js`(올릴 때) · `core/field.js`(지면) · `core/renderers/ad.js`(글자).

## 한눈에

```
키비주얼 ─┐                     ┌─ 지면(배경)   ← 그림이 먼저, 없으면 브랜드색
          ├─ 색 3개 뽑기 ─ 세 자리 ─┼─ 글자색       ← 지면 밝기로 흰/검 자동
로고 ─────┘   (주색·보조·포인트)   └─ 뱃지·강조    ← 지면에서 옅게/진하게
```

## 1. 색 뽑기 — 그림마다 3개

- 키비주얼에서 넓게 쓰인 색 순서로 뽑아요. 회색·아주 밝은 색·아주 어두운 색은 바탕으로 보고 빼요.
- 비슷한 색은 하나만 남겨요. 같은 파랑이 1·2·3등을 다 가져가지 않게요.
- 로고에서도 똑같이 뽑아요. 검정·흰색 로고는 뽑을 색이 없어서 비어요.

## 2. 세 자리 정하기 — 주색 · 보조 · 포인트

| 올린 것 | 주색 | 보조 · 포인트 |
|---|---|---|
| 로고만 | 로고 | 로고 |
| 키비주얼만 | 키비주얼 | 키비주얼 |
| 둘 다(기본) | **키비주얼** | 키비주얼, 모자라면 로고 |
| 둘 다 + 로고 색을 눌렀을 때 | **로고** | 키비주얼 |
| 로고가 검정·흰색 | 키비주얼 | 키비주얼 |

- 기본은 **키비주얼 > 로고**예요(11-12 사용자 결정). 키비주얼 색을 넓은 순서대로 주색 · 보조 · 포인트에 채우고, 키비주얼 색이 모자란 자리만 로고 색이 채워요. 키비주얼과 거의 같은 로고 색은 안 끼워요.
- 입력 화면의 색 칩에서 로고 색을 누르면 주색이 로고로 바뀌어요(11-11까지의 기본).
- 조심할 것: 키비주얼이 사진이면 대표색이 살색 · 베이지로 나올 수 있어요. 그럴 땐 로고 색 칩을 눌러 주세요.
- 포인트는 남은 색 중 가장 쨍한 색이에요. 색이 모자라면 색상환을 돌리지 않고, 있는 색의 밝기·채도만 바꿔 만들어요. 그림에 없던 색이 끼어들지 않게요.
- 화사한 키비주얼이면 주색을 지면 색에 맞춰 한 번 더 고쳐요(로고가 주색일 때는 안 고쳐요).

## 3. 지면(배경) — 실제로는 그림이 먼저예요

주색이 로고여도, 배너 바탕은 아래 순서로 정해요. 위에서 먼저 걸리는 것을 써요.

1. 사람이 직접 고른 색·그라데이션
2. 색 자리를 손으로 고쳤으면 주색 → 보조색 그라데이션
3. 바탕 있는 일러스트 → 그림 가장자리 색(이음매가 안 보이게)
4. 분위기 있는 그림(누끼 원본 바탕, 어두운 사진) → 그 색
5. 사진·누끼 → 그림에서 뽑은 화사한 색(비주얼 우선)
6. 흰색 로고만 있으면 → 어두운 브랜드색
7. 그 밖 → 브랜드색

## 4. 다크 · 라이트 — 따로 저장하지 않고 그때그때 만들어요

| 이름 | 만드는 법 | 쓰는 곳 |
|---|---|---|
| 진한 브랜드(딥) | 흰 글자가 4.5:1 될 때까지 명도를 내림 | 어두운 지면 |
| 옅은 브랜드(틴트) | 브랜드색 78~82%를 흰색과 섞음 | 밝은 지면 · 밝은 사진 옆 |
| 브릿지 | 지면 끝을 그림 가장자리 색 쪽으로 당김 | 밝은 사진과 진한 지면 사이 |

## 5. 글자색 — 흰색 아니면 검정

- 글자는 **흰색이나 검정 둘 중 하나**예요. 중간 회색은 인쇄·메일에서 탁해져요.
- 색 있는 지면에는 흰 글자가 먼저예요. 흰 글자가 큰 글자 기준 3:1을 못 넘는 밝은 지면에서만 검정이에요.
- 그라데이션은 양 끝 모두에서 읽혀야 해요. 못 읽히면 그라데이션을 단색으로 접어요.
- 사람이 고를 수 있는 것: 글자 톤(다크/라이트), 글자별 색(메인·서브·상세), 메인 강조색. 강조색은 지면 대비 4.5:1을 넘을 때만 써요. 규정 있는 매체(자소설·리멤버·카카오 등)는 매체 규정을 따라요.
- 로고도 지면에 맞춰 원색 로고나 흰 로고를 골라요.

## 아직 없는 것

- **글자색 팔레트**: 키비주얼에서 「글자색」을 따로 뽑지는 않아요. 글자는 지면 밝기로 흰/검만 정해요.
- **다크·라이트 세트**: 이름 붙은 세트로 저장하지 않아요. 지면을 정할 때 딥·틴트를 그때그때 계산해요.
