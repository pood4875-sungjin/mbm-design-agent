AX 마케팅 디자인 에이전트 — 만든 방법과 노하우

공유용 · 2026-10-30 · 김성진

채용 정보 한 줄과 키비주얼 한 장을 넣으면 자소설닷컴·카카오·리멤버·에브리타임·구글 등 매체 규격에 맞춰 광고 소재를 한 번에 만들어 주는 에이전트입니다. 컨시어지 조직이 실제 캠페인에 쓰고 있고, 매주 월요일 정기 미팅에서 사용 현황을 보고 요청을 받아 고도화합니다.

원본 앱 /app/ · 홈페이지형 작업 화면 /hub/ · 피그마형 편집기 /hub/pro.html
매체 15 · 규격 90(전달 48) · 디자인 규칙 약 200 · 자동 테스트 582 · 커밋 330+ (8월~)

1. 무엇을 하는 도구인가

입력 채용 정보(회사·채용 구분·접수 기간·직무), 키비주얼, 로고와 브랜드색
출력 매체별 광고 이미지(PNG/JPG)와 수정용 SVG. 파일명·용량·규격은 매체 제출 양식대로

원칙

  • 정보는 시스템이, 표현은 디자이너가. 글자·로고·매체 규정은 규칙으로 고정하고 그림 배치와 배경만 AI가 판단
  • 비어 있는 정보는 추측해서 채우지 않음. 회사명이 없으면 물어봄
  • 내보내기 전에 사람이 승인. 규정 위반은 「차단」, 승인분만 ZIP으로

2. 어떻게 만들었나 — 노하우 6가지

Claude Code(터미널에서 코드를 읽고 고치는 AI)와 8월부터 만들었습니다. 기술보다 「AI에게 무엇을 기준으로 주느냐」가 결과를 갈랐습니다.

① 매체 규정을 문서가 아니라 데이터로

매체별 가이드(크기, 글자 수, 로고 유무, 금지 배경색, 폰트)를 PDF로 두지 않고 매체마다 JSON 파일 하나로 만들었습니다. 렌더러·검수기·가이드 문서가 모두 이 파일을 읽습니다. 규정이 바뀌면 한 곳만 고칩니다.

② 기준은 말이 아니라 샘플 실측으로

「패딩 좀 더 줘」로는 끝이 없었습니다. 담당 디자이너의 피그마 소재를 규격마다 실측(글자 위치·크기·굵기·로고 칸·그림 칸)해 「구멍 뚫린 틀」로 만들었습니다. 배경색·키비주얼·글자만 바뀌고 나머지는 틀 그대로. 틀과 ±2px 벗어나면 승인이 막힙니다.

③ 깨지는 그림을 모아 케이스 장부로

실제 키비주얼 107장을 전 규격에 넣어 깨지는 곳(얼굴 잘림, 글자 겹침, 지면색 어색)을 찾아 규칙으로 만들고 다시 전부 돌려 회귀를 봅니다. 57라운드 반복해 경고 190개를 수십 개로 줄였습니다.

④ AI가 맥락을 잃지 않게 히스토리 폴더를

작업이 끝날 때마다 날짜별 기록과 브리핑(지금 어디, 정해야 할 것)을 남기고, AI는 새 작업 시작 때 이 폴더부터 읽습니다. 다른 계정·다른 날에 이어 받아도 바로 이어집니다. 규칙마다 「누가 언제 왜」 근거를 붙였습니다.

⑤ 반복 작업은 스킬로

키비주얼 검수, 누끼, 로고 정리, 피그마 비교, 히스토리 기록, 배포처럼 매번 같은 순서로 하는 일은 한 단어 명령(스킬 13개)으로 묶었습니다.

⑥ 고칠 때마다 테스트를

담당자 요청 하나를 반영하면 그 사례를 테스트로 남깁니다(현재 582건). 다음에 다른 걸 고쳐도 이전 요청이 다시 깨지지 않습니다.

3. 작업 프로세스

  1. 요청 모으기 — 컨시어지 조직이 Notion 「컨시어지 요청 리스트」에 적고, 매주 월요일 미팅에서 사용 현황과 함께 훑음 (최근 10-28 한 번에 19건)
  2. 코드와 대조 — 요청마다 걸리는 곳과 상태(고침 / 규칙만 / 새 기능 / 결정 필요 / 이미 됨)를 표로. 결정 필요한 건 먼저 물음
  3. 갈래별 반영 — 매체 규칙 · 렌더러 · 앱 · 문장 파서로 나눠 동시에. 요청마다 테스트 추가
  4. 전수 검사 — 자동 테스트 전부 + 케이스 장부 재실행. 앱 띄워 콘솔 오류 0 확인
  5. 기록 — 날짜별 기록, 브리핑, 규칙 장부 갱신
  6. 푸시 = 배포 — main에 올리면 GitHub Pages에 바로 반영

4. 요청 방식

개선 요청(Notion)에 넣으면 좋은 것

항목내용왜
매체 · 규격「자소설닷컴 PC 채용공고 160×600」처럼 규격까지규격마다 규칙이 다름
지금 결과문제가 보이는 결과 이미지같은 조건으로 재현해야 고침
기준 샘플디자이너가 만든 정답(피그마 링크·이미지)실측해서 틀로 만듦
원하는 기준「6자까지 OK, 7자부터 서브로」처럼 숫자로그대로 규칙·테스트가 됨
우선순위상 / 중 / 하여러 건일 때 순서

좋은 예 「리멤버 1005×360에서 PC와 MO 메인 문구가 달라요. 규정상 같아야 합니다. (결과 이미지 2장 첨부)」
아쉬운 예 「글씨가 좀 이상해요」 — 어느 매체·규격인지, 무엇과 비교해 이상한지 없어 재현부터 막힘

앱 첫 화면에 공고 적는 법

첫 화면 문장은 AI 추측이 아니라 적힌 글자만 읽는 규칙으로 칸을 채웁니다. 아래 순서를 지키면 빠짐없이 읽히고, 읽은 값은 칸에 보이니 틀리면 바로 고치면 됩니다.
