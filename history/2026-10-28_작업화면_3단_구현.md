# 2026-10-28 — 작업 화면 한 틀(왼쪽 입력 · 가운데 결과 · 오른쪽 편집)

**상태: 로컬 커밋(푸시 안 함).** 앱 코드(app/ · core/) 영향 없음, hub/ 만. 테스트는 hub 와 무관(돌리지 않음).

## 1. 사용자 피드백 → 방향
- 어제 만든 둘(피그마식 · 쉬운 모드)은 원한 게 아니었다. 원한 것: **홈에 도구 카드 → 누르면 그 도구의 생성 화면**. 광고 소재는 들어가서 **자연어 입력이나 파일 첨부 → 기획 추출 → 생성**, **왼쪽은 입력(칸 추가 가능) · 오른쪽은 디자인 편집 패널**. 엘리베이터도 왼쪽 기획 · 오른쪽 결과. 둘 다 같은 포맷이되 **피그마 제품 같지 않게**. 편집은 **누르면 오른쪽에서 패널이 나오는** 형태.
- 와이어프레임으로 구조 제안 → 「이 구조로 만들어」(결정: 프레임 **한 번 클릭 = 오른쪽 편집 패널**, 두 번 클릭 = 그 규격만 크게).

## 2. 만든 것(hub/)
| 파일 | 역할 |
|---|---|
| `index.html` + `studio.js` + `studio.css` | 새 셸. 홈(도구 카드 4 + 최근 작업) → 작업 화면 3단 |
| `lib.js` | 어제 easy.js 에서 뽑은 공용: 말로 적은 글 읽기(`readPrompt`) · 배치 프리셋 4 · 색 테마 · 대비 보정 · 글 상자 높이 · 매체 맞추기(`syncMedia`) · 엘리베이터 장면 만들기(`buildScene` 2692×708) |
| `pro.html` | 어제 피그마식 편집기(옛 index.html) 그대로. 탭스트립 「작업 화면으로」 버튼이 `./#/ad/<id>` 로 돌아온다 |
| 지움 | `easy.html` · `easy.css` · `easy.js`(기능은 새 셸에 흡수, 코드는 커밋 0f04afc 에) |

**작업 화면(광고 소재 · 엘리베이터 공통)**
- 머리띠: ← 홈 · 도구 이름 · 작업 이름(바로 고침) · 저장 상태 · 되돌리기/다시 실행 · 전문가 편집기 ↗ · 내보내기.
- **왼쪽 입력**: ① 「무엇을 만들까요」 말로 적기 + 📎 붙이기(txt·md 는 글로 읽어 붙이고, 그림은 키비주얼로, PDF·워드·PPT 는 이름만 — 파서는 2차) → 「읽어서 만들기」. 문서가 생긴 뒤엔 「다시 읽기」. ② **읽은 값** 칸(고객사 · 채용 구분 · 접수 시작 · 마감 · 직무 고정 + 「＋ 칸 추가」로 시즌 · 고용 형태 · 근무지 · 슬로건 · 고지). 점선 = 읽은 값, 주황 = 비어 있음. 고치면 0.45초 뒤 모든 규격 글자에 반영 + 작업 이름도. ③ 키비주얼 · 로고(바꾸면 전체, 색 자동 체크). ④ 매체 칩 12(켜고 끄면 규격을 더하고 뺌 — `syncMedia`, 새 규격은 지금 색 · 그림 · 글꼴로). ⑤ 스타일(색 테마 4 + 직접, 글꼴, 배치 전체). 엘리베이터는 ①이 「장면 내용(한 줄에 한 장면 · 제목 | 본문)」, ②④ 없음.
- **가운데 결과**: 빈 상태 → 불러오는 중 → 매체별 카드(미리보기 · 확인 필요 n · 체크 → 선택 내려받기 · 매체별 ZIP). **한 번 누르면 오른쪽 편집**, 두 번(또는 카드의 ⤢)이면 **크게 보기** = 어제 캔버스 엔진(끌기 · 핸들 · 스냅 · 안내선 · 글자 두 번 눌러 고치기, 룰러 · 좌표 · 라벨 끔) + 위에 작은 도구(가운데 · 앞/뒤 · 복제 · 삭제), 이전/다음, Esc 로 목록.
- **오른쪽 편집**(선택해야 나타남, 폭 380 슬라이드): 규격 이름 · 크기 · 「크게」 · ✕, 미리보기, **글**(내용 · 크기 −/+ · 굵게 · 정렬 · 색 4 + 직접 · 지우기 · 글 추가) · **그림**(이 규격만/전부 바꾸기 · 꽉/다 보이게 · 그림 색으로 전체 · 로고 바꾸기/귀퉁이/크기) · **배경**(색 + 모든 규격에) · **배치**(4 프리셋, 이 규격) · **세부 조정**(접힘: 크게 보기에서 고른 레이어의 X/Y/W/H · 불투명 · 모서리 · 회전 · 잠금. 제약 · 효과 · 선은 전문가 편집기 링크) · 이 규격 PNG.
- 되돌리기는 **문서 전체** 스냅샷(올린 그림은 @kv 로 한 번만 직렬화) 60단계, ⌘Z/⇧⌘Z. 자동 저장 0.7초.
- 피그마 티 뺀 것: 탭스트립 · 아이콘 레일 · 레이어 트리 · 룰러 없음. 웹 글자 14px · 카드 · 부드러운 선. 피그마 세부는 「세부 조정」 안과 pro.html 로.

## 3. 확인(브라우저 JS · 1440폭)
- 홈 → 광고 소재 → 말로 적기(「GS에너지 2025 상반기 신입 공채, 6월 20일부터 7월 2일까지… 직무는 사업·재무」) + 자주 쓰는 3곳 → 읽어서 만들기 → 22규격, 읽은 값 5칸 점선. 카드 클릭 → 오른쪽 패널(글 3 · 그림 · 배경 · 배치) + 미리보기. 오른쪽에서 글 고침 → 캔버스 반영. 배치 「그림 전체」 → 스크림. 「크게」 → 캔버스 · 선택 상자 · 세부 X=100 → 반영 · ⌘Z 되돌림. 목록으로 → 22카드 · 선택 유지. 왼쪽 채용 구분 「경력 채용」 → 모든 규격 글자 + 작업 이름. 매체 칩 끄기 → 19규격. 색 테마 진하게. 콘솔 오류 0.
- 엘리베이터: 장면 3줄 → 2692×708 3장(배경 · 키비주얼 · 로고 · 메인 문구 · 본문), 넓은 카드, 오른쪽 패널(배치 카드 없음), 한 줄 추가 → 4장.
