# 2026-11-02: 피그마 시안을 틀로 탑재

사용자: 과거 통과 소재가 청사진. 데이터 기준이든 템플릿이든 그걸로 뽑아야 한다. 합격 기준 = 1 매체 가이드 2 타이포·여백 안정 3 키비주얼·배경 조화(작아지거나 허전하지 않게) 3-1 끊기는 지점 그라데이션.

## 흐름
1. `use_figma` 로 프레임 노드를 읽어 칸·타이포·뱃지·이미지 칸을 추출. 고객사 문구·이미지·브랜드 색 값은 저장하지 않는다.
2. `scripts/build-templates.mjs` → `core/templates-data.js` (94세트 188프레임, 같은 캠페인의 규격 묶음이 한 세트).
3. `core/renderers/ad-template.js` 가 칸에 내용을 채운다. 지면은 키비주얼에서, 색은 역할(글자색·강조색)로.
4. `npm run self-block -- --recipes`(전 조합) + `core/tplquality.js`(청사진 대조) → `scripts/template-quality.mjs` → `core/templates-quality.js`.
5. 후보: 기본안 + 시안 2개 자동, 인스펙터 「다른 시안 보기」로 통과 시안 전체에서 고른다.

## 유형 이름 규칙
비주얼 위치 + 타이포 특징: 예) 우측 비주얼 · 일정 뱃지형, 전면 비주얼 · 색 강조형, 하단 비주얼 · 굵기 대비형.

## 측정값
- 소재 1,918장 측정. 분포: `core/template-norms.js`.
- 이음: 일부 칸 이미지의 약 40%가 명시적 그라데이션, 2단 정지점, 길이는 이미지의 28~94%.
