## 한 줄로
**채용 광고 소재를 매체 규격(74종)마다 자동으로 만들어 주는 에이전트**를 만들고 있습니다.

## 1. 무엇을 만드나
- **입력**은 셋입니다.
  - 채용 정보: 회사, 직무, 마감일 같은 내용
  - 키비주얼: 메인 그림
  - 로고·브랜드색
- **출력**은 블라인드·구글·인스타·카카오·자소설 등 매체별 광고 이미지입니다. 지금 74개 규격을 지원합니다.
- **원칙 셋**
  - 정보는 시스템이, 표현은 디자이너가 맡습니다.
  - 비어 있는 정보는 추측해서 채우지 않습니다.
  - 내보내기 전에 디자이너가 승인합니다.
- **규칙 두 기둥**
  - **광고소재 가이드**: 매체가 정한 규정입니다. 크기, 글자 수, 로고 유무 같은 것들이고 `core/media/*.json`에 있습니다.
  - **디자인 가이드**: 키비주얼 종류마다 어디에 얼마나 크게 놓을지, 글자는 어떻게 쓸지 정한 규칙입니다. `core/kvtypes.js`, `core/canon.js`, `core/renderers/ad.js`에 있습니다.

## 5. 정해야 할 것 (사용자)
1. 세로·정사각형 메인 행간: 1.33(세아제강·한미 실측)과 1.28(9월 공채) 중 어느 것으로 할지. 지금은 1.28입니다.
2. 군중 사진을 지면 전체에 까는 규칙을 채용 소재에도 쓸지. 행사 소재에서 나온 규칙이고, 지금은 채용에도 켜져 있습니다.
3. 근거가 한 건뿐인 수치를 그대로 둘지: 장식 프레임 1.7배, 좁은 띠 넘침 35%, 카카오 글자 크기 48~164px.
4. 질감 위 글자는 흰색을 먼저 쓰고, 대비가 부족하면 스크림을 깝니다. 이대로 둘지.
5. 키비주얼 유형을 직접 지정하는 기능을 앱에 넣을지. 의사 사진처럼 측정으로 판정이 안 되는 경우에 씁니다.
6. 마이다스 브랜드색이 #00146E가 맞는지.
7. 10-12 작업을 커밋할지, GitHub Pages에 배포할지(10-09까지는 커밋·푸시됨).
8. 굵기: 날짜 줄을 500으로 둘지 700으로 둘지. 디자이너 근거가 3:2로 갈립니다. 블라인드처럼 날짜가 메인 아래 단독 큰 줄이면 700도 있습니다. 지금은 500입니다.
9. 굵기: 에브리타임 메인을 800(ExtraBold)으로 켤지. 근거는 1건이고, 지금은 700입니다.
10. 굵기: 자소설 채용공고 13px 흰 글자 값을 400으로 둘지. 템플릿 실측(400)을 가독 하한(500)보다 앞세운 것입니다.
11. 로고 색 겹침 규칙의 수치: 대비 1.6 미만, 면적 50% 이상이면 검정 단색. 근거는 1건(desk-37 동부건설 주황 × 주황 지면)입니다.
12. 글자 속 구멍 지우기: 색 엠블럼 안의 흰 글자도 투명해져, 밝은 지면에서는 지면색이 비칩니다. 이대로 둘지 정해 주세요. 단색 변환에서는 이 방식이 맞습니다.
13. 채도 지면 흰 글자: 지면은 명도를 최대 0.14 내리고 그림은 6%만 어둡힌다(흰 주인공이 회색으로 죽지 않게). 그림도 지면만큼 어둡힐지(이음매 0) 정해 주세요.
14. 분위기 있는 KV 배경을 구글(밝은 지면 매체) 선호보다 먼저 둘지. 어두운 사진(KB)은 말씀대로, 채도 있는 그라데이션(기아·GC)도 같은 순서로 두었습니다. ilhwa-dark 는 빨강 딥 → 사진의 남색이 됐습니다.
15. 근거 1건 수치: 흰 글자 명도 상한 0.12(노랑 경계), 분위기 채도 0.5·그라데이션 0.15, 질감 스크림 0.35~0.75, 누끼 판정 chroma 0.12·그라데이션 0.15.
16. 「채도 높은 브랜드색 위 흰 글자」를 받치는 레퍼런스가 references/ 에 없습니다. `/research 브랜드 컬러 위 흰 글자 대비` 를 권합니다.

## 6. 남은 문제
- **의사 사진(hr-doctor)**: 흰 가운과 흰 배경이 같은 색이라 인물을 못 찾아, 렌더가 깨집니다. 자동 경고는 0건입니다.
- **좁은 세로 띠(120×600, 288)**: 그림 아래가 비어 보입니다.
- **가로 띠(320×50, 400×76, 728×90)**: 그림 가장자리가 뚝 잘립니다.
- **AI 간호사 인스타**: 얼굴이 코에서 잘립니다.
- **유리 슬랩 580×400**: 회사명 「MIDAS / IT」 사이에서 줄이 바뀝니다.
- **사람 판정**: 아직 0건입니다. 판정 시트는 `ref/learned/cases/_out/verdict.html`에 있습니다.
- **로고 원본 품질**(데스크탑 로고 폴더): 파비콘급(긴 변 120px 미만) 56개, 90° 돌아간 세로 글자(실리콘투), 사이트 머리띠 통째(현대코드). 큰 가로 로고를 다시 받아야 합니다. 표에 파일이 빈 회사가 1곳 있습니다(세아해암학술장학재단).
- **작은 원본에서 딴 누끼**(desk-37-cut 163px): 큰 규격에서 흐립니다.
- **가로로 긴 떼 누끼**(desk-20-cut 코스알엑스): 좁은 띠에서 빈 띠 경고 9건이 남았습니다. abl-group과 같은 문제입니다.

## 7. 다시 돌리는 법
```
cd ~/mbm-design-agent
node scripts/cases.mjs intake            # ref/learned/cases/_inbox/ 에 넣은 그림 일괄 테스트
node scripts/cases.mjs run --round "메모"  # 전체 케이스 다시 돌리기
node scripts/cases.mjs relogo             # 로고 규칙(core/logo.js)을 바꿨을 때 장부 로고 다시 손질
python3 scripts/logo-prep.py <로고폴더> <출력> --csv <index.csv>   # svg·ico·gif → PNG (스킬 logo-prep)
python3 scripts/kv-cutout.py <KV> <out.png> --preview <p.png>      # 누끼 (스킬 kv-cutout)
npm test
```
