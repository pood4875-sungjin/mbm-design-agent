# 브리핑 — 지금까지 한 일 (쉽게)

> 마지막 갱신: 2026-10-14(가이드 배치 규칙) · 다음 갱신 때 이 줄을 바꿉니다.

## 한 줄로
**채용 광고 소재를 매체 규격(74종)마다 자동으로 만들어 주는 에이전트**를 만들고 있습니다.
지금은 「키비주얼을 넣으면 어떤 경우에도 디자이너처럼 놓이게」 하는 **디자인 규칙을 다듬는 단계**입니다.

---

## 1. 무엇을 만드나
- **입력**은 셋입니다.
  - 채용 정보: 회사, 직무, 마감일 같은 내용
  - 키비주얼: 메인 그림
  - 로고·브랜드색
- **출력**은 블라인드·구글·인스타·카카오·자소설 등 매체별 광고 이미지입니다. 지금 74개 규격을 지원합니다.
- **원칙 셋**
  - 정보는 시스템이, 표현은 디자이너가 맡습니다.
  - 비어 있는 정보는 추측해서 채우지 않습니다.
  - 내보내기 전에 디자이너가 승인합니다.
- **규칙 두 기둥**
  - **광고소재 가이드**: 매체가 정한 규정입니다. 크기, 글자 수, 로고 유무 같은 것들이고 `core/media/*.json`에 있습니다.
  - **디자인 가이드**: 키비주얼 종류마다 어디에 얼마나 크게 놓을지, 글자는 어떻게 쓸지 정한 규칙입니다. `core/kvtypes.js`, `core/canon.js`, `core/renderers/ad.js`에 있습니다.
  - 규칙 전부(174건)를 한 줄씩 모은 장부는 [규칙장부.md](규칙장부.md)에 있습니다 — 어떻게 작동하는지, 어떤 규칙이 어디 있는지, 근거가 1건뿐인 것은 무엇인지.

## 6. 남은 문제
- **편집 고도화(10-14) 한계**: 누끼가 이미 폭을 다 쓰는 아래 띠에선 「크게」가 더 안 커짐 · 직접 수정은 덩어리 셋(키비주얼·글자·로고)만 · 「왼쪽」은 블리드 없이 열에 맞춰 넣기 · 구글 「레이아웃 시안」 선택이 내보내기에 안 들어가는 기존 문제(확인 필요) · 직접 조작 패턴 레퍼런스 없음(`/research 캔버스 에디터 직접 조작` 제안).

- **NAP DSP 비즈보드 로고 크기(매체 규정 전수 검사, 47건)**: 배경 있는 KV 를 못 쓰는 이 규격에서 로고가 오브젝트 노릇을 하며 209px 폭으로 커진다. 규정 120×46 은 「썸네일 박스형」 수치라 로고 단독일 때도 지켜야 하는지 확인 필요. 그리고 **로고 위치는 어느 매체도 숫자 규정이 없어** 검사 못 함(안전영역 숫자 있는 규격 28개만 패딩 검사됨) — `_out/lint/lint-report.md` 끝 목록.
- **사람 판정**: 아직 0건입니다. 판정 시트는 `ref/learned/cases/_out/verdict.html`에 있습니다.
- **로고 원본 품질**(데스크탑 로고 폴더)
  - 파비콘급(긴 변 120px 미만) 56개, 90° 돌아간 세로 글자(실리콘투), 사이트 머리띠를 통째로 딴 로고(현대코드)가 있습니다.
  - 큰 가로 로고를 다시 받아야 합니다.
  - 표에 파일이 빈 회사가 1곳 있습니다(세아해암학술장학재단).
- **작은 원본에서 딴 누끼**(desk-37-cut 163px): 큰 규격에서 흐립니다.
- **좁은 세로 띠(120×600) 일부**: 떼 누끼(abl-group·midas-book-open)와 성긴 와이어(midas-stadium-wire)는 아직 빈 띠 29~43%입니다. 단일 사물은 10-12 저녁에 풀었습니다.
- **인물 사진의 넉넉한 띠**(AI 간호사 300×600): 머리 윗부분이 윗변 녹임에 조금 걸려 흐립니다.
- **구글 580×400 메인 겹침 15~20%**: desk-16·20·27·33과 desk-20-cut·desk-32-cut 에 있습니다. 같은 종류입니다(샘플 px 로 상세·서브를 키우면 메인이 24px 로 떨어져 되돌렸습니다).
- **샘플 밀도 vs 누끼 겹침(10-13)**: 샘플이 보여 준 상세·날짜 줄을 더하자 누끼 주인공 위로 글자가 올라가는 규격 — fox-cutout·desk-35-cut 인스타 1080 상세 31%, fox-cutout·sep-open-recruit NAP 300×250 24~26%. r43 대비 회귀 3건으로 남겨 뒀습니다.
- **가이드 대조표 ✗ 상위(r47, 95건)**: 글자가 주인공 위(textOverSubject) 28 · 작은 글자 대비(contrast.small) 17 · 누끼 블리드 면적(objectBleed.area) 17 · 빈 띠(emptyBand) 16 · 구글 상세 px 띠 vs 샘플(guide.detailPx) 5 · 작은 원본 확대 4 · 날짜 필수 4 — `_out/trace/index.html` 「✗ 규칙별 모음」.

## 7. 다시 돌리는 법
```
cd ~/mbm-design-agent
node scripts/cases.mjs intake            # ref/learned/cases/_inbox/ 에 넣은 그림 일괄 테스트

node scripts/cases.mjs relogo             # 로고 규칙(core/logo.js)을 바꿨을 때 장부 로고 다시 손질(단색용 logo-mono.png 포함)

node scripts/cases-lint.mjs [id …] [--spec 규격]   # 매체 규정(치수·글자수·줄 수·안전영역·글자 px·로고) 전수 검사 → _out/lint/lint-report.md
python3 scripts/logo-prep.py <로고폴더> <출력> --csv <index.csv>   # svg·ico·gif → PNG (스킬 logo-prep)
python3 scripts/kv-cutout.py <KV> <out.png> --preview <p.png>      # 누끼 (스킬 kv-cutout)

```
