# 2026-10-26: 통합 홈(AI 디자인 스튜디오) 구현 — 피그마 196:77

**상태: 로컬 커밋(푸시 안 함).** 앱 테스트 영향 없음(새 폴더 hub/).

## 1. 한 일
- 사용자가 피그마 「중앙화」 페이지에 다시 그린 흐름(섹션 196:77)을 코드로 옮겼다: 홈 탭 + 작업 탭(피그마식) + 새 탭(+) · 오른쪽 작업 내역 · 설정 → 홈 카드 4개 → 카드 고르면 새 탭에 입력 화면 → 파일을 넣거나 바로 시작하면 같은 탭이 도구 화면.
- 위치: `hub/`(index.html · hub.css · hub.js · tools.js). 공개 페이지에 올리면 /mbm-design-agent/hub/.
- 도구 목록은 `hub/tools.js` 한 곳(이름 · 설명 · 상태 · 주소 · 입력 문구). 홈 카드 · 새 탭 · 작업 탭이 모두 이걸 읽는다.
- 도구 화면은 탭 안 iframe. 광고 소재는 같은 출처라 입력에서 받은 파일을 앱의 브리프 파일 입력에 바로 넣는다(확인: GS 브리프 txt → 앱 브리프 칸에 들어감, 탭 이름 = 파일 이름). 엘리베이터는 다른 출처라 postMessage({type:'ai-studio:files'})로 보낸다 — 엘리베이터 쪽이 받아 줘야 동작.
- 탭 · 최근 작업은 이 브라우저(localStorage)에만. 작업 탭을 닫을 땐 확인 창.

## 2. 피그마와 다르게 한 것
- 탭 막대: 피그마는 다른 앱 탭 막대 스크린샷 이미지 → 코드로 실제 탭을 만들었다(아이콘 · 이름 · 닫기).
- 홈 왼쪽 사이드바(피그마 파일 브라우저 스크린샷)는 넣지 않았다 — 사이드바 없는 홈(195:1297)을 기준.
- 입력 화면 문구: 광고 소재 드롭존을 「채용 브리프 불러오기」로(디자인은 PPT 문구), 엘리베이터 제목을 「엘리베이터 콘텐츠 입력」으로. 「파일 없이 바로 시작」 링크를 더함(파일이 없으면 넘어갈 길이 없어서).
- 최근 작업 옆 메모 「2차 이후 — 1차엔 숨김」 대신 「이 브라우저에서 연 작업」.

## 3. 확인
- 1440 기준 위치: 제목 102 · 안내 168 · 카드 80,240 302×354 · 최근 작업 638/680 — 피그마와 ±2px.
- 흐름: 카드 → 입력 → 파일 드롭 → 도구 화면, + 새 탭 → 카드, 준비 중 카드 → 안내, 탭 닫기 확인, 작업 내역 팝오버 — 브라우저에서 클릭으로 확인.
- 375 폭: 가로 넘침 없음.
- 확인 못 함: 엘리베이터는 암호 화면이라 로그인 뒤 탭 안에서 그대로 쓰이는지 못 봤다(브라우저가 다른 출처 iframe 의 로그인 쿠키를 막으면 매번 암호를 물을 수 있음).
