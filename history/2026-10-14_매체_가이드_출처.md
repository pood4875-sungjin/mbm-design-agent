# 2026-10-14 매체 공식 가이드 출처 찾기

## 왜
지금 매체 규정(`core/media/*.json`)은 영업팀 자료 묶음과 Figma 보드에서 옮긴 값이라, 매체가 직접 공개한 가이드 주소가 하나도 기록돼 있지 않았습니다. 나중에 공식 가이드 페이지를 자동으로 지켜보다가 바뀌면 변경을 제안하려고 합니다(감지 → 제안 → 사전 검증까지, 자동 반영은 하지 않음). 그 첫 단계로 15개 매체의 공식 출처를 찾았습니다.

## 한 일
- 15개 매체마다 광고주용 공식 가이드(도움말·광고 안내 페이지·PDF)를 웹에서 찾았습니다. 찾은 것은 종류(공개 HTML / 공개 PDF / 상품 안내만 / 못 찾음), 갱신일, 핵심 숫자가 있는지를 기록했습니다. 몇 개 숫자는 우리 JSON 과 대조했습니다.
- 매체 JSON 마다 새 키 `officialSources: [{ url, covers, type, checkedAt, note }]` 를 넣었습니다. 확인한 URL 만 넣었고, 못 찾은 매체는 빈 배열입니다.
  - 요청은 `sources` 였습니다. 그런데 `sources` 는 이미 영업 자료·Figma 출처 문자열 목록으로 쓰이고 있습니다(`test/media.test.js` 필수 필드). 그래서 겹치지 않게 새 키로 만들었습니다. `build-media.mjs` 는 키를 그대로 넘기므로 따로 고칠 것이 없었습니다.
- `test/media.test.js` 에 형태 검사 1건을 더했습니다(url 은 https, type·checkedAt 있음, covers 는 실제 규격 id).
- `docs/media-sources.md`: 매체별 표, 다른 점, 못 찾은 매체와 대안, 감시 설계 메모.
- `ref/learned/media-watch.json`: 감시할 URL 15곳과 비교 방식(md / html / pdf / link), 기준 문구·선택자 힌트, 감시가 안 되는 6개 매체와 그 이유.
- 규정 값은 하나도 바꾸지 않았습니다.

## 발견 (제안 후보, 반영하지 않음)
1. **NAP DSP 가이드 새 판(2026.10)**: 같은 공식 링크가 지금은 `_202610.pdf` 를 내려줍니다. 우리 원본 `_202603` 과 비교하면 비즈보드 절이 바뀌었습니다.
   - 크기 1029×258 → **960×300**
   - 포맷: PNG-32 삭제
   - 로고: 「120×46 로고」 문구가 「지정 위치에 로고 필수(PSD 템플릿)」로 바뀜
   - 카피 240~526px, 간격 32px, 부가정보·의무고지 허용
   - 나머지 배너 규격은 그대로입니다. 브리핑 「정해야 할 것 3」(로고 120×46 해석)이 이 판으로 다시 열립니다.
2. **카카오 CPT**: 공식 용량이 300KB 인데 우리는 null 입니다. 「10/20 이후 버전」 새 가이드 페이지도 있습니다(고딕·브랜드 폰트 허용).
3. **카카오 비즈보드**: 우상단 66×174px AD·AI 마크 영역이 우리 JSON 에 없습니다. 카피 길이는 공식이 px 기준(290/480~796px)입니다.
4. **인스타 스토리**: Meta 안전영역(상단 14%, 하단 35%, 좌우 6%)이 우리 값에는 비어 있습니다. 피드는 공식 권장이 4:5 1440×1800 이고, 1:1 도 허용됩니다.
5. **당근**: 공식 문서에 최소 200×200 1:1, 10MB, 제목 30자, 브랜드 20자가 있습니다. 우리 두 규격은 전부 null 입니다.
6. **일치**: 구글 5개 크기와 150KB, 카카오 디스플레이 숫자 전부, 비즈보드 1029×258·300KB.

## 테스트
- `node scripts/build-media.mjs` → 15 media, 90 specs (core/media.js 는 officialSources 만 늘어남)
- `npm test` 395건 모두 통과. 이 작업이 더한 것은 1건이고, 나머지 증가분은 동시에 작업 중인 다른 작업(folders)의 테스트입니다.
- 렌더·규칙 변경이 없어서 라운드는 돌리지 않았습니다.

## 남은 문제
- NAP DSP 2026.10 비즈보드 변경을 반영할지(960×300 전환은 렌더러·케이스 전체에 영향). 우선 영업 담당에게 새 판이 적용됐는지 확인하는 것이 먼저입니다.
- 네이버 GFA 소재 가이드 문서 URL 은 사람이 광고주센터에서 한 번 복사해 주어야 합니다.
