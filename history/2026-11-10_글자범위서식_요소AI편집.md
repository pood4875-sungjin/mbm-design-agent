## 1. 글자 범위 서식 (425d7eb)
- 저장: `overrides.elements[id].runs = [{ s, e, c?, o?, w?, px?, ls?, t }]` — 속성끼리 독립(색만 바꿔도 굵기는 남음, null = 그 속성만 지우기). `core/elementedit.js addRun · stripRuns · scaleRuns`.
- 요소 전체 값(범위 없이 굵기·색·자간)을 바꾸면 그 속성의 범위 서식은 걷힘 — 피그마처럼 전체 값이 이김. 크기는 비율로 범위 크기도 같이.
- 오른쪽 패널(피그마 UI3 구성, `app/fui.js` 부품): 「글자」 = 글꼴 / 굵기 이름(Thin~Black, 그 글꼴이 가진 것만)·크기(입력+목록) / 행간·자간 % / 가로 정렬 3·세로 정렬 3(세로는 글상자가 글자에 맞춤이라 꺼 둠). 「칠」 = 색 칩·헥스·불투명도 %·숨김·빼기. 범위를 고르면 같은 칸이 범위 값(섞이면 「혼합」)을 보이고 범위에 먹음. 예전 「고른 글자 · 칠」 칸과 안내 문구 없앰.
- 서식을 바꾼 뒤에도 고른 범위 유지(새 문서에서 같은 [s,e) 다시 고름). ⌘B 굵게 토글(그 글꼴에서 가장 가까운 Bold↔Regular), ⌘I·⌘U 막음, Esc 끝내기.
- 실시간: 색 피커·숫자 칸 입력 중엔 보이는 프레임의 그 글자에 직접 입힘(재렌더 없음), 확정 때 한 번 커밋(되돌리기 한 걸음). 헤드리스 입력 20회: 처리 최대 1.9~3.0ms · 프레임 간격 평균 15.8~16.9ms(최대 17~20ms).
- 범위 크기를 키우면 px 행간을 비율로 바꾸고, 커진 만큼 글상자 높이(max-height)를 늘리고 같은 부모 안 아래 글자를 내림(옮긴 요소는 그대로). 카카오 1200×600 실측: 「GS에너지」 90px → 메인 176→198, 서브 337→359.
- 매체 잠금 사유 한 줄: 범위 색(글자색 규정 · 자소설 「모든 문구 한 색」), 굵기·자간(자소설 「폰트 스타일도 변경 불가」 · 비즈보드 「글꼴 스타일 변경 불가」), 크기(자소설·비즈보드).
- 고친 버그: 커밋 뒤 선택 손잡이가 다시 떠서 두 번째 끌기가 글자 고르기 대신 요소 옮기기가 됐다 → 글자 편집 중엔 손잡이를 다시 띄우지 않음.

실측(카카오 1200×600, 메인 「2025년 GS에너지 / 신입 공채」, `_out/textrun-1110/`)
- 전체 Regular → 「GS에너지」 끌어 골라 ExtraBold(800)·#E4002B: 바뀐 글자 6~10 「GS에너지」만, 나머지 400 그대로
- 「신입」 ⌘B → 700, ⌘Z → 400 · 저장 후 다시 열기: 범위 굵기·색·크기 그대로
- SVG: 「GS에너지」가 따로 `<text font-size="90" font-weight="800" fill="#E4002B">`

## 2. 요소 AI 편집 (187a34d)
- 요소(글자·로고·키비주얼)를 고르면 선택 상자 오른쪽 위 바깥에 AI 아이콘 → 팝오버(요소 칩 · 입력 · 추천 칩 · Enter/Esc) → 결과 바로 캔버스 + 「적용 / 되돌리기」.
- ① 규칙(LLM 없음, `core/elementai.js quickElementEdit`): 굵게·얇게·크게·작게(%)·색·정렬·자간·강약·한 줄로·「낱말」만 ~. 「강약」 = 회사명(없으면 가장 긴 낱말)을 그 글꼴 최대 굵기, 나머지 낱말 Regular·0.78배.
- ② 로컬 서버 `POST /api/element-edit`(`server/elementedit.js`, claude -p · sonnet · effort low) — 연산 JSON → 서버 검증(굵기·최소 크기·대비 4.5·잠금·안전영역·겹침, 지금과 같은 값 빼기). 취소하면 자식 claude 도 끊음.
- 공개 앱(서버 없음): ① 만, ② 는 「로컬 앱(AI 서버)에서만」 안내.
