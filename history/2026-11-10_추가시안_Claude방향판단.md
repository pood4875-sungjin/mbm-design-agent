# 2026-11-10 (14) — 기본안·추가 시안은 규칙 + Claude 는 판단만, 자유 디자인은 클릭

## 사용자 결정
- 「생성되는 걸 어디까지 Claude 에게 맡길지」 → A·B·C 비교 뒤 사용자 안: 「기본안이 캔버스에 빠르게 깔리고, 추가 시안 3개 정도는 규칙 기반 + AI 가 판단만 도와서. 추가(자유) 시안은 클릭해서 생성」. 이유: 자유 디자인은 3안 다 오는 비율 12/16, 3안 134~281초, 퀄리티 보장 안 됨(11-09 루프 실측).

## 만든 것
- `/api/kvjudge` 한 번의 호출로 그림 종류 + **추가 시안 방향**(A center·mirror·full / B 태그·모양 / C 밝은 지면 씀·안 씀)을 같이 고름. 캐시 키 v2.
- `core/aislots.js`(새) `cleanAiSlots` · `core/variants.js preferAiSlot` — `style.aiSlots` 로 슬롯 후보 **순서만** 바꿈. 거르기 그대로. 없으면 예전과 같음. `core/style.js` 통과.
- 앱: 그림 올리면 규칙 결과 먼저 → Claude 판단이 오면 `aiSlots`·유형을 넣고 다시 그림(알림 · 되돌리기 ⌘Z). 생성 뒤에 판단이 오면 캠페인에도 반영.
- **AI 그림 판단 자동**: 초안 생성 직후 · 인스펙터에서 그림 바꾼 직후(Claude 연결 때). 그 사이 손댄 소재(승인·다른 수정)는 건드리지 않음. 사람이 직접 돌린 판단은 덮지 않음.
- 고친 결함: `app/hybrid.js hasServer` 가 API 키가 있을 때만 서버를 썼다 → 키 없이 Claude 계정만 있으면 「AI 그림 판단」이 「AI 키가 없습니다」로 실패하던 것. 이제 서버에 Claude Code 가 있으면 서버로.
- 자유 디자인(「AI 추가 제안」)은 지금처럼 버튼을 눌렀을 때만 — 바꾼 것 없음.
