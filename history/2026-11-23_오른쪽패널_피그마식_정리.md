# 2026-11-23 오른쪽 패널 피그마식 정리 + 카카오 썸네일 로고 어긋남

## 1. 카카오 비즈보드(960×300) 광고주체 로고가 그림 밖으로 어긋남
- 증상: 로고가 썸네일 왼쪽 위 밖에 반쯤 걸쳐 있었다(사용자 캡처: 그림 x 662 · 폭 259, 로고 x 609).
- 원인
  - 썸네일 칸을 덮어 채울 때 주인공이 60%보다 적게 보이면 칸을 그림 크기로 줄여 오른쪽에 붙이는 규칙(`slotFit`)이 있다.
  - 이 규칙이 공식 크기 고정 칸(둥근 320×222)에도 걸렸다. 그림은 260 폭으로 줄었는데 광고주체 로고는 원래 칸(601+8) 기준이라 어긋났다.
  - 11-15 결정 「공식 칸은 줄이지 않는다」에도 어긋난다.
- 고침: 둥근 공식 칸(`roundSlot`)은 `slotFit` 을 건너뛴다(core/renderers/ad.js). 재현 입력(ar 1·0.8)에서 칸 601·320×222, 로고 609.

## 2. 오른쪽 패널 피그마식 정리(사용자 「불필요한 거 없애고 피그마 편집기같이」, 정리안 선택)
- **이 소재만**
  - 순서: 레이아웃 안 → 채우기 → 키비주얼 → 글자 → 선택 색 → 요소 → 고급.
  - **채우기**(새): 이 소재 배경을 지면 줄 + 층으로 편집한다(`a.overrides.style.background`).
    - 예전 「배경」 프리셋(배경·그라데이션 버튼)과 배경색 한 줄을 대신한다.
    - 「로컬 앱에서 배경 컬러 편집이 안 된다」던 곳이다. 앱에서 지면 색을 바꾸면 그 소재 배경이 바로 바뀌는 것을 확인했다.
  - 키비주얼 위치·크기·스크림: 버튼 줄 + 설명 → 이름 + 드롭다운 한 줄(`presetArtifactHtml compact`). 못 고르는 값은 비활성 + 이유.
  - 글자: 폰트 + 칠(한 줄, 비면 「자동」) + 정렬. 글자색 공통/흰/검정 세그먼트와 「글자별 편집」을 뺐다. 글자마다는 캔버스에서 글자를 골라 요소 패널에서 고친다.
  - 선택 색: 주·보조·포인트 칩 한 줄.
  - 고급(접힘): 글자 세로 위치 · 정보 태그 · 태그 모양 · 가이드.
- **전체 일괄**
  - 순서: 페이지 → 배경(채우기) → 키비주얼 → 로고 → 글자 → 선택 색 → 내보내기 → 도구 → 고급.
  - 글자: 폰트 줄 + 폰트 파일 첨부 링크 + 칠 + 정렬. 기본/흰/검정 세그먼트와 긴 설명을 뺐다.
  - 고급(접힘): 글자 세로 위치.

## 3. 그라데이션 팝업을 피그마 화면처럼(사용자 「색 정지점이 제대로 안 나온다 — 준 것처럼」)
- 배포: 위 1·2 는 b6b25bd 로 공개 주소에 올렸다.
- 원인: 지면(불투명 칸)을 단색 → 선형으로 바꾸면 피그마 기본처럼 「그 색 → 투명」 정지점이 생겼다. 지면은 투명을 못 써서 오른쪽 정지점이 투명 격자로 보였고, 고칠 칸(불투명도)도 없었다.
- 고친 것(app/fillpanel.js)
  - 투명이 안 되는 칸은 정지점 불투명도를 걷는다. 단색 → 그라데이션은 「그 색 → 40% 어두운 색」으로 만든다.
  - 배치를 피그마처럼 바꿨다.
    - 맨 위: 종류 드롭다운(선형·방사형) · 각도 · 90° · 뒤집기.
    - 그 아래: 막대, 정지점 목록(위치 % · 색 · 불투명도 % · 빼기).
    - 색 판은 정지점(목록 견본이나 막대 손잡이)을 누를 때만 아래에 열린다.
  - 위쪽 탭은 단색 · 그라데이션 · 이미지 3개로 줄였다. 방사형은 드롭다운에서 고른다.
- 확인: 로컬 앱 「이 소재만」 지면에서 정지점이 78D8D5 → 488280(불투명도 100 잠김)으로 나왔다. 정지점을 누르면 색 판이 열린다.
- 테스트: fill-1123 · notion-1120 통과.

## 4. 캔버스 그라데이션 방향 손잡이(채우기 2차, 사용자 「fill 누르면 프레임에서 방향 설정 — 피그마처럼」)
- 그라데이션 칠의 팝업을 열면 칠한 상자 위에 손잡이가 뜬다(app/fillpanel.js drawHandles).
  - 대상 상자: 이 소재만 배경 = 그 소재, 전체 일괄 배경 = 고른(없으면 보이는 첫) 소재, 글자·상자 칠 = 그 요소.
  - 선형: 시작·끝 손잡이 + 선 + 가운데 정지점 점. 끌면 각도와 선 위 자리(from·to %)가 바뀌고, Shift 를 누르면 45° 단위.
  - 방사형: 중심 · 가로 반지름 · 세로 반지름 손잡이 + 타원. Shift 를 누르면 원.
  - 캔버스를 옮기거나 확대해도 매 프레임 자리를 맞춘다. 끄는 동안은 보드 미리보기, 놓으면 한 번 저장.
- 값(core/gradient.js normGradient)
  - 선형 from·to: CSS 그라데이션 선 위 % — 정지점 위치를 from~to 로 옮겨 그린다. 손잡이를 선에 수직으로 옮긴 것은 같은 그림이라 선 위로 투영한다.
  - 방사형 cx·cy·rx·ry: `radial-gradient(ellipse rx% ry% at cx% cy%)`. 값이 없으면 예전 「가운데 원」 그대로다.
- 확인
  - 로컬 앱: 끝점을 끌자 117°, from 29.8 · to 82.1 이 되고 소재 배경이 바로 따라갔다.
  - 방사형: 중심·반지름을 끈 값이 CSS 와 SVG(radialGradient 중심 173·122, 세로 1.787배)에 맞게 나왔다.
