## 1. 유형 직접 지정 (결정 5)
측정으로 유형이 틀리게 나오는 그림이 있다(의사 사진처럼). 그때 디자이너가 유형이나 세분 유형을 직접 고른다. 기본값은 「자동」이다.
- `core/kvtypes.js:203` `OVERRIDE_FLAGS`: 세분 유형마다 켜고 끌 깃발. 렌더러의 분기가 모두 이 깃발을 보기 때문에, 깃발을 바꾸면 놓는 법·지면·글자 규칙이 함께 따라온다.
- `core/kvtypes.js:232` `kvTypeChoices`, `:244` `applyKvTypeOverride`, `baseKvMeta`. 측정값에 지정을 입힌다. 여러 번 입혀도 결과가 같고, 「자동」으로 돌리면 측정값 그대로 돌아온다.
  - 인물·캐릭터를 골랐는데 주인공 상자를 모르면 위쪽 90%를 사람으로 본다. 앱에는 인물 분리가 없어서다. 그래서 머리는 지키고 아래부터 자른다.
- `core/kvtypes.js:186`·`:193`: 지정한 세분 유형이 대표가 되고, 요약에 「유형 직접 지정」이 붙는다.
- `core/style.js:35`: `style.kvTypeOverride` 를 추가했다. normalizeStyle 이 kvMeta 에 지정을 입히므로 ad.js·field.js·adcheck 가 모두 같은 답을 본다.
- 앱 `app/app.js:811` `kvTypeControlHtml`
  - 위치: 그래픽 가이드 단계와 인스펙터 「스타일」 맨 위.
  - 형태: 네이티브 `<select>` 에 `<label for>` 와 `aria-describedby` 도움말을 붙였다. 첫 항목은 「자동 (지금: …)」이고, 그 아래 4유형이 optgroup 으로 나뉘며 각 그룹은 「세분 자동」과 세분 유형으로 이뤄진다.
  - 접근성: 고른 뒤 다시 그려도 포커스가 선택 상자에 남는다. 포커스 링은 공통 `:focus-visible` 을 쓴다.
  - 연결: restyle 이 지정값을 넘긴다. 키비주얼을 바꾸거나 지우면 「자동」으로 돌아간다.
- 케이스 장부: `cases.json` `typeOverride` 와 `node scripts/cases.mjs type <id> <유형|세분 유형|auto>`(`scripts/cases.mjs:180`). run·검수·kv-guide·case-shot·case-review 가 모두 이 값을 쓴다.
- 지금 장부에 직접 지정한 케이스는 없다. hr-doctor 는 아래 §5의 인물 상자로 자동 판정이 맞게 됐다.

## 2. 글자 속 구멍 (결정 12)
- `core/logo.js:62` knockoutLogo 의 기본 동작을 바꿨다.
  - 이전: 글자 속을 늘 지웠다.
  - 이후: 바탕이 어두운 상자(밝기 < 0.6)일 때만 지운다. `holes:true` 면 늘 지우고, `holes:false` 면 남긴다.
  - 어두운 상자 로고(도루코 검정 상자)의 속은 상자 찌꺼기라서, 남기면 어두운 지면에 검은 점이 뜬다. 그래서 원색에서도 지운다.
  - 결정 원문은 「단색일 때만」이지만, 이 예외는 「흰 속을 지킨다」는 결정의 취지 안에서 정했다.
- `core/logo.js:135`: prepLogoRGBA 가 `mono`(글자 속까지 지운 단색용 사본, 트림은 같음)를 함께 돌려준다.
- `core/logo.js:143`: 로고 실측(톤·대표색)은 사본으로 잰다. 남긴 흰 속까지 세면 볼보의 흰 원판 엠블럼이 「흰색 로고」로 잡혀 지면이 어두워진다(desk-29). 이 처리로 장부 92건의 logoMeta 는 하나도 바뀌지 않았다.
- `core/renderers/ad.js:564`: 단색 필터(흰 반전·검정)를 걸 때만 `style.logoMono` 를 쓴다. banner·print·photobooth 도 똑같이 바꿨다.
- 앱 `prepLogo`·`knockoutLogo` 가 `monoDataUrl` 을 만들고 `it.logoMono`·`style.logoMono` 로 넘긴다. 로고 톤·실측도 사본으로 잰다.
- 장부: `cases.mjs relogo` 를 다시 돌렸다. `logo-mono.png` 가 생긴 케이스는 12건이다(desk-05·10·14·18·18-cut·19·29·32·32-cut·33·35·35-cut).
