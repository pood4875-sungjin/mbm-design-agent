## 무엇을 바꿨나
1. **서버 유무 판정 한 곳 — `app/runtime.js`**
   - `app/index.html` 머리(첫 `<style>` 앞)에 `window.MBM_RUNTIME = /*MBM_RUNTIME*/null` 자리표시와 한 줄 스크립트. 서버 표시가 아니면 `<html class="no-server">` 를 바로 달아요.
   - 서버가 index.html 을 내줄 때 자리표시를 바꿔 끼워요: `server/server.mjs` → `'server'`, `scripts/serve.py` → `'static'`, GitHub Pages → 그대로 `null`.
   - 그래서 판정이 **동기**예요. 첫 그리기 전에 끝나서 깜빡임이 없어요.
   - **기본 = 숨김 쪽**으로 했어요. 근거: 공개 링크에서 AI 버튼이 잠깐 보였다 사라지면 「눌렀는데 없어짐·실패」가 생겨요. 로컬 앱은 서버가 'server' 를 끼워 주니 처음부터 보여서 반대쪽 깜빡임도 없어요.
   - 예외 하나: 새 코드로 다시 켜기 전의 **옛 로컬 서버**는 자리표시를 몰라서 null 로 내줘요. 주소가 localhost 일 때만 `/api/health` 를 한 번 물어 확인하고, 서버면 class 를 떼고 인스펙터를 다시 그려요(`onServerChange`). github.io 에서는 `/api/*` 를 한 번도 부르지 않아요.
   - `?aistub=1`(시나리오 캡처용 가짜 서버)은 서버 있음으로 봐요.
2. **숨김 = CSS 한 줄**(`.no-server …{display:none !important}`) — 목록은 `app/runtime.js AI_ONLY_SELECTORS` 와 같고, 테스트가 둘을 맞춰요.
3. **칩** — 공개 링크에선 「Claude 연결하기」 대신 **「규칙 모드 · AI는 로컬 앱에서」**. 누르면 「규칙 모드예요」 창: 짧은 설명 두 줄 + 「로컬 앱 켜는 방법 보기」(docs/local-ai-setup.md) + 「캠페인 JSON 내보내기」·「닫기」. 「다시 확인」「계정 연결」처럼 실패할 버튼은 없어요.
4. **뒤에서 도는 AI 호출 0** — `/api/claude/status`·`/api/health`·`/api/freeprefs`·`/api/kvjudge`·`/api/analyze`·`/api/claude/ask` 를 판정 뒤에만 불러요.
5. **기획 해석은 규칙 파서** — `app/llm.js hasKey()` 가 서버 없으면 false. 브라우저 키(localStorage·config.local.js)가 남아 있어도 공개 링크에선 api.anthropic.com 을 부르지 않아요. 공고는 `core/brief.js` 규칙 파서가 읽어요.
6. `docs/local-ai-setup.md` 에 「공개 링크는 규칙판이에요」 칸을 더했어요.
