## 만든 것
- `core/svgexport.js` — 렌더된 광고 DOM(래스터가 찍는 것과 같은 문서) → SVG 한 장. 특정 렌더러 구조에 기대지 않고 계산 스타일·상자를 읽는 범용 변환기.
  - 글자: 글자 덩어리마다 `<text>`, 브라우저가 실제로 낸 줄마다 `<tspan x y>`(글자별 `Range.getClientRects` 로 줄을 복원, baseline 은 캔버스로 잰 글꼴 윗길이 비율). 글자를 윤곽선으로 바꾸지 않음. line-clamp 로 안 보이는 글자는 빼고 끝에 「…」.
  - 색만 다른 이어진 토막(두 톤 강조)은 x·y 없이 붙여 Figma 에서 글자 노드 하나(색 구간 여럿)가 되게. 굵기·크기가 다른 토막(「모집직무 : 값」)은 따로 둔다 — 붙이면 Figma 가 앞 토막 굵기로 통일한다(실측).
  - 지면·스크림: 단색 `<rect>`, linear/radial-gradient → `<linearGradient>`/`<radialGradient>`(CSS 각도·모서리 키워드·정지점 규칙 그대로 절대 좌표로). 칩·CTA 는 둥근 `<rect>` + `<text>`.
  - 키비주얼: background-size/position(cover·contain·명시 크기·4값 위치) 대로 `<image>` + `<clipPath>`. 보이는 부분(+캔버스 안 10% 여유)만 담고, 표시 크기 2배까지(긴 변 1600px 근처에서 멈춤). 불투명이면 JPEG, 알파 있으면 PNG.
  - 녹임: `mask-image` 그라데이션 → `<mask>`(흰색 + 알파 정지점, `mask-type:alpha`). 두 변 녹임(intersect)은 마스크 두 겹.
  - 로고: `<image>`. 원본이 SVG 면 중첩 `<svg>` 로 벡터 유지 — 단색 변환(brightness(0)[ invert(1)])도 칠을 검정/흰색으로 바꿔 벡터 유지. PNG 로고의 단색 변환은 캔버스 `filter` 로 색을 입힌 PNG(래스터 대체).
  - 레이어 이름(id): 광고 › 지면 · 키비주얼 · 스크림 · 서브 · 메인 · 날짜 · 상세 › 칩-접수기간 … · CTA · 로고 자리 › 로고.
  - 옮기지 못하는 효과(box-shadow·transform·filter·blend·clip-path)는 건너뛰고 기록 — SVG 머리 주석 + 앱 에이전트 로그에 「대체·근사한 것」 목록.
- 앱(`app/app.js`): 매체 소재 내보내기 창에 **「SVG (Figma 편집용)」** 버튼(한 장 → .svg), 「전체 내보내기」 창에 **「ZIP + SVG」** 버튼(같은 ZIP 의 `svg/<래스터와 같은 파일명>.svg`, 차단 소재는 래스터처럼 뺌). 두 창에 「Figma에서 Pretendard 폰트가 설치되어 있어야 글자가 그대로 보입니다」 안내. SVG 는 용량 맞춤(단색 배경·JPG) 전의 원래 디자인을 옮긴다.
- `scripts/svg-check.mjs` — 충실도 검사. 케이스 × 규격마다 headless Chrome 에서 변환 → HTML 1x 와 SVG 1x 를 찍어 픽셀 차이(평균 절대 차이 · 채널 차이 40 넘는 픽셀 %) + 글자 토막 위치 오차(DOM 줄 상자 vs 같은 문서에 붙인 tspan 상자). `--cases`·`--specs`·`--logo <파일>`(로고 바꿔 끼우기)·`--accent #HEX`(두 톤 강조)·`--out <하위폴더>`. 결과 `ref/learned/cases/_out/svg-check/index.html`(HTML | SVG | 차이).
- `test/svgexport.test.js` 14건(그라데이션 해석·각도·정지점·배경 배치·줄 묶기·레이어 이름·id·둥근 모서리·제출 배수·이스케이프).

## Figma 가져오기 확인(새 연습 파일 「MBM SVG 가져오기 확인 (scratch)」, 개인 팀 drafts)
`figma.createNodeFromSvg` 로 실제 내보낸 SVG(그림만 줄여서)를 넣어 봄.
- 글자 → **TEXT 노드(편집 가능)** ✓. 그룹 이름은 id 그대로(광고·지면·키비주얼·서브·메인·상세·칩 접수기간·로고 자리·로고) ✓.
- 키비주얼·로고 → 이미지 채움 사각형 ✓, 녹임 마스크 → 「Mask group」(ALPHA 마스크) ✓, 그라데이션 → GRADIENT_LINEAR ✓.
- **안 되는 것**: ① `letter-spacing` 은 어떤 형태(속성·style·em)로도 0% 로 들어온다 → 메인 자간(-2.5%)은 Figma 에서 다시 지정해야 함(SVG 주석·로그에 적어 둠). ② 여러 줄 글자는 줄마다 TEXT 노드 하나(묶음 안에) — `dy` 로 써도 같다. ③ 굵기·크기가 다른 토막을 한 줄로 붙이면 굵기가 하나로 통일됨 → 따로 둠. ④ 이 연습 환경(클라우드)에는 Pretendard 가 없어 Inter 로 대체됨 — 사용자 PC 에 Pretendard 가 있으면 그 글꼴로 잡힐 것(확인은 못 함).

## 남은 문제
- Figma 의 자간 미지원 — SVG 안에서 풀 방법 없음(글자마다 x 를 박으면 편집성이 깨진다). Figma 플러그인으로 직접 그리는 방식이면 풀린다(다음 단계 후보).
- 같은 이름의 소재가 두 장이면(예: 네이버 GFA 300×300 두 개) ZIP 안에서 이름이 겹친다 — 래스터에도 원래 있던 문제.
- `.claude/launch.json` 에 앱 미리보기 설정 `mbm-agent`(포트 4793) 추가.
