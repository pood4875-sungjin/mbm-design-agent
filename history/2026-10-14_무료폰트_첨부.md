# 2026-10-14 무료 폰트 첨부 — 매체가 정하면 그 폰트, 아니면 캠페인에서 고른 폰트

## 왜
사용자 요청: 「무료 폰트를 앱에 넣어 두고, 폰트 기준이 없는 매체는 고른 폰트로 나가게. Pretendard 가 무조건 기준인 매체(자소설·카카오·리멤버)는 제외하고 안내 문구를 넣어 달라. 순서는 나눔스퀘어 → 나눔스퀘어 네오 → 나눔스퀘어라운드 → 카카오 빅산스.」
- 그동안 폰트는 CDN 링크 4종(Pretendard·나눔스퀘어 계열)뿐이었고, 래스터 내보내기는 설치된 폰트에 기댔다(설치 안 된 PC 에서는 대체 폰트로 찍힘).
- 「카카오 빅산스」는 카카오 기업사이트(brand resource, page/detail/11571)에서 지금 배포하는 **카카오 큰글씨(영문 name 테이블 Kakao Big Sans)** 로 확인 — OFL 적용, 개인·상업 무료. 옛 「카카오 서체(2013)」는 현재 라이선스 페이지를 못 찾아 넣지 않았다.

### 2. 카탈로그 `core/fonts.js`
- 항목마다 `label·family·stack·dir·weights·license{name,url,commercial,embed}·source·group`. 묶음 순서 = 기본(Pretendard) → 무료 폰트(사용자 지정 넷이 맨 앞) → 첨부(런타임 custom).
- `localFaceCss(id)` 미리보기용 상대 경로 @font-face · `embeddedFaceCss(id, dataUrls)` 내보내기용 dataURL @font-face · `fontInfoLine(id)` 라이선스 한 줄.
- 매체 규정 읽기(값은 안 바꿈): `fontRuleOf(medium, spec)` → `{fixed, required, requiredId, allowed, recommended}` · `effectiveFontId(medium, selectedId)` = required → allowed 중 카탈로그 첫 것 → 고른 폰트.

### 3. 게이팅
- 렌더러 `core/renderers/ad.js:399` — `mr.fonts.required` 가 있으면 `'Pretendard', <고른 스택>` (그대로). `core/lint.js` 실측 서체가 다르면 `font` 경고(그대로).
- 산출물 개별 폰트 `overrides.style.fonts`(`app/app.js artifactFontHtml`) — 자유 매체만 선택 칸, 고정 매체는 「이 매체는 Pretendard 고정 — 매체 규정(자소설닷컴)」 문구만.
- 지금 매체 JSON 15개: required 3(자소설닷컴·카카오톡·리멤버 = Pretendard) · recommended 1(네이버 GFA 「나눔고딕 혹은 고딕계열」, 안내만) · 자유 11. `allowed` 배열은 아직 어느 매체에도 없다.

### 4. 앱 `app/app.js`
- 폰트 선택(인테이크 스타일 단계 · 캠페인 인스펙터 `#iFont`)이 「기본 / 무료 폰트 / 첨부」 optgroup. 옵션 title 에 라이선스 한 줄.
- 안내 문구(선택 아래): **「자소설닷컴·카카오·리멤버는 매체 규정상 Pretendard로 고정됩니다. 여기서 고른 폰트는 폰트 규정이 없는 매체에만 적용됩니다.」** + 「고정: 자소설닷컴(Pretendard) · 카카오톡(Pretendard)」 + 「고른 폰트 적용(나눔스퀘어 네오): 네이버 GFA — 권장 나눔고딕 혹은 고딕계열」 + 라이선스 줄(캠페인 매체에서 계산).
- 내보내기 창: **「폰트 고정 매체: 자소설닷컴·카카오톡 (Pretendard) · 나머지: 나눔스퀘어 네오 — 파일에 폰트를 함께 넣어 내보냅니다」**.
- 미리보기 iframe: `previewDoc(html, fontId)` 가 상대 경로 @font-face 를 넣는다(srcdoc 은 부모 base URL). 래스터·배너 내보내기: `exportFaceCss()` 가 woff2 를 fetch 해 dataURL 로 끼움(기본 Pretendard 는 예전처럼 설치 폰트). SVG: 앱 문서에 `#bundledFonts` @font-face 를 넣어 글자 상자를 같은 서체로 재고, SVG 에는 family 이름만 남는다(Figma 에 같은 이름 폰트 필요 — 내보내기 창 문구).

## 남은 한계
- 구글 GDN 규격이 든 저장 캠페인이 없어 앱 확인은 네이버 GFA(자유 매체)로 했다. google-gdn 은 테스트에서 확인.
- 카카오 폰트는 배포 zip 에 라이선스 파일이 없어 페이지 문장 + 폰트 name 테이블의 OFL URL 로 확인했다(자체 라이선스 문서 없음 — 확실하려면 카카오 문의).
- 나눔 계열은 500·600 굵기가 없어 400/700 으로 대체 렌더(아이브로 600 → 700, 슬로건 500 → 400). 굵기 위계가 Pretendard 보다 한 단 거칠다.
- SVG(Figma 편집용)는 폰트를 싣지 않는다 — Figma 에 같은 이름 폰트 설치 필요.
- 내보내기 HTML 은 묶은 폰트 전 굵기를 base64 로 실어 소재당 0.6~1.2MB 커진다(제출물 PNG/JPG 크기는 그대로).
