# 2026-10-22 — A/B 비교 환경: 규칙 렌더러(A) vs AI 디자인(B)

## 왜
지금 에이전트는 매체 규칙·템플릿으로만 소재를 그린다(A). Claude 가 키비주얼·로고·문구·고객사 요구·브랜드 색·매체 규격을 보고 **디자인 구성 자체를 판단**하는 방식(B)이 더 나은지, 같은 입력으로 나란히 놓고 재 보기 위한 환경을 만들었다. 공개 배포(main)는 건드리지 않고 별도 브랜치·폴더에서.

## 현황 점검(1단계)
- LLM 을 쓰는 곳은 `app/agent.js agentTurn`(브리프 해석) 하나뿐 — 브라우저가 `app/config.local.js`/localStorage 의 키로 api.anthropic.com 을 직접 부르고, 키가 없으면 규칙 파서 `scriptedTurn` 으로 폴백. 디자인 판단·검수(`core/gate.js`·`core/adcheck.js`·`core/lint.js`)는 API 를 안 쓴다.
- `app/config.local.js` 는 자리표시(`sk-ant-...`)만 있고 실제 키는 없음 → B 트랙은 **키를 서버에 넣어야** 돈다.
