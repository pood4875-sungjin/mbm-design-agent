# 2026-10-27 — 쉬운 모드(웹사이트형) 구현

**상태: 로컬 커밋(푸시 안 함).** 앱 코드(app/ · core/) 영향 없음, hub/ 만. 테스트는 hub 와 무관(돌리지 않음). 계획은 [같은 날 계획 기록](2026-10-27_쉬운모드_계획.md).

## 1. 무엇을 만들었나
- `hub/easy.html` — 디자이너가 아니어도 쓰는 **웹사이트형 입구**. 피그마식 편집기(`hub/index.html`)와 같은 문서(localStorage `studio.doc.<id>`)를 읽고 쓴다. 어느 쪽에서 고쳐도 다른 쪽에 그대로 보이고, 버튼 하나로 오간다(피그마 쪽 탭스트립 「쉬운 모드」 ↔ 쉬운 모드 머리띠 「전문가 편집기 ↗」, 결과 · 편집 화면에서는 같은 문서 · 같은 규격을 선택한 채로 연다 — `./#doc=<id>&f=<frame>`).
- 흐름: **홈 → 만들기 3단계 → 결과 갤러리 → 간단 편집**(한 화면에 목적 하나).

| 화면 | 주소 | 내용 |
|---|---|---|
| 홈 | `easy.html#/` | 큰 제목 + 「새로 만들기」 · 「예시로 먼저 보기」, 3단계 설명 카드, 내 작업(썸네일 · ⋯ 메뉴: 열기 · 전문가 편집기 · 복제 · 삭제), 예시로 시작 5 |
| 만들기 ① 내용 | `#/new` · `#/new/<예시>` | **빈칸 채우기 문장**(「[고객사]의 [채용 구분] 광고를 만들어요. 접수는 [시작]부터 [마감]까지, 모집 직무는 [직무]」) — 빈 칸은 주황, 예시/말에서 읽은 값은 점선, 직접 쓴 값은 실선. 접힌 추가 칸(시즌 · 고용 형태 · 근무지 · 슬로건 · 고지). **말로 적어도 돼요**: 한 줄 적고 「읽어서 채우기」 → 회사(…에너지 · …아이티 등 꼬리말) · 신입/경력 · 날짜 두 개 · 직무 · 근무지 · 시즌을 읽어 빈칸에(틀릴 수 있어 점선으로 보이게). 예시로 채우기 칩 |
| ② 그림 | | 키비주얼 끌어다 놓기/고르기(1600px 로 줄임) · 예시 그림 5 · 뽑은 색 미리보기(지면 · 글자 · 포인트 + 「어두운 그림이라 진한 지면 + 흰 글자」) · 색 자동 체크 · 로고 올리기 |
| ③ 매체 | | 매체 12곳 체크(규격 수) · 전부/해제/자주 쓰는 3곳 · 오른쪽 요약 카드(고객사 · 채용 구분 · 기간 · 그림 · 매체 n곳 · 규격 n종) · 「n종 만들기」(고객사 · 채용 구분 비면 꺼짐) |
| 결과 | `#/doc/<id>` | 이름(바로 고침) · 규격 수 · 「확인 필요 n」(누르면 그것만) · **전체 ZIP** · 매체별 ZIP · 카드 체크 → 「선택 내려받기」 떠 있는 바. 카드 = 미리보기(보이는 것부터 그림) · 크기 · 「고치기」 · PNG, 누르면 크게 보기. **한 번에 바꾸기 줄**: 글꼴 · 색 테마(그림에서 자동 · 밝게 · 진하게 · 흰 바탕 · 지면/글자/포인트 직접) · 키비주얼 바꾸기(색 자동) · 로고 바꾸기 · 내용 바꾸기(10칸 → 글자 반영 + 이름) · 처음 배치로 |
| 간단 편집 | `#/edit/<id>/<frame>` | 왼쪽 큰 미리보기 = 피그마 편집기와 **같은 `Editor`** 를 규격 하나짜리 그림자 문서 위에 띄움(룰러 · 좌표 · 라벨만 끔). 끌기 · 스냅 · 핸들 크기 · 안내선 · 두 번 눌러 글자 고치기 · 마퀴가 그대로. 선택하면 위에 작은 도구(가운데 · 맨 앞/뒤 · 복제 · 삭제). 오른쪽 카드: **글**(내용 · 크기 −/+ · 굵게 · 정렬 · 색 4 + 직접 · 지우기 · 글 추가 — 캔버스에서 고르면 그 칸으로) · **그림**(키비주얼 이 규격만/전부 바꾸기 · 꽉 채우기/다 보이게 · 그림 색으로 전체 맞추기 · 로고 바꾸기 · 네 귀퉁이 · 크기) · **배경**(색 + 모든 규격에) · **배치**(자동 · 글 왼쪽/그림 오른쪽 · 글 위/그림 아래 · 그림 전체 + 글 가운데(스크림 32%) + 모든 규격에 같은 배치) · 도움말. 되돌리기/다시 실행(이 규격, ⌘Z) · 이전/다음 규격 · 크게 보기 · PNG · 전문가 편집기에서 열기 |

- 글 내용 · 크기를 바꾸면 줄 수를 재서 **상자 높이를 자동으로** 늘린다(넘침 방지, 내보내기와 같은 canvas 측정).
- 색을 한 번에 바꾼 뒤 규격마다 배경 · 글자 **대비 3:1 미만이면 글자색을 보정**(팔레트 글자색 · 검정 · 흰색 중 가장 잘 보이는 것). 따로 칠한 배경이 있는 규격에서 흰 글자 + 흰 바탕이 되던 함정.
- **저장 용량**: 올린 그림(dataURL)을 규격 51개가 같은 src 로 들고 있어 그대로 저장하면 51배였다. 저장할 때 `@kv` · `@logo` 로 한 번만 쓰고 읽을 때 되돌린다(`doc.js serialize/hydrate`, 피그마 편집기도 같이 혜택). 실측: 10KB 그림 · 22규격 → 저장 70KB(치환 22곳).

## 2. 디자인 근거(레퍼런스)
- 빈칸 채우기 문장 + 세 가지 빈칸 상태(ux-patterns.md › Mad Libs). 받침 따라 바뀌는 조사 자리엔 빈칸 없음(의 · 부터 · 까지 · 는).
- 한 화면에 목적 하나 · 큰 버튼(industry-examples.md › 토스 UX 법칙 ③ 힉 · ② 피츠), 해요체 · 능동 · 한 줄(토스 UX 라이팅).
- 빈 상태 = 할 일 + 버튼(ux-patterns.md › Empty States). 큰 글씨 위계(ui-trends.md › Big Typography). 그림 위 글자 스크림 32%(ui-trends.md › Material 스크림 20~40%).

## 3. 확인
- 브라우저(JS, 패널 800 · 1440 · 375폭): 말로 적기 → 5칸 읽힘(마이다스 → 예시 자동) → ② 뽑은 색 → ③ 자주 쓰는 3곳 22종 → 만들기 → 결과 22카드 · 썸네일 · 색 테마 진하게(지면 #132144 · 글자 흰색) · 글꼴 Noto Sans KR · 내용 바꾸기(메인 문구 「마이다스\n경력 채용」 + 이름) · 처음 배치로(스크림 제거 · 왼쪽 정렬) · 올린 그림 전체 바꾸기 + 저장/다시 읽기 일치.
- 간단 편집: 글 내용 · 크기 68 → 72 · 배치 「그림 전체」(키비주얼 0,0,1100,800 · 스크림 · 가운데 · 흰 글자) · 되돌리기 · 로고 왼쪽 아래(64,680) · 캔버스 클릭 선택 → 오른쪽 칸 강조 · 끌기(64,140 → 307,310 스냅) · 가운데(550,400) · 배경 흰색 · 전문가 링크 `./#doc=…&f=…` → 피그마 편집기가 그 규격 선택한 채로 열림. 콘솔 오류 0(이전 `/hub` 슬래시 없는 주소의 404 만 남아 있던 것).
- 모바일 375: 가로 넘침 0, 머리띠 글자 줄바꿈 → 브랜드 글자 숨김 · nowrap 보정.
- 캡처: [홈](img/hub-easy/home.png) · [만들기 ①](img/hub-easy/new1.png) · [결과](img/hub-easy/doc.jpg).
- `npx serve` 는 `index.html` 을 `/hub`(슬래시 없음)로 돌려 상대경로 자산이 404 → 전문가 편집기 링크는 전부 `./#…` 로.

## 4. 남은 것
- 쉬운 모드 글 상자는 세로만 자동. 긴 글은 사용자가 크기를 줄여야 한다(자동 축소는 안 넣음 — 의도치 않게 작아지는 걸 피함).
- 배치 프리셋은 규격 비율을 안 가리고 같은 규칙. 긴 가로(2400×560)에서 「글 위/그림 아래」는 어색할 수 있다.
- 말로 적기 파서는 규칙(정규식)뿐. app/ 의 브리프 파서 · AI 판단과는 아직 안 이음.
- 공유 · 로그인 · 팀은 2차(서버). 저장은 브라우저.
