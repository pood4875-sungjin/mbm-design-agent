# 2026-11-23 좁은 창에서 스타일 단계 로고 칸이 사라지던 문제

## 증상
- 사용자 제보: 공개 주소 앱의 스타일 단계에서 PNG 로고가 들어가지 않는다. 같은 일이 여러 번 있었다.
- 보내 준 PNG 3개(LINE 2종, MIDAS)는 로고 처리 자체가 정상이었다. 배경 지우기와 여백 자르기가 모두 됐다.

## 원인
- app/index.html 의 머리글 로고 규칙이 클래스 이름만으로 걸려 있었다.
  - `.logo{…}` 기본 모양
  - `@media (max-width:768px){ .logo{display:none} }`
- 스타일 단계의 로고·흰색 로고·가로형·세로형 칸은 `kvthumb logo` 클래스를 쓴다.
- 그래서 창 폭이 768px 이하이면(좁은 창, 화면 나누기, 확대) 로고 칸까지 숨겨졌다. 키비주얼 칸만 보여서 로고를 넣을 수 없었다.
- 이전 테스트는 파일을 입력 칸에 바로 넣어서, 칸이 보이는지는 확인하지 못했다.

## 고친 것
- 네 규칙을 `header .logo` 로 좁혔다. 머리글 로고만 숨기고, 스타일 단계 칸과 이 소재만 견본(`.fimgsw.logo`)에는 닿지 않는다.
- 755px 창: 로고·흰색 로고 칸이 보이고 LINE 로고가 들어간다. 머리글 로고는 숨는다.
- 1400px 창: 칸 크기와 글자 모양이 그대로다.
