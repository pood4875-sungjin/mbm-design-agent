# 2026-10-12 밤 — 매체 규정 전수 검사 (사이즈·글자수·패딩·위치)

사용자 질문: 「광고소재 사이즈, 텍스트 개수, 패딩, 위치 규칙은 잘 지켜서 나오고 있는 건지 확인 한 번만 더 돌려줘.」

지금까지 케이스 장부(`node scripts/cases.mjs run`)는 **디자인 검수(core/adcheck.js)** 만 돌렸다 — 글자-주인공 겹침·로고 가림·빈 띠 같은 것.
**매체 규칙 검사기(core/lint.js lintArtifact)** 는 앱 안에서만 돌고, 장부 전체에 돌린 적이 없었다. 이번에 그걸 돌렸다.

## 한 것
1. `scripts/cases-lint.mjs` (새) — 전 케이스 × 전 광고 규격을 다시 그려 headless Chrome 에서 앱과 같은 식(app/measure.js measureDom)으로 재고(글자 역할·문구·줄 수·px·색·상자, 로고 상자, 오브젝트 상자, 글꼴, 투명 선언) `lintArtifact` + 보조 규칙을 돌린다.
   - `node scripts/cases-lint.mjs [id …] [--spec 규격id] [--keep]` → `ref/learned/cases/_out/lint/summary.json` · `lint-report.md` · `<id>.lint.json`
2. `scripts/lib/lint-extra.mjs` (새) — lint.js 가 안 보는 것: 로고 삽입 불가 규격의 로고(차단) · 템플릿 로고 영역(w·h)보다 큰 로고(경고) · 로고 높이 범위(카카오 hRange, 로고가 메인 카피를 대신할 때만) · 매체가 박아 둔 역할별 글자 px(자소설 fontSizes) · 에브리타임 오브젝트 상자(누끼일 때 너비 220~320·구역) · 규격별 「검사할 규정 데이터가 있나」(coverageOf) · dump-dom 되돌리기(decodeDump).
3. 테스트 `test/cases-lint.test.js` 9건. `npm test` 334 → **343 통과**.
4. kv-review 스킬에 한 줄: 「매체 규정 전수 검사: node scripts/cases-lint.mjs」.

### 측정 오탐 — 잡고 고친 것(검사 스크립트 쪽)
- 첫 실행에서 chars 차단 9건이 났으나(리멤버·캐치·카카오·알바몬 메인/서브) 전부 **오탐**: Chrome `--dump-dom` 이 U+00A0 를 `&nbsp;` 로 직렬화한 것을 안 풀어 「MIDAS&nbsp;IT」가 5자 더 세어졌다. `decodeDump` 로 풀고 나니 0. 테스트로 고정.
- `outside-drawn`(매체가 텍스트로 따로 받는 역할을 소재에 그림)은 규칙으로 두지 않았다 — 이미지 밖 글자 규정은 「소재에 안 그린다」가 아니라 「따로 전달한다」는 뜻이라, 이미지 안에 메인 카피가 있는 건 위반이 아니다.
- `logo-size` 에서 「별도 파일로 제출」(블라인드 96×96, 캐치 160×160)과 로고 파일 자체가 제출물인 규격(자소설 M채팅목록 300×180)은 제외 — 이미지 속 로고 영역이 아니다.

### 렌더러 버그 — 고친 것
- **잡다 PC 라벨 칩 4자**: 라벨 사다리는 「모집직무 : …」「고용형태」 둘뿐이라 둘 다 한도를 넘으면 마지막 후보가 그대로 그려졌다(「신입·경력」 5자).
  - `core/renderers/ad.js` byWidth: 라벨은 한도 안 후보가 없으면 `''` (이전 `cands[cands.length-1]`).
  - `core/renderers/ad.js` 720줄 뒤: 후보가 하나뿐일 때도 한도를 넘으면 비움. `want.label && copy.label` 일 때만 칩을 그림.
  - 근거 케이스 sep-open-recruit(employType 「신입·경력」). 정보 줄이 아니라 장식 칩이라 비우는 게 맞고, 지어내지 않는다.
  - 라운드 43 (`매체 규정 전수 검사 후 수정 — 잡다 라벨 칩 한도`): 경고 **32 → 32**, 92케이스 변화 없음(규격 단위 비교도 +/−/~ 0). 디자인 검수에는 영향 없음.

### 고치지 않은 것 — 규정 해석이 필요한 것
- **NAP DSP 비즈보드 1029×258 로고 47건**(로고 있는 케이스 전부 중 KV 를 못 쓴 경우): 규정 「썸네일 내 우측/상단 여백 8px, 120×46 로고」는 **썸네일 박스형** 수치다. 이 규격은 투명 PNG 오브젝트가 필수라 배경 있는 KV 는 안 쓰고(`kvUse: none`), 그때 렌더러가 **로고를 오브젝트로** 칸 폭의 2/3(209px)로 키운다(logoZone — 셀트리온·LX 예시 문법).
  - 썸네일(사진)이 있을 때(`kvUse: part`, 10건)는 로고가 17px 높이로 들어가 통과.
  - 로고가 오브젝트를 대신할 때 120×46 을 지켜야 하는지는 규정에 없다. 지키게 하려면 `rules.logo.w/h` 를 logoZone 캡으로 쓰면 되지만(한 줄), 그러면 오브젝트 자리가 거의 비어 디자인 검수(empty-band)가 늘 수 있다 → **사용자 판단**으로 남김.
