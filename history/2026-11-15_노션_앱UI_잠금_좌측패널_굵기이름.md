## 결정과 근거
- **굵기 이름 = 피그마와 같은 영문만**(Light·Regular·Medium·SemiBold·Bold·ExtraBold·Black), 숫자는 안 붙였어요. 근거: 이미지 11_18 표의 영문 칸이 피그마 글꼴 스타일 이름과 같고, 한글 칸(「약간 굵게」 등)은 사람마다 갈려요. 내보낸 SVG 를 피그마에서 열 때도 같은 이름이 떠요.
- **반영하기 = 버튼으로 한 번에**(시안 「실시간 반영이 아닌 버튼으로 일괄」). 고친 칸이 있으면 주 버튼(#0A74CC, L 40)으로 켜지고, 없으면 테두리 버튼이 꺼져 있어요. 고친 글은 다른 요소를 골라 패널이 다시 그려져도 남아요(초안). ⌘Enter 도 반영. 되돌리기는 한 걸음, 그리기는 한 번이에요.
  - 기본 정보·추가 행·필수 고지도 같은 버튼으로 반영해요(전에는 칸마다 바로 반영).
  - 시안은 켜진 버튼이 검정이지만 버튼 시스템(11-11) 주 버튼 색을 썼어요.
- **? 도움말**: 누르면 말풍선 + 패널 어둡게, 바깥 클릭·Esc 로 닫혀요(시안 10_17 1~3번).
- **「모든 소재에서 빼기」는 시안대로 뺐어요.** 이미 뺀 요소는 칸 아래 「모든 소재에서 뺐어요 · 다시 넣기」로 되살릴 수 있어요. 새로 「모든 소재에서 빼기」를 하는 길은 이제 없어요(소재 하나는 캔버스 Delete) → 정할 것.
- **잠금 목록은 한 곳**: `core/canon.js` `textPosLock`(매체 id 또는 규격 id 앞머리). `lockedMedia`(렌더러 틀 고침 막기 — 블라인드·캐치·에브리타임·카카오 전체 포함)와는 범위가 달라서 따로 뒀어요. 판정 함수는 `app/elselect.js` `textPosLocked`.
- 서브 문구·상세 문구엔 「자동」 꼬리표가 없어요. 서브는 11-10 결정(비우면 안 나옴)이고, 상세는 모집 직무 그대로라 자동 문구가 없어요.
