## 3. 어떻게 (기술)
- 저장소 쪽: `scripts/figma/export-frames.mjs`(zone.json·guide·SVG·PNG) → `figma-frames-build.mjs prep/post/manifest`(Plugin API ops) → **`scripts/figma/checklist8-figma.mjs`(새)** 8항목 글감 `_plan/checklist.json`.
- Figma 쪽: 플러그인 샌드박스에 `fetch` 가 없어 30KB ops JSON 을 **SVG `<text>` 캐리어**로 upload_assets 에 실어 올린 뒤 use_figma 에서 읽어 실행(새 방법, 이전 에이전트가 코드 붙여 넣기로 하던 것). 그림은 upload_assets nodeIds(60개씩) + curl `figma-frames-upload.mjs`. SVG 제작물은 올린 뒤 B 단계로 굵기(600→Bold 오독)·자간 복원.
- 이어받기: 이전 에이전트가 매체 12 + 표지까지 만들고 끊김(rate limit). 남은 것(판정 흐름·규칙 장부·샘플·비교·알바몬 B·자소설 2·당근 전체)을 이어 만들고 compare 는 t1014 를 넣어 다시 만들었다. 당근은 `core/media/daangn.json` 에 200×200 이 생긴 뒤 내보내기부터 다시.

## 4. 확인한 것
- 스크린샷: 자소설·리멤버·구글 ② 섹션(블록이 프레임 오른쪽, 2240 폭 규격도 자연스러움), 구글 580×400 블록, 자소설 요약, 판정 흐름 누끼 묶음, 규칙 장부 유형 판정, 샘플 카드(dongbu-flatbg), 당근 ②.
- 편집 가능: ③ SVG 프레임의 글자가 TEXT 노드(`findAll(TEXT).characters` 로 확인 — 당근 「자소서 없는 간편지원」「마이다스」…). 작업 프레임은 COMPONENT(복제해 쓰면 됨).
- PNG 대체: SVG 4MB 초과·가져오기 실패 0건. 로고 단색 변환(filter)은 SVG 단계에서 PNG 로 대체된 것이라 프레임 아래 「근사·대체」 줄로 표시.
- 올리기 실패 0 (flow 36/36 · samples 535/535 · compare 114/114 · SVG 234/234 · 캐리어 전부).
