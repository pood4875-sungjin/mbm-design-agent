# 2026-10-16 오후 — 지면은 비주얼이 우선(kvHarmony)

## 요청
사용자: 「배경 색은 비주얼에 어울리게 뽑아야대. 비주얼이 우선이야.」 (앱 생성 결과: 한샘 사무실 사진 위 브랜드 빨강 지면, ABL 캐릭터 누끼 위 분홍 틴트 — 로고 색이 지면을 정하고 있었음)

## 전에는
`core/field.js resolveField` 순서: 직접 고른 색 → 바탕 있는 그림의 변 색(kv-edge) → 분위기(kv-mood: 누끼 원본 팔레트·어두운 사진·채도 그라데이션 변) → **사진·누끼는 브랜드색**(brand-photo / brand-tint / brand-tint-warm / bridge) → 대표색(kv-colour) → 브랜드.
사진·누끼는 대부분 이음매도 분위기도 없어 브랜드(=로고 주색)로 떨어졌다.

## 바꾼 것
- `CANON.kvHarmony { photoFrom: 'edge', cutoutFrom: 'dominant', tint: 0.78 }` (core/canon.js).
- resolveField: kv-mood 다음, 흰 로고·브랜드 가지 앞에 **kv-harmony** 가지 — 사진은 글자 쪽 변 색(없으면 대표색), 누끼는 대표색(없으면 변 색). 어두운 지면 매체 → `brandDeep(base)`(흰 글자 4.5:1 까지 같은 색상 어둡힘, 135°) `kv-harmony-photo`/`kv-harmony`. 밝은 지면 매체 → `[mix(base, 흰, 0.78), 흰]` `kv-harmony-tint`.
- 브랜드색은 포인트(칩·날짜 상자·회사명 강조·textColour.brand)에만. 직접 고른 색(manual)은 여전히 최우선.
- 트레이스 규칙 `kvHarmony`. 규칙장부 `kv-harmony-field`(61라운드) — brand-photo(10-06)·warmLightBrand 틴트(10-14)·dark photo no-bridge(10-14) 대체.
- 테스트 3건 기대 갱신(ad.test 지면 읽기 · t1014 난색 틴트 · 어두운 사진 브릿지). 466/466.

## 확인 필요
- 누끼 대표색이 무채·베이지(ABL)면 지면이 탁해진다 — 대표색 셋 중 채도 있는 색(ABL 복숭아·민트)을 고를지, 아니면 디자이너처럼 브랜드색을 쓸지.
- 다른 세션(local_7f3bbb74)이 오늘 네이버·카카오·구글 틀을 손봄(ad204e2 까지) — 이 규칙은 그 위에 얹힘, 충돌 없음(작업 트리 깨끗한 상태에서 시작).
