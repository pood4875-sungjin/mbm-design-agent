# 2026-10-26: 피그마 UI 를 레퍼런스로 한 목업 — 홈 → 광고 소재

**상태: 로컬 커밋(푸시 안 함).** 앱 코드 영향 없음(hub/ 만).

## 1. 바뀐 방향
- 사용자: 앞의 hub/ 는 「구현」이 아니라 흐름을 짜자는 뜻이었고, 디자인은 피그마 UI(에디터 화면)처럼 통일하려 한다. 계획부터 맞춘 뒤(플로우 v2, 피그마 「중앙화」 페이지 섹션 197:2) 「피그마 구조를 참고해 메인 → 광고 소재 위주로 목업으로 볼 수 있게」.
- 결정(10-26 문답): 결과물 = 피그마에 그리기 · 통일 범위 = 에디터 전체를 피그마 문법으로 · 홈 사이드바 = 2차 · 입력 단계 = 따로 두지 않고 새 탭이 바로 작업 화면.
- 앞서 만든 iframe 방식 hub(실제 도구를 탭 안에 띄움)는 지우고 목업으로 바꿨다.

## 2. 목업(hub/)
- 피그마 UI3 라이트 문법: 탭 바 40(홈 아이콘 · 작업 탭 · +) · 왼쪽 패널 240 · 캔버스 · 오른쪽 패널 240 · 아래 떠 있는 툴바.
- 대응: 왼쪽 File/Assets → 입력(캠페인 정보 · 에셋 · 브랜드 컬러) / 레이어(페이지 = 차수 하 · 중 · 상 · 보조, 섹션 = 매체, 프레임 = 규격) · 캔버스 = 빈 상태(브리프 끌어다 놓기) → 매체별 섹션의 규격 프레임 · 오른쪽 Design/Prototype → 디자인(선택 규격 크기 · 배치 · 글자 · 내보내기 · 승인) / 검수 · Share → 내보내기 · 툴바 = 선택 · 손 · 코멘트 · 생성.
- 흐름: 홈 → 광고 소재 → 새 탭(빈 작업 화면) → 샘플 · 파일로 입력 → 생성 → 보드(하 20) → 규격 고르기(오른쪽 패널) → 승인 → 차수 페이지 바꾸기 → 내보내기 → 탭 닫기 확인. + 새 탭 → 같은 카드. MBM → 준비 중 안내. 작업 내역 팝오버.
- 보드 그림은 GS에너지 샘플 렌더 51장(history/img/2026-10-22_ai-samples-bg). 규격 목록 hub/mock-data.js(core/media.js + _extract.json 차수). 실제 생성 · 내보내기 · 검수 값은 없다(목업 표시).
- 바로 보기: hub/#empty(빈 작업 화면) · hub/#board(생성된 보드).
- 엘리베이터 카드는 「다음 단계」 안내(이번엔 광고 소재 위주).

## 3. 확인
- 브라우저에서 위 흐름 전부 클릭으로 확인, 콘솔 오류 없음. 1440×900 스크린샷으로 홈 · 빈 작업 화면 · 보드 눈 확인(섹션 제목과 프레임 이름 겹침 · 보이지 않는 탭 줌 5% 고침).
