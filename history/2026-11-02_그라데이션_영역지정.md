# 2026-11-02 — 피그마식 그라데이션 편집기 · 키비주얼 영역 지정

## 요청
- 사용자 「그라데이션은 직접 설정할 수 있는 기능을, 피그마와 동일한. 노션 확인해 봐」(Notion N3 색상 스타일 설정: 단색/그라데이션 분리, 1차는 자동 추출 색).
- 사용자 「위치에 따라 뭐 보여지는 게 다른가? 기능 이상한데 반영도 안 되고. 차라리 누르면 영역 지정을 내가 할 수 있게」(Notion N4 키비주얼).

## 원인 (영역)
점 찍기는 그림을 덮어 자르는 경로(coverPos·subjectCrop)만 읽었다. 칸에 통째로 넣는 누끼는 값을 안 읽어 동서식품 누끼는 44규격 중 35규격이 그대로, 배경형 뿌리 그림과 AI 그림 상자도 안 읽었다.

## 바꾼 것
- **영역 지정** `app/kvfocus.js`: 끌어서 그리기 · 안쪽 끌어 옮기기 · 네 모서리 크기 · 방향키 · Esc·「자동으로」 해제. 점 찍기 없앰(그냥 누르면 아무 일 없음).
- **렌더** `core/renderers/ad.js regionFit`: 그린 뒤 모든 그림 칸·지면 전체 그림에 영역을 맞춘다. 바탕 있는 그림은 칸을 덮고, 덮으면 잘리는 납작한 칸은 칸을 그림만큼 줄인다(자소설 틀 칸은 유지). 지정이 있으면 AI 그림 상자보다 먼저.
- **그라데이션** `core/gradient.js` · `app/gradedit.js`: 선형·방사형 · 각도(숫자·다이얼·90° 돌리기) · 뒤집기 · 막대(눌러 추가, 끌어 이동, Delete 삭제, 화살표) · 색 목록(위치 %, 색, 헥스, 삭제). 시작값은 자동 지면색. 인테이크와 작업 화면 인스펙터 둘 다. 끄는 동안은 편집기만 움직이고 놓을 때 한 번 다시 그린다.
- 단색 전용 규격은 매체 규정대로 단색으로 접힌다.
- 카드를 다시 그려도 스크롤이 맨 위로 튀지 않게(`reslotStyle`).

## 피그마와 다른 점
- 각진(Angular)·다이아몬드 없음: SVG(피그마 편집용) 내보내기가 옮기지 못한다.
- 정지점 투명도 없음: 광고 지면은 불투명.
- 캔버스 위 손잡이 없음: 그라데이션이 규격별이 아니라 캠페인 공통이라 패널에서 정한다.

## 확인
- 테스트 615 통과(새: gradient-edit 5, kvfocus 영역 3).
- 3케이스(일러스트·사진·누끼) × 44규격, 작은 영역 기준: 안 바뀜 0, 영역 다 보임 35·40·37, 그림 없는 규격 8·3·6은 로고·전달물 등 제외. 95% 미만은 구글 300×600(87~93%)·당근 피드 90%·리멤버 잡 사이드 누끼 1건(미해결).
- 브라우저(GS에너지 샘플): 끌기·옮기기 → 13프레임 중 그림 규격 전부 다시 그려짐. 막대 눌러 추가 49%, 끌어 23%, 헥스 변경 → 지면 `linear-gradient(180deg,#E0F8FF 0%,#E2401A 23%,#ACEEFF 100%)`, 인스펙터 스크롤 유지.

## 남은 것
- 리멤버 530×200 누끼에서 영역이 안 보이는 1건 재현 확인.
- 그림에 자기 배경이 있으면 지면을 바꿔도 그림 칸 안의 원래 배경은 남는다. 배경 제거(누끼) 선택은 별도.
- hub 작업 화면에는 아직 없음(`app/` 만).
