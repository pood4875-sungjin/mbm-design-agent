# 2026-11-10 저녁 편집 UI hub 2차 — 탭줄 머리 · 오른쪽 패널 머리 · 캔버스 이름표

## 왜 했나요
사용자가 「왼쪽 입력만 남기라던 게 반영 안 됐다, 편집 툴·버튼도 다 피그마 스타일로」라고 했어요.

- 반영이 안 보인 까닭: 고친 코드가 이 세션 브랜치에만 있었어요. main 서버(4796)로 보면 옛 화면이 떠요. 이 세션 서버는 4798이에요.
- 그래서 왼쪽 말고 나머지(머리줄·오른쪽 패널·캔버스)도 hub/pro 편집 화면에 맞췄어요.

## 바꾼 것 (근거: hub/fui/ui3.css)
- **머리줄**: hub 탭스트립처럼 바꿨어요.
  - 연회색 40px 줄이에요. 맨 왼쪽은 홈 칸(46px)이에요.
  - 지금 캠페인은 흰 탭(이미지 아이콘 + 이름)으로 보여요. 옆에 + 칸(44px)이 있어요.
  - 뒤로 버튼은 홈 칸이 대신해요.
- **오른쪽 패널 머리(48px)**: 선택하기·전체 승인·내보내기를 머리줄에서 패널 맨 위로 옮겼어요.
  - 내보내기만 주 버튼(파랑)이고, 나머지는 고스트 버튼이에요.
  - 패널을 닫았거나 폰 폭이면 캔버스 오른쪽 위에 떠요.
- **오른쪽 패널 안**
  - 탭(디자인·검수)은 글자 탭이에요.
  - 「모든 소재」 같은 꼬리표는 18px·r4 회색이에요.
  - 키비주얼·로고 칸은 점선 대신 r5 연회색 칸이에요. 가로형·세로형은 한 줄에 둘씩 서요.
  - 버튼은 r5, 「키비주얼 제거」 같은 링크는 고스트 24px이에요.
  - 프리셋 칩(글자 세로 위치·정보 태그 등)은 hub 세그먼트 모양이에요. 고를 게 많으면 두 줄로 내려가요.
  - 매체 추가는 큰 카드 대신 32px 체크 행이에요.
- **캔버스 이름표**: 소재 이름·줄 머리가 줌을 따라 작아지던 걸 바꿨어요.
  - 화면에서 늘 11px·12px 한 줄로 보여요(줌 역수 `--iz`, 최대 3배).
  - 고른 소재는 이름과 테두리가 파랑이에요.
