# 2026-11-10 저녁 편집 UI hub 2차 — 탭줄 머리 · 오른쪽 패널 머리 · 캔버스 이름표

## 왜 했나요
사용자가 「왼쪽 입력만 남기라던 게 반영 안 됐다, 편집 툴·버튼도 다 피그마 스타일로」라고 했어요.

- 반영이 안 보인 까닭: 고친 코드가 이 세션 브랜치에만 있었어요. main 서버(4796)로 보면 옛 화면이 떠요. 이 세션 서버는 4798이에요.
- 그래서 왼쪽 말고 나머지(머리줄·오른쪽 패널·캔버스)도 hub/pro 편집 화면에 맞췄어요.

## 바꾼 것 (근거: hub/fui/ui3.css)
- **머리줄**: hub 탭스트립처럼 바꿨어요.
  - 연회색 40px 줄이에요. 맨 왼쪽은 홈 칸(46px)이에요.
  - 지금 캠페인은 흰 탭(이미지 아이콘 + 이름)으로 보여요. 옆에 + 칸(44px)이 있어요.
  - 뒤로 버튼은 홈 칸이 대신해요.
- **오른쪽 패널 머리(48px)**: 선택하기·전체 승인·내보내기를 머리줄에서 패널 맨 위로 옮겼어요.
  - 내보내기만 주 버튼(파랑)이고, 나머지는 고스트 버튼이에요.
  - 패널을 닫았거나 폰 폭이면 캔버스 오른쪽 위에 떠요.
- **오른쪽 패널 안**
  - 탭(디자인·검수)은 글자 탭이에요.
  - 「모든 소재」 같은 꼬리표는 18px·r4 회색이에요.
  - 키비주얼·로고 칸은 점선 대신 r5 연회색 칸이에요. 가로형·세로형은 한 줄에 둘씩 서요.
  - 버튼은 r5, 「키비주얼 제거」 같은 링크는 고스트 24px이에요.
  - 프리셋 칩(글자 세로 위치·정보 태그 등)은 hub 세그먼트 모양이에요. 고를 게 많으면 두 줄로 내려가요.
  - 매체 추가는 큰 카드 대신 32px 체크 행이에요.
- **캔버스 이름표**: 소재 이름·줄 머리가 줌을 따라 작아지던 걸 바꿨어요.
  - 화면에서 늘 11px·12px 한 줄로 보여요(줌 역수 `--iz`, 최대 3배).
  - 고른 소재는 이름과 테두리가 파랑이에요.

## 덧붙임 — 그림·로고 말로 고치기: 배경 제거 (POST /api/kv-edit)
- 사용자: 「배경 제거해줘 같은 것도 연결된 Claude 로 돌려서 확실하게」.
- Claude 는 픽셀을 직접 못 고쳐요. 그래서 판단과 검수를 Claude 가, 픽셀은 로컬 누끼 도구(scripts/kv-cutout.py)가 맡아요.
  1. 계획: Claude(sonnet)가 원본을 보고 할 일(cutout/none)과 누끼 옵션을 골라요.
  2. 실행: 누끼 도구로 투명 PNG를 만들어요. 남은 면적이 3% 미만이거나 95%를 넘으면 수치로 바로 실패 처리해요.
  3. 검수: 원본 | 남색 | 주황 세 칸 비교 그림(server/kvreview.py)을 Claude(opus, 생각 깊게)가 봐요. 부분마다 남음·지워짐을 적고 1~5점을 매겨요. 잃은 부분이 있으면 2점 이하예요.
  4. 4점 이상이면 넣고, 3점은 「작은 흠」 표시와 함께 넣어요. 2점 이하는 그림을 바꾸지 않고 이유만 보여요. 최대 3번 시도해요.
- 결과는 이 소재만 새 그림이에요(「이 소재 그림 바꾸기」와 같은 길이라 되돌리기 한 걸음).
- 실측
  - 로켓(desk-13): 1번 시도 4점, 17~22초.
  - GS 장면 일러스트(t1014-gs2026): 3번 다 하늘 띠가 남아 「깔끔하게 못 땄어요」로 그대로 둬요(64초).
  - 고치기 전에는 투명 0% 결과나 다리가 지워진 결과도 4점으로 통과했어요. 숫자 검사, 세 칸 비교, 항목 목록, 생각 깊게로 막았어요.
- 공개 앱(서버 없음)에서는 「로컬 앱(Claude 연결)에서 돼요」로 안내만 해요.
- 테스트: test/kvedit-1110.test.js 5개(옵션 허용 목록 · 할 수 없는 지시 · 프롬프트). 전체 885 통과.

## 덧붙임 — 그림 말로 고치기 넓힘 (사용자 「자연어로 할 수 있는 건 Claude 가 다, OpenAI 는 추후」)

- 규칙(크게·작게·옮기기)은 지시를 다 알아들을 때만 바로 처리하고, 남는 말이 있으면 Claude 로 넘겨요. 전에는 「글자랑 안 겹치게 … 작게」를 규칙이 「작게」만 보고 처리했어요.
- 시키지 않은 누끼는 버려요(계획 지시문 + 서버 안전장치). 실측: 「안 겹치게 작게」「반투명」에 누끼를 붙였었어요.

- 앱 실측(로켓 KV, 자소설 PC 프리미엄 팝업)

  - 「로켓 머리 부분만 크게 보이게」 영역 + 자리·크기, 12초
  - 「반투명하게 하고 15도 기울여줘」 외관(55%·15°), 6초
