## 한 것
- **왼쪽 = 입력 패널 하나**: 레일(입력·에셋·파일·검수)·탭 코드 걷음. 폭 284. hub/fui/ui3.css 문법 — 섹션 머리 40·12px 600, 라벨 11 회색 24 높이, 입력 32·r5·#F5F5F5·11px(textarea 16 행간), 섹션 사이 1px 선, 고른 요소의 묶음은 선택 파랑(--sel) 바탕. 「모든 소재에서 빼기」 → 눈 아이콘(빠지면 눈 감김·누르면 다시 넣기), 「글자에 반영」 → 브리프 머리 btn.sm, 기본 정보는 접는 섹션(chev). 추가 행 ↑↓× 는 24 아이콘 버튼.
- **머리 48**: 작업 화면만 불투명 판·아래 1px 선·유리/그림자 없음, 로고 글자 13/600.
- **레퍼런스 칸 제거**: 인테이크 칸·안내문·오른쪽 섹션·업로드 함수·CSS. `style.references` 저장값과 normalizeStyle 은 그대로(옛 캠페인 깨지지 않게).
- **회전**: `overrides.elements.kv|logo.rot`(°, -180~180으로 접음). `core/elementedit.js` patchBox 가 그 층 transform 끝에 `rotate()` + `data-rot`. 녹임 마스크는 같은 층이라 같이 돈다. `core/svgexport.js` 는 data-rot 층의 회전을 잠깐 빼고(자식 상자가 회전 전 값) 그린 뒤 `<g transform="rotate(a cx cy)">`. 사진형 뒤집기 잠금도 풂(같은 결정). UI = 외관 「회전」 행(칸·90°·좌우·상하, hub 모양). 사진형을 돌리면 「녹임 층이 같이 돈다」 안내.
- **색 스타일 「+ 사용자 색」**: `c.swatches`(최대 8, 렌더엔 안 씀). 스타일 머리 +, 행마다 −, ⌘Z 됨. 모든 색 고르기 칸에 `list="mbmSwatches"` — 크롬 색 창에 견본으로 뜬다(캠페인 3색 + 사용자 색).
- **고침 1 — 로고 이 소재만**: 원색 로고만 바꾸면 캠페인의 옛 흰색 로고를 물려받아 어두운 지면에서 옛 로고가 그대로 보였다 → 이 소재가 따로 올린 흰 로고가 없으면 흰 자리를 비워 새 로고를 반전해 쓴다(`withArtLogo`).
- **고침 2 — 콘솔 404 2건**: `app/config.local.js`(로컬 키 파일, 없음) → 로컬 호스트에서만 부르고 서버(server.mjs·serve.py)는 없으면 빈 JS 200 / `favicon.ico` → 인라인 SVG 아이콘.
