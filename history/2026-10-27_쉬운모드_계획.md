# 2026-10-27 — 쉬운 모드(웹사이트형) 계획

**상태: 계획. 구현 기록은 같은 날 `_2` 파일에.**

## 1. 요청
- 피그마 스타일 편집기는 잘 됐으니 **그대로 유지**.
- 디자이너가 아니거나 피그마를 안 쓰는 사람도 쓸 수 있게 **웹사이트 느낌의 쉬운 UX**를 따로.
- 편집 기능은 광고 소재 쪽에서 어느 정도 유지.
- 계획 → 구현까지 밤 사이.

## 2. 결정
- **두 입구, 한 문서.** `hub/index.html`(피그마 편집기)와 `hub/easy.html`(쉬운 모드)이 같은 localStorage 문서(`studio.doc.<id>`)를 읽고 쓴다. 어느 쪽에서 고쳐도 다른 쪽에 그대로 보인다. 둘 사이는 버튼 하나로 오간다(「전문가 편집기」 ↔ 「쉬운 모드」).
- 쉬운 모드는 **한 화면에 목적 하나**(토스 UX 법칙 ③ 힉의 법칙, industry-examples.md): 홈 → 만들기 3단계 → 결과(갤러리) → 간단 편집.
- 문구는 **해요체 · 능동 · 한 줄**(industry-examples.md › 토스 UX 라이팅). 큰 글씨 위계(ui-trends.md › Big Typography).
- 내용 입력은 **빈칸 채우기 문장**(ux-patterns.md › Mad Libs): 받침 따라 바뀌는 조사 자리엔 빈칸을 안 둔다(의 · 부터 · 까지 · 는). 빈칸 상태 셋: 예시/말에서 읽은 값(점선) · 직접 쓴 값(실선) · 빈 곳(강조).
- 빈 상태는 「할 일 + 버튼」(ux-patterns.md › Empty States).
- 피그마 쪽 코드(canvas.js · doc.js · export.js)는 **그대로 재사용**. 간단 편집기는 같은 `Editor` 를 프레임 하나짜리 그림자 문서 위에 띄우고 룰러 · 좌표 · 라벨만 끈다. 끌기 · 핸들 크기 · 스냅 · 안내선은 그대로 살아 있다(편집 기능 유지).

## 3. 화면(IA)
| 주소 | 화면 | 내용 |
|---|---|---|
| `easy.html#/` | 홈 | 큰 제목 + 「새로 만들기」, 3단계 설명, 내 작업 카드, 예시로 시작 |
| `#/new` | 만들기 | ① 내용(빈칸 문장 + 말로 적기 + 예시로 채우기) ② 그림(키비주얼 올리기/예시 고르기 · 로고 · 색 자동 미리보기) ③ 매체(체크 · 전부/추천) → 만들기 |
| `#/doc/<id>` | 결과 | 매체별 갤러리(미리보기 · 크기 · 확인 필요 표시), 전체/선택 ZIP, 한 번에 바꾸기(글꼴 · 키비주얼 · 색 테마 · 내용), 전문가 편집기 열기 |
| `#/edit/<id>/<frame>` | 간단 편집 | 왼쪽 큰 미리보기(끌기 · 크기 가능) · 오른쪽 「글 · 그림 · 배경 · 배치」 카드, 되돌리기, 이전/다음 규격, PNG, 전문가 편집기로 이 규격 열기 |

## 4. 간단 편집기에서 되는 것
- 글: 내용 · 크기(−/+) · 굵게 · 색(팔레트 + 직접) · 정렬 · 추가/삭제. 캔버스에서 클릭하면 그 글 칸으로 이동.
- 그림: 키비주얼 바꾸기(이 규격만/전체) · 채우기/맞추기 · 색 자동. 로고 바꾸기 · 크기 · 네 귀퉁이 위치.
- 배경: 색 고르기, 전체 규격에 적용.
- 배치: 자동 · 글 왼쪽/그림 오른쪽 · 글 위/그림 아래 · 그림 전체 + 글 가운데(스크림 32%, ui-trends.md › Material 스크림 20~40%).
- 선택한 것: 가운데, 복제, 앞/뒤, 삭제. 방향키 · ⌘Z.

## 5. 안 하는 것(전문가 편집기로)
- 제약 · 자동 레이아웃 · 효과 · 혼합 모드 · 선 · 레이어 트리 · 페이지 · 룰러/간격 재기. 「전문가 편집기로 열기」가 같은 규격을 선택한 채로 연다.
