# 2026-11-23 피그마식 채우기(Fill) 1차 — 배경 · 글자 · 상자

사용자 요청: 「컬러편집은 피그마처럼 — 단톤·그라 설정, 방향 설정, 추가 레이어 쌓기」(피그마 Fill 패널 · 그라데이션 편집 캡처 2장).
정한 것: 범위 = 배경 + 글자 + 도형·박스. 1차 = 패널 통합 + 층 쌓기 + 정지점 불투명도. 캔버스 방향 핸들은 2차.

## 바뀐 것
- **채우기 모델 `core/paint.js`(새 파일)**
  - 칠 종류: 단색 · 선형 · 방사형 · 이미지(배경만).
  - 층마다 불투명도와 숨김, 그라데이션은 정지점마다 불투명도(a).
  - CSS 로 바꿀 때 불투명도를 색(rgba)에 굽는다.
  - 각진(angular)·다이아몬드는 SVG(피그마 편집용)로 못 옮겨서 뺐다.
- **패널 `app/fillpanel.js`(새 파일)**
  - 목록: 위층부터 한 줄(끌기 · 견본 · 헥스/종류 · % · 눈 · 빼기), 머리 + 로 층 더하기, 끌어서 순서 바꾸기.
  - 팝업: 종류 탭, 색 판(채도·명도), 색상 막대, 불투명도 막대, 스포이드(Chrome), 헥스·%.
  - 그라데이션: 각도 · 90° · 뒤집기 · 막대(누르면 추가 · 끌기 · Delete) · 정지점 목록(위치 · 색 · % · 빼기).
  - 이미지: 고르기 · 꽉 채우기/전체 보기/반복 · 반복 크기 · 가로·세로 위치.
  - 끄는 동안은 미리보기만, 놓으면 한 번 저장(되돌리기 한 걸음).
- **배경(스타일 단계 · 오른쪽 패널)**
  - 맨 아래 「지면」 줄: 자동/단색/그라데이션, 불투명 고정, 「자동으로 되돌리기」.
  - 그 위 채우기 층: `style.background.layers`.
  - 예전 배경 이미지 한 장(`background.image`)은 층 하나로 옮긴다(`core/style.js bgLayersOf`).
  - 렌더러 `withBgImage` 가 층을 아래부터 쌓는다(이미지 = data-bg-image, 단색·그라데이션 = data-bg-fill).
  - 지면 그라데이션은 정지점 불투명도를 걷는다(`core/field.js`).
- **글자 「칠」(요소 패널)**
  - 같은 목록·팝업.
  - 한 장 단색이면 예전 값(색 · 불투명도 · 숨김)으로 저장하고, 여러 겹·그라데이션이면 `elements[id].fill` 에 저장한다.
  - 렌더: 글자 모양으로 자른 배경(background-clip:text). 대표 색을 color 에 둬서 대비 검수가 읽는다.
  - 글자 일부를 고른 상태(범위 서식)는 예전 단색 줄 그대로다.
- **상자 칠(새)**
  - 배경이 있는 요소(알약·버튼 등)에 「상자 칠」 칸이 생긴다. `elements[id].bfill`.
  - 상자 요소의 글자 칠은 안쪽 span 으로 자른다.
- **SVG 내보내기**
  - 글자 칠 층마다 그라데이션 정의를 하나씩 만들고 같은 글자를 겹친다.
  - 자른 배경 사각형은 그리지 않는다.
  - 배경 층은 기존 여러 겹 배경 처리 그대로다.
- **정리**
  - 예전 그라데이션 편집기 `app/gradedit.js` 를 지웠다.
  - 배경 이미지 칸(`bgImageHtml`·`bindBgImage`)을 지웠다.

## 확인
- 로컬 앱 스타일 단계: 지면 줄 팝업(선형, 불투명 — % 없음), 층 2장 더하기, 위층 선형 + 투명도 막대가 나왔다.
- 소재 생성 → 메인 문구 칠을 선형(진회색→빨강)으로 바꿨다. 보드, PNG 래스터, SVG(그라데이션 정의 1개) 모두 같은 그라데이션이었다.
- 상자 칠은 단위 테스트로만 확인했다(GDN 소재에 알약이 없었다). 앱 화면 확인은 남았다.
