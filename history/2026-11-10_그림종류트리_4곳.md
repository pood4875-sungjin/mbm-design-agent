# 2026-11-10 (10) — 그림 종류 트리로 다시 나누고 4곳 고침

사용자: 「그림 종류는 크게 누끼 / 이미지. 누끼는 캐릭터(다수·1개) / 오브젝트, 이미지는 실사 / 그래픽, 그래픽은 오브젝트+배경 / 패턴. 오브젝트+배경이면 오브젝트가 잘 보이면서 배경색이 자연스럽게 연결」 → 지금 코드와 대조해 다른 4곳 → 「4개 다」.
예시 로고: 사용자가 준 MIDAS 회색 워드마크. 사용자가 보낸 예시 그림(걷는 사람들·제일약품 아이소메트릭·소파 두 사람·3D 얼굴·별 상자·패턴 2)은 대화에만 붙어 파일로 못 열었다 — 제일약품은 케이스 midas-jeil-iso 로 대신, 나머지는 파일 받으면 넣기.

## 바꾼 것
1. **캐릭터 여럿 / 사물 여럿** — `core/kvtypes.js` 새 세분 `cutout-group-character`(머리 봉우리 ≥ 3 또는 세로로 선 주인공, 조각 ≤ 7). `cutout-group` 은 「여러 오브젝트 떼」. 떼 11건: 캐릭터 5(ABL 2·고양이·캐릭터 떼·한샘 블록*) / 사물 6(책·상자·트럭·물류·흩어진 아이콘). *한샘 색 블록은 예전부터 캐릭터로 잘못 잡히던 것(남은 문제).
2. **오브젝트 + 배경은 오브젝트가 잘 보이게** — `core/renderers/ad.js` 틀 이미지 칸(bgRule)에서 그림 전체 덮기 대신 오브젝트 상자가 칸에 **통째로 들어가는 데까지** 당겨 키움(`subjectCrop fit`). 처음엔 「덮기」로 당겼다가 GS에너지 사람·삼성 3D·NIFCO 글자·파라타 오브젝트가 칸 변에서 잘려 「맞추기」로 바꿈.
3. **실사 판정 보강** — `core/palette.js` 결 거칠기 ≥ 0.03 + 같은 색 면 < 40%(`flatFill`, 이미 재던 값) → 실사. fig-32(흰 바탕 세 사람)·hdot-hall(세미나홀) 2건 바로잡힘(remeasure), 그래픽 오인 0(bc·fig-08·20·24 는 안 걸림).
4. **여럿 넣을 때 크기** — 모서리 칸에서 사물 떼가 칸보다 가로로 길면 칸 높이를 채우게 키우고 바깥으로 넘침(70% 이상 보이게). 캐릭터 떼는 키우면 가장자리 얼굴이 잘려서(ABL 곰) 안 키움. 세로 띠·열 칸은 통째로(10-19 자소설 160×600 결정 지킴 — 처음 넣었다가 테스트가 잡음).
