# 2026-10-28 — 생성이 흘러나오게(피그마 메이크식) · 광고 소재 · 엘리베이터

**상태: 로컬 커밋(푸시 안 함).** hub/ 만, 앱 코드 영향 없음. 테스트는 hub 와 무관(돌리지 않음).

## 1. 사용자 피드백 → 방향
- 「생성되는 느낌이 촤촤작 나야 한다. 피그마 메이크 같은 흐름이어야 한다」 — 어제까지는 가운데에 진행 막대 하나만 띄웠다가 끝나면 22장이 한꺼번에 떴다.
- 바꾼 것: **읽어서 만들기를 누르면 바로 작업 화면으로 넘어가고, 그 위에서 단계가 눈에 보이게 흘러간다.**

## 2. 만든 것(hub/studio.js `startGen` · `runGen`, studio.css 「생성 흐름」)
① 왼쪽 **읽은 값** 칸이 비어 있다가 **한 글자씩 타이핑**되며 채워진다(고객사 → 채용 구분 → 접수 시작 → 마감 → 직무, 날짜 칸은 한 번에). 타이핑 중인 칸은 파란 테두리, 끝나면 살짝 반짝.
② 가운데에 **매체별 뼈대 카드**(규격 비율 그대로 회색 반짝임)가 먼저 깔리고, 머리에 「규격을 그리는 중 n / 22」 + **진행 로그**(「말에서 읽었어요 · 고객사 · 채용 구분 …」 → 「그림에서 색을 뽑았어요 ■■■」 → 「자소설닷컴 그리는 중…」 → 「자소설닷컴 11종 ✓」 … → 「다 그렸어요 · 검수 통과」). 로그는 최근 6줄, 진행 중 줄은 파란 점이 깜빡.
③ 썸네일이 준비되는 대로 **카드가 하나씩 톡 들어온다**(최소 90ms 간격, 엘리베이터는 160ms). 다 되면 저장 · 일반 결과 화면으로 바뀌고(카드 클릭 → 오른쪽 편집) 토스트.
- 「기다리지 않고 다 보기」 버튼 → 남은 것 즉시. `prefers-reduced-motion` 이면 처음부터 즉시.
- 생성 중 왼쪽 입력은 잠금, 머리띠 상태 「그리는 중…」. 도중에 홈으로 나가면 흐름을 버림(문서는 이미 완성이라 저장은 됨).
- 엘리베이터도 같은 흐름(칸 타이핑 없음, 장면마다 「장면 n ✓」).
- 지운 것: 옛 `showLoading`(진행 막대 카드)과 `.loadbox` CSS.

## 3. 확인(브라우저 JS · 1440폭)
- 광고 소재 「GS에너지 … 신입 공채」 자주 쓰는 3곳 → 0.9초: 칸 타이핑 중 + 뼈대 22장 · 2.1초: 4/22 들어옴 · 약 4초: 22/22, 로그 6줄, 저장됨. 51규격(마이다스아이티)도 동일, 「기다리지 않고 다 보기」 → 0.9초 안에 끝. 엘리베이터 3장면 → 장면 1·2·3 ✓. 콘솔 오류 0.
