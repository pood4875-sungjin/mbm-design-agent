- 「룰 기반 말고 클로드 계정 연결했을 때 얘가 어떻게 디자인하는지 테스트」 → 토큰 없이(구독) 가능한 건 로컬 Claude Code 뿐. 담당자 배포 앱은 API 키 또는 수확한 시안 틀.
- 범위: **키비주얼로 새 배경 디자인 자체**(그라데이션·도형·스크림·합성) + **타이포 자유**, 규격·가이드는 검수기가 강제. 픽셀 그림 생성은 아님(HTML/CSS/SVG).
- 취향 규칙 1차(대문자 아이브로우·그라데이션 글자·칩·글로우 금지)는 「다채롭지 못하다」로 폐기 → **규칙 둘뿐: 양의 자간 금지 · 장평 금지**(`docs/freedesign-rules.md`).

## 만든 것
- `server/freedesign.js` + `POST /api/freedesign`(`server/server.mjs`), `/api/health.freedesign`: 프롬프트(규격 규칙·브리프·kvMeta·청사진 수치·`docs/freedesign-rules.md` 전문) → 엔진 `claude-code`(`claude -p --output-format json`, KV·로고는 임시 파일 + Read) / `api` → HTML 추출·검증(루트·크기·역할·브리프 문구 외 금지·글자 수·로고·글꼴·외부 URL + 자간·장평) → 위반 시 사유 붙여 1회 재요청.
- `app/freedesign.js` + `core/freetpl.js`: 인스펙터 「대화로 시안 뽑기」 → 큰 창(규격 select·엔진 표시·대화·결과 카드) → 카드마다 검수 배지(measure → lint → adcheck → gate) · 「이 안으로 쓰기」(variants `kind:'free'`, `renderAd` 맨 앞 분기 `style.free.tpl` — 보드·미리보기·내보내기·SVG 같은 길) · 「다시: 말로 수정」(history·prev) · 「자유 시안으로 저장」(localStorage `mbm-free-templates`, 글자/KV/로고 자리표시) → 같은 규격 「다른 시안 보기」 맨 앞.
- 스킬 `/design-free <케이스> <규격,…>` + `scripts/freedesign-{brief,render,run}.mjs`.
- 테스트 709/709(freedesign 8 · freetpl 3).
