## 2. 화면 구조(`app/index.html`)
| 자리 | 내용 |
|---|---|
| 왼쪽 256 `#leftPanel` | 캠페인 이름 · 「초안 · 검수 완료 n/m」 · 브리프 칸 · 「글자에 반영」 · 프롬프트(`onCommand` 그대로) |
| 가운데 `#viewport` | 눈금자(`app/ruler.js`, 고른 프레임 범위 파랑) · 규격 프레임. 패널이 덮지 않아 보드가 가운데 폭을 다 쓴다 |
| 오른쪽 288 `#inspector` | 디자인/검수 탭 · 범위 표시 · 값 편집 |

- hub 처럼 붙박이 패널 + 선으로 나눈 섹션. 유리 카드 층은 뺐다.
- 좁은 창: 1024↓ 패널 폭을 줄이고 왼쪽은 접고 시작 · 768↓ 오른쪽은 아래 칸(42%), 왼쪽은 덮어 열기 · 아래 막대에 패널 접기 버튼 둘. 1600·1180·1024·700 에서 가로 넘침 0.

## 3. 범위(오른쪽 맨 위)
| 고른 것 | 표시 | 패널 | 값이 가는 곳 |
|---|---|---|---|
| 없음 | 전체 일괄 | 비주얼 · 배경 · 컬러 · 글자 · 레퍼런스 · 매체 추가 | `restyleWith` → `c.style` |
| 프레임 | 이 소재만 | 레이아웃 안 · 요소 목록 · 비주얼 · 배경 · 컬러 · 글자 · 가이드 | `a.overrides.style` |
| 프레임 안 요소 | 이 요소만 | 위치 · 크기 · 글꼴 · 굵기 · 정렬 · 색 | 아래 4절 |

- 개별값이 있으면 섹션 머리에 「개별 ↔」, 범위 표시 줄에 「개별 n ↔」. 누르면 일괄값으로 되돌린다(섹션별 · 전부). 왼쪽 브리프 칸도 개별값이면 칸마다 되돌리기.
- Esc: 요소 → 소재 → 전체. 빈 곳 클릭 = 전체.
- 레이아웃 안(`#iVariants`)은 이 소재만 패널 맨 위. style 키 내용을 안 본다(`v.style` 을 그대로 합친다).

## 4. 프레임 안 요소 선택(`app/elselect.js`)
- 한 번 누르면 프레임, 고른 프레임 안을 한 번 더(또는 ⌘/Ctrl) 누르면 그 자리 요소. 글자 → 로고 → 키비주얼 순, 작은 상자 먼저. 올리면 얇은 테두리.
- 두 번 누르기 · Shift+2 = 그 프레임으로 확대(25% 에선 글자 한 줄을 집기 어렵다).
- 끌기 · 네 모서리 크기 · 화살표 1px(Shift 10) · +/− · 패널 숫자 칸(식 계산 그대로). 안전영역 밖이면 빨간 테두리, 놓으면 안쪽으로(`core/editlayout.js` 그대로). 끄는 동안 `LIVE`(campaign 안 고침), 놓을 때 되돌리기 한 걸음.
- 키보드: 「요소」 목록 버튼 → Enter 로 고름 → 화살표.

| 값 | 저장 |
|---|---|
| 메인·서브·상세 색 · 크기 | `overrides.style.roleColors` · `roleScale`(있던 것) |
| 그림·로고 위치 · 크기(자유 칸) | `overrides.layout`(직접 수정 그대로) |
| 글자 위치 · 굵기 · 글꼴 · 정렬, 그 밖 역할(기업명·뱃지·날짜)의 색 · 크기, 틀 칸 그림·로고 | **새 `overrides.elements`** |

### 왜 렌더러를 안 고치고 되나
`core/elementedit.js applyElementEdits(html, edits, size)` 가 그려진 html 에서 그 요소의 인라인 스타일만 고친다. 옮기기는 절대 위치면 `left/top` 에 더하고 흐름 안이면 `position:relative` — `transform` 을 안 써서 래스터·SVG 어디서나 상자 그대로. 틀 칸 그림·로고만 렌더러 `kvWrap` 과 같은 `data-edit` 층으로 감싼다.
지나는 곳: `core/generate.js`(보드) · `liveRender`(끄는 동안) · `exportAdFiles` post(PNG/JPG·ZIP) · `adSvgOf`(SVG). 글꼴을 요소에 고르면 `data-el-font` 를 달아 미리보기·내보내기에 @font-face 를 같이 싣는다.

### 잠금
- 색이 규정인 규격 색 칸 · 크기가 규정인 규격(자소설·비즈보드) 크기 칸 · 글꼴 고정 매체 글꼴 칸은 비활성(이유 한 줄). 있던 규칙 그대로.
- **틀이 정한 그림·로고·글자 칸은 열어 뒀다**(사용자 「열어둘 필요」). 옮기면 게이트가 판정 — 자소설은 틀 ✗ 가 「차단」이라 이미지 내보내기가 잠기고 SVG 만 나간다(기존 규칙). 패널에 「틀이 정한 칸 · 옮기면 검수에 걸릴 수 있어요」.

## 5. 비주얼 활용 재배치
전체 일괄 「비주얼」 한 섹션: 키비주얼 교체 · 끌어서 보여 줄 영역(`kvfocus`, `regionFit`) · 가로형/세로형 · 색 다시 맞춤 · 제거 · AI 그림 판단 · 자리(`kvPlace`) · 크기(`kvSize`) · 스크림 · 로고. 이 소재만은 자리 · 크기 · 스크림과 교체로 가는 버튼. 쓰이지 않던 `presetCampaignHtml`·`presetArtifactHtml` 을 살려 키를 골라 그린다.

## 6. 함께 고친 것
- `propagate()` 가 공통 스타일로만 다시 그려 개별값이 다음 재생성까지 빠지던 것 → 브리프 일괄 변경 뒤 `regen`.
- 화면 좁을 때 머리띠 버튼 글자가 세로로 쪼개지던 것(nowrap).

## 8. 못 한 것 · 남은 것
- 아래 도구 막대(프레임·도형·글자·이미지·코멘트·AI)와 손 도구, 페이지 배경 섹션은 안 넣었다. 그릴 데이터 모델이 없어 누르면 안 되는 버튼이 된다. 지금은 소재 안 요소를 고치는 편집기.
- 글자 내용은 왼쪽 브리프로만 고친다(캔버스에서 직접 타이핑 없음).
- 같은 역할 여러 개(뱃지 등)는 몇 번째로 기억한다. 문구가 바뀌어 줄 수가 달라지면 번호가 다른 줄을 가리킬 수 있다.
- 요소 편집은 고른 안에만 입힌다 — 「전체 안 포함」 ZIP 의 다른 안에는 안 들어간다.
- 결정 필요: 자소설 등 틀 ✗ 차단 매체에서 위치를 손으로 옮기면 PNG 를 막을지(지금은 기존대로 차단).
