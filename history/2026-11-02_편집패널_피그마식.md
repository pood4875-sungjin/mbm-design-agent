# 2026-11-02: 편집 패널을 피그마 UI3 식으로 · 끄는 동안 보드가 실시간으로 따라옴

**상태: worktree 브랜치 커밋(푸시 안 함).** 렌더 결과·저장 형식은 그대로, `app/` · `test/` 만.

## 1. 사용자 요청
- 「이런 편집 기능 같은 건 이전에 피그마처럼 기능 만들었던 걸 최대한 반영해 줄래?」 — 큰 알약 버튼·큰 입력칸이던 그라데이션 편집기·배경 칸·인스펙터 컨트롤을 `hub/` 모양·조작으로.
- 「실시간으로 반영되는 게 보이는 게 나을 듯」 — 끄는 동안 소재가 따라 바뀌게(깜빡임 없이).

hub CSS 를 전역에 깔지 않았다. `index.html` 「피그마 UI3 편집 컨트롤」 묶음에 앱 토큰으로 옮겼다(--bg2→--soft, --border2→--accent-line, --blue→--focus) — 다크모드 포함.

## 3. 옮기지 못한 것·다르게 한 것
- **hub 에 그라데이션 구현이 없다**(`2026-10-26` 기록 「남은 것」). 행 구조만 옮기고 편집기는 앱 것을 다시 입혔다.
- hub 의 불투명도·보이기 칸은 뺐다. 값 형식(`background.gradient`)에 알파·숨김이 없어서.
- 배치 프리셋 `.pseg`·`#pBgColor`(`editor.js`)는 안 건드렸다. `presetCampaignHtml`·`presetArtifactHtml` 을 부르는 곳이 없어 화면에 안 나온다.
- 인테이크의 폰트 칸·인스펙터의 흰 카드 층(`.isec`)은 그대로.

## 4. 고친 것(기능)
- 정지점을 누르거나 끈 뒤, 또는 화살표를 한 번 누른 뒤 다시 그려지며 포커스가 사라져 **Delete·연속 화살표가 안 먹던 것** → 그 칸으로 돌려준다.
- 정지점 행의 빈 곳을 누르면 그 손잡이로 포커스.
- 헥스 칸 추가: 지금까지 색 칩뿐이던 배경 단색·브랜드 색·글자색도 헥스로 입력.

## 5. 실시간 미리보기(`app/live.js`)
- 끄는 동안: 보이는 프레임만, 렌더러로 다시 그린 html 을 **기존 iframe 문서에 달라진 속성만 입힌다**(`morphDoc`). `srcdoc` 재적재 없음, 같은 data: 그림은 건드리지 않음. 한 프레임 14ms 예산으로 돌아가며 그린다.
- 끄는 동안 `campaign` 을 고치지 않는다 → 되돌리기·저장·승인 게이트·측정 큐 안 돎. `lintAds` 는 끄는 중이면 미룬다. `renderInspector` 안 부름.
- 놓으면 `restyleWith` 한 번(되돌리기 한 걸음). `softly` 로 `srcdoc` 대신 문서에 입히고 검수는 같은 길(`iframe.onload`)로. 글꼴 선언(head)이 다르면 예전처럼 `srcdoc`.
- 대상: 브랜드 색 3칸 · 배경 단색 · 그라데이션 정지점·각도·색 · 글자색(일괄·개별) · 키비주얼 영역 끌기. 영역 끌기를 취소하면 저장된 그림으로 되돌린다.

## 6. 확인
- 실제 앱: 샘플 → 광고 소재 → 다음 → 다음 → GS에너지 KV·로고 → 인스펙터. 라이트·다크 각 37개 확인 통과, 콘솔 오류 0(`config.local.js`·`favicon` 404 는 이 worktree 에 파일이 없어서, 앱 오류 아님).
  - 정지점 추가 → 소재 9칸이 `manual-gradient` · 끌기 25% → `linear-gradient(180deg,#E0F8FF 0%,#C6F3FF 25%,…)` · 헥스 FF3366 → 지면 · 각도 식 `90+45` → `135deg` · 방사형 → `radial-gradient` · 단색 헥스 · 되돌리기 · 정렬 아이콘.
  - 실시간: 끄는 중 포커스 손잡이·인스펙터 스크롤 그대로, 놓은 뒤 되돌리기 한 번 = 끌기 한 걸음.
- 테스트: `test/fui-live.test.js` 4건 추가. 이 worktree 에서 605건 중 576 통과 · 29 실패 — 실패 29건은 시작 시점과 이름까지 같다(로컬 전용 `ref/learned/cases/*` 가 worktree 에 없어 ENOENT 인 것들). 새 실패 0.

## 7. 남은 것
- 놓을 때 멈칫(32장 약 350ms). `regen` 의 안 후보 계산을 뒤로 미루면 줄지만 `core/generate.js` 라 이번 범위 밖.
- 실제 색 피커(OS 팝업)를 사람 손으로 끌어 본 것은 아니다. 헤드리스에서 `input`·`change` 이벤트로 확인.
- 보드를 확대해 일부만 보일 때 화면 밖 프레임은 놓을 때 갱신된다(의도).
